# 0015: 数式エラーの一覧

- 状態: open
- 起票日: 2026-09-19

## 背景

KaTeXは `throwOnError: false` で呼んでいるので、壊れた数式はプレビュー内に
赤字で出る（設計上の約束で、入力途中にプレビューが消えないための判断）。
ただし長い文書では、その赤字がスクロールの外にあると気づけない。
「どこかが壊れているが、どこか分からない」状態になる。

## やりたいこと

- 文書中の壊れた数式の件数が常に見える。
- 一覧から選ぶと、その数式がエディタとプレビューの両方で特定できる。
- 壊れていないときは邪魔にならない。

## やらないこと

- LaTeXの文法チェックや修正候補の提示。KaTeXが出すエラーをそのまま見せる。

## メモ

- `renderMarkdown.ts` はいまKaTeXの結果をHTML文字列として返すだけで、
  エラーの有無を呼び出し側に返していない。戻り値を `{ html, errors }` の形に
  変える必要がある（`lib/` の純粋関数のまま実現できる）。
- 数式の位置（ソース上のオフセット）を持てば、エディタ側の該当箇所へ飛べる。
  抽出時にオフセットを記録しておくこと。
- [0010](0010-scroll-sync.md) の「行と出力の対応づけ」と材料が共通する。
