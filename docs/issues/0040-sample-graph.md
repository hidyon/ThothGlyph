# 0040: サンプル文書にグラフが入っていない

- 状態: closed
- 起票日: 2026-09-20

## 背景

[0037](0037-graph.md) でグラフを描けるようにしたが、初回訪問で出るサンプル文書
（「二次方程式の解の公式」）は数式・箇条書き・複数行の式だけで、グラフが入っていない。

サンプル文書の狙いは「何ができるかが一目で分かること」（`src/sampleDocument.ts`
のコメント）。グラフはこのアプリの記法であって他所で見かけないので、
**サンプルに出ていなければ、あることに気づかれない**。パレットの `Markdown` タブに
雛形ボタンはあるが、ラベルは `グラフ` の4文字で、押すまで何が起きるか分からない。

## やりたいこと

- 初回訪問の画面にグラフが1つ描かれていて、ソース側にその書き方が見えている。
- グラフが文書の内容とつながっている（飾りで置かない）。
- 日本語と英語の両方のサンプルに同じ狙いで入る。
- READMEのスクリーンショットにもグラフが写る。

## やらないこと

- サンプル文書の書き直し。いまの内容は保ち、グラフを足すだけにする。
- グラフを2つ以上入れること。1つで「あること」は伝わる。

## メモ

- 二次方程式の文書なので、判別式の符号と「グラフが $x$ 軸と何回交わるか」を
  結びつけるのが素直。$D > 0$ の例として $y = x^2 - 2x$（解は0と2）を置く。
- サンプル文書は長くすると初回の印象が重くなる。足すのは見出しなしの1段落と
  ブロック1つまで。
- 実機検証がサンプル文書の**先頭行**に依存している（`# 二次方程式の解の公式`)。
  先頭は変えないので影響しないはずだが、全区分を流して確かめること。
