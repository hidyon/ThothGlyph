# 0084: Markdown標準ではない機能が、READMEから見分けられない

- 状態: open
- 起票日: 2026-09-22

## 背景

READMEの「できること」は機能を並べているだけで、**どれがMarkdownの標準で、
どれがこのエディタだけの振る舞いか**が書かれていない。

実際には次の3つが標準ではない。

| 機能 | 記法 | 持ち出した先（GitHubなど）での見え方 |
|---|---|---|
| 式の自動採番（[0044](0044-equation-numbers.md)） | `\tag{名前}` | 番号ではなく**名前**が出る（`(密度)`） |
| 式への参照（0044） | `[(1)](#eq-名前)` | 書いた数字のまま。**飛べない** |
| 関数のグラフ（[0037](0037-graph.md)） | ` ```graph ` | グラフにならず、**コードブロック**として出る |

採番と参照については、**そもそもREADMEに機能として載っていない**
（「できること」の表に行がない）。

Markdownには採番も相互参照もカウンタも無く、**どの処理系でも自動で番号が合う
書き方は存在しない**（順序付きリストの番号だけが例外で、それも参照は追従しない）。
持ち出して使うことを前提にした道具なので、**どこまでが持ち出せるか**は
使う前に分かるべき情報になっている。

## やりたいこと

- READMEに**式の自動採番と参照**を機能として載せる。
- **Markdown標準ではないもの**（採番・参照・グラフ）を、持ち出した先での
  見え方とセットで書く。
- 完全な形で渡したいときの逃げ道（[0050](0050-html-export.md) のHTML書き出し、
  [0082](0082-bake-equation-numbers.md) の番号の焼き込み）にも触れる。
  **まだ無いものは「今はない」と書く**（機能仕様の書き方に合わせる）。

## やらないこと

- 記法そのものの変更。[0083](0083-crossref-dialect.md)。
- 機能仕様（`docs/functional-spec.md`）の書き換え。あちらには既に
  「持ち出した先での見え方」が書いてある。READMEは使う人向けの入口。

## メモ

- [0035](0035-readme-for-users.md) でREADMEを使う人向けに書き直した。その体裁
  （表と短い節）を崩さないこと。
- 0083で記法が変わると、この記述も変わる。**0083の後にやるほうが書き直しが少ない。**
