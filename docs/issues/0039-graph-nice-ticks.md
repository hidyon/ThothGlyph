# 0039: グラフの目盛りの値がきりのよい数にならない

- 状態: open
- 起票日: 2026-09-20

## 背景

[0037](0037-graph.md) のグラフは、yの範囲を描いた値から自動で決め、その範囲を
5等分した位置に目盛りを置く。範囲がきりのよい数にならないので、目盛りの値も
きりの悪い数になる。

`y = x^2` / `y = 2x + 1` / `y = sin(x)` を幅1440pxで描いたときの実際の表示:

```
20.5 / 13.3 / 6.03 / -1.19 / -8.41
```

読めはするが、グラフから値を読み取るには使いにくい。市販の道具は
`20 / 15 / 10 / 5 / 0` のように**きりのよい数**を選び、その外側に軸の範囲を広げる。

## やりたいこと

- 目盛りの値が `1 / 2 / 5 × 10^n` のようなきりのよい数になる。
- 目盛りの本数は今と同程度（4〜6本）で、範囲によって増減してよい。
- 自動で決めたyの範囲は、きりのよい目盛りが端に来るように外側へ丸める。
- `y:` で範囲を手で指定したときは、指定した範囲を変えない
  （指定を無視して広げると、指定した意味がなくなる）。

## やらないこと

- 対数軸。別の話。
- 目盛りの本数を利用者が指定すること。まず自動で使ってみる。

## メモ

- 実装は範囲の幅から「きりのよい刻み」を選ぶ関数を `lib/` に1つ足すだけで済むはず
  （`renderGraph.ts` の目盛りの計算を差し替える）。
- 0037の単体テスト `renderGraph.test.ts` に「目盛りを5本ずつ出す」というチェックが
  あるので、本数が変わるならそのテストも直す。
- 幅360pxで目盛りの文字が長くなりすぎないか（左余白60ユーザー単位）を測ること。
