# 0056: パレットだけ見出しがなく、何の領域か分からない

- 状態: closed
- 起票日: 2026-09-20

## 背景

ソースとプレビューには見出し行（`.pane__header`）があり、`ソース` `プレビュー` と
書いてある。**パレットにだけ見出しがない。**

実測（2026-09-20、幅1440×900・日本語）:

| 領域 | 見出し | 高さ |
|---|---|---|
| ソース | `ソース` ＋ 右端に `検索` `ファイルに保存` `ファイルを開く` | 30px |
| プレビュー | `プレビュー` ＋ 状態（`更新中…` `準備中…`） | 30px |
| パレット | **なし**（いきなりタブが並ぶ） | — |

[0054](0054-palette-placement.md)でパレットが左の縦帯になり、
**3つの領域が横に並ぶ形**（180px / 630px / 630px）になったので、
ソースとプレビューにあって左端の帯にだけ無いのが目立つ。

## やりたいこと

- パレットにも、ソース・プレビューと**同じ形の見出し**が付く。
- 見出しの高さが他の2つと同じ30pxである。
- 見出しが付いても、パレットの中身が使える高さが減りすぎない
  （幅1440pxの縦帯で845px、幅360pxで139pxが現在の値）。

## やらないこと

- 見出しの中にボタンを置くこと（ソース側の `検索` のような）。まず名前だけ。
- 3つの見出しの見た目を作り直すこと。

## メモ

- **狭い画面（横帯）では高さがそのまま30px増える**。幅360pxのパレットは
  139pxで、うち一覧は98pxの蓋（[0032](0032-palette-height-narrow.md)）。
  ここに30px足すと169pxになり、textareaは194px → 164pxに減る。
  **仕様で「横帯のときは出さない」を選ぶ余地がある**（縦帯だけ見出しを出す）。
  どちらにするかは、幅ごとに測ってから決めること。
- 文言は `lib/messages.ts` に2言語で足す（`パレット` / `Palette`）。
- 見出しを付けるなら、`role="region"` と `aria-label` の扱いも仕様で決める
  （いまのタブは `role="tablist"` を持っている）。
