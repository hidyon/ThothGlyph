# 0003: 数式の画像書き出し

- 状態: open
- 起票日: 2026-09-19

## 背景

Markdownをコピーしても、貼り付け先がLaTeXをレンダリングできなければ数式は
ただの `$...$` の文字列になる。スライド、チャット、Word などに数式を持って
いきたい場面では画像が要る。

## やりたいこと

- プレビュー中の数式から、その1つを画像として取り出せる。
- 背景が透明で、貼り付け先の背景色を問わず使える。
- 解像度が十分で、拡大しても粗くならない。

## やらないこと

- 文書全体のPDF書き出し。数式単体に絞る。

## メモ

- KaTeXの出力はHTML+CSSなので、そのままでは画像にできない。実現方法は
  仕様段階で検討する:
  - MathML/HTMLをSVGに変換する（KaTeX単体では不可。MathJaxのSVG出力なら可能だが
    依存が増える）
  - `foreignObject` を使ったSVG化（フォント埋め込みが課題）
  - canvasへの描画
- どの数式を対象にするか（クリックで選ぶ？ 全部？）もUIとして決める必要がある。
- 実現手段によっては重い。0001・0002を先に片付けてから着手したい。
