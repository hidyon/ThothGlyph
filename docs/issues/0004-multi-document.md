# 0004: 複数文書の管理

- 状態: open
- 起票日: 2026-09-19

## 背景

今は文書が常に1つしかない。別の文書を書き始めるには、今の内容を手でどこかに
退避するしかない。メモとして使ううちに必ず「前に書いたあれ」を開きたくなる。

## やりたいこと

- 文書を複数持ち、一覧から選んで開ける。
- 新規作成、リネーム、削除ができる。
- どの文書を編集していたかが次回訪問時に復元される。

## やらないこと

- フォルダ階層、タグ、全文検索。まず平坦な一覧で使ってみてから考える。

## メモ

- 0001（自動保存）の保存形式を、そのまま複数文書に拡張できる形にしておくと楽。
  0001の仕様を書くときに、ここへの拡張余地を意識すること。
- localStorageの容量上限が効いてくるのはこのissueから。IndexedDBへの移行が
  必要になるかもしれない。
