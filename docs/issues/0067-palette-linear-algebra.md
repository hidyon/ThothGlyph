# 0067: パレットに線形代数の記号と公式がない

- 状態: open
- 起票日: 2026-09-21

## 背景

[0064](0064-palette-beyond-highschool.md) で統計・確率と集合・論理をパレットに
足したが、**線形代数は範囲外にした**（[0064の仕様](../specs/0064-palette-beyond-highschool.md#スコープ外)）。
0064の背景にある実測（統計の証明集から10ページ相当の覚書を書き通したとき、
常用する記号を検索して1件も出なかったもの）のうち、次の2件が残っている。

| 要るもの | 使う場面 | いまの検索結果 |
|---|---|---|
| `\top` | $X^\top$（転置） | 0件 |
| `bmatrix` | 角括弧の行列（`pmatrix` はある） | 0件 |

語で引いても出ない。**「転置」0件**（0064の実装後に実機で再確認し、
`palette-stats` 区分のチェックとして固定してある）。

いまパレットにある行列の記号は `括弧・構造` グループの `pmatrix`（2x2）1件だけで、
**行列式・逆行列・ノルム・内積の記号も分類もない**。公式は15分類75件のうち
線形代数の分類が0件。

## やりたいこと

- 大学初年度の線形代数の講義ノートを書くときに、常用する記号を
  **覚えていなくても選んで入れられる**。
- 語で引ける。「転置」「行列式」「ノルム」と打てば当たる。
- 足しても画面が悪くならない（0064と同じ制約）。

## やらないこと

- **記号の新しいタブを作ること。** 0064で実測したとおり、タブを1つ足すと
  検索欄が2行目に落ち始める幅が上がる（日本語944→1007px、英語は横帯の全幅）。
  落ちると横帯で+34px。既存グループ（`括弧・構造` `演算子` `関係子`）へ足す。
- **既存の130件・75件を減らすこと・並べ替えること。**
- **装飾・書体の追加**（[0068](0068-palette-decorations.md)）。

## メモ

- 範囲の候補（仕様で絞る）: `\top` 転置・`bmatrix`・`\det`・逆行列・`\|x\|` ノルム・
  `\langle x, y \rangle` 内積・`\operatorname{rank}`・固有値。
  公式は「行列」「固有値」あたりの分類を各5件。
- **`\mathrm{T}` と `\top` のように同じ用途で書き方が複数あるものは片方にする**
  （0064では立体の `\mathrm` に統一した）。
- **0064で測ったコストがそのまま使える**（仕様の「3つの足し方のコストを測り比べた」）。
  記号を既存グループへ足すのは実質コスト0、公式は分類ごと約32px。
  ただし**幅1199pxの公式タブは0064で180pxまで伸びていて、2段目タブは2行目に
  入ったところ**なので、分類を足すと3行目に入る可能性がある。測り直すこと。
- READMEの件数（記号130個・公式75件）は単体テストで固定されている。
  足すと `npm test` が落ちるので、READMEも同じコミットで直す。
- 追加するLaTeXは**仕様の時点で `katex.renderToString` に `throwOnError: true` で
  通すこと**（0064でそうした。43件すべて描けることを確かめてから仕様に書いた）。
