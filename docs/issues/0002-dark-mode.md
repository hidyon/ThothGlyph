# 0002: ダークモード

- 状態: closed
- 起票日: 2026-09-19

## 背景

現在の配色はライトのみで固定されている。`index.css` に `color-scheme` の指定もなく、
OSがダークテーマの環境では白い画面が眩しい。数式エディタは長時間見つめる道具なので
影響が大きい。

## やりたいこと

- OSのテーマ設定に追従して、ライト／ダークが切り替わる。
- 手動でも切り替えられ、選んだテーマが次回訪問時も保たれる。
- ダークでもKaTeXの数式とプレビューのMarkdown（コード、引用、表、罫線）が
  読める配色になっている。

## やらないこと

- 任意配色のテーマ機能。ライトとダークの2つだけ。

## メモ

- 色はすでに `:root` のCSS変数に寄せてあるので、ダーク側の値を上書きするだけで
  済む見込み。
- KaTeXの数式は `currentColor` で描かれるので追随するはずだが、エラー時の赤
  （`errorColor: '#dc2626'`）はダーク背景でのコントラストを確認すること。
- テーマの保持先は0001の保存機構と方式を揃えたい。0001の後にやるのが自然。

## 結果（2026-09-19 クローズ）

3状態（自動／ライト／ダーク）で実装した。保存先は `matheditor:theme:v1` で、
[0001](0001-autosave.md) の命名規約に揃えてある。

メモに書いていたKaTeXのエラー色の懸念は実測で解消した（ダークで8.77:1）。
`errorColor` は変えず、`.katex-error` をCSSで上書きしている。

仕様から変えた点: 初期テーマの適用を `index.html` のインラインスクリプトにした。
Reactのマウントを待つと、OSがライトで手動ダークの場合に白が20ms見えたため
（実測して相談のうえ決定）。

検証: `npm test` 43件、実機38/38 OK、コンソールエラーなし。
ダークのスクリーンショットも目視した。
