# 0048: 幾何の図を描けない

- 状態: open
- 起票日: 2026-09-20

## 背景

[0037](0037-graph.md) で描けるようになったのは `y = f(x)` の**関数のグラフ**だけ。
数式ノートで出てくる図はそれだけではない。

- 三角形・四角形に頂点や角の記号を振ったもの（幾何、三角比）
- 円と接線、中心角
- 数直線（不等式の解、区間）
- ベクトルの矢印

いまはこれらを描く手段がない。画像も貼れない（[0045](0045-paste-image.md)）ので、
図が要る説明はノートに残せない。

## やりたいこと

- 上の4種類くらいの図を、テキストで書いて描ける。
- 頂点や辺に記号（$A$、$a$）を振れる。
- 0037と同じ書き味（コードフェンス、プレビューに即出る、持ち出すと式が残る）。

## やらないこと

- 一般の作図（定規とコンパスの手順を書く、自由な曲線）。
- マウスで図を描くこと。テキストで書ける範囲に絞る。
- 3Dの図。

## メモ

- 0037の土台（SVGの生成、パイプラインへの接続、幅360pxの制約）はそのまま使える。
  **`renderGraph.ts` の3つの制約**（色と文字の大きさはCSSで当てる、`clipPath` は
  使わない、狭い画面の余白は残り14ユーザー単位）を先に読むこと。
- 記法を種類ごとに作ると増えすぎる。まず**数直線**だけで始めて、書き味を
  確かめてから広げる手もある（数直線は不等式の解とセットで需要が高く、
  描画も単純）。
- TikZの記法を真似るかどうか。真似ると覚えている人には早いが、実装が
  果てしなくなる。**このエディタの範囲を仕様で線引きすること。**
