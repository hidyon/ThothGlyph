# 0057: 3つの領域の幅が固定で、読む・書くに合わせて変えられない

- 状態: closed
- 起票日: 2026-09-20

## 背景

画面は横に3つ並ぶが、幅はすべてCSSが決めていて利用者は変えられない。

実測（2026-09-20、幅1440×900・日本語）:

| | パレット | ソース | プレビュー |
|---|---|---|---|
| 幅 | 180px（固定） | 630px | 630px |
| 決め方 | [0054](0054-palette-placement.md) の `180px` | `1fr` | `1fr` |

書いているときはソースを広くしたく、読み返すときはプレビューを広くしたい。
数式が長い行（`\begin{aligned}` の導出など）はソースが狭いと折り返し、
グラフや表はプレビューが狭いと縮む（0054の実測で、プレビュー512pxのとき
グラフは464px、422pxのとき374pxになった）。

## やりたいこと

- 領域の境目をドラッグすると、**左右の幅が変わる**。
- 変えた幅が次に開いたときも残る。
- 極端に狭くして中身が読めなくなることがない（下限がある）。
- 狭い画面（幅720px以下、上下2分割）の見え方は変わらない。

## やらないこと

- 領域の並べ替え（プレビューを左に持ってくるなど）。
- 領域を閉じる／隠す機能。[0022](0022-narrow-pane-switch.md)（狭い画面での
  切り替え）とは別の話として扱う。
- 高さの可変（上下2分割のときの分け方）。

## メモ

- **保存形式を決める必要がある。** テーマ（`matheditor:theme:v1`）や言語と
  同じく専用のキーを足すのが素直（`matheditor:panes:v1`）。
  [0004](0004-multi-document.md)（複数文書）とは別の入れ物なので、
  そちらの保存形式変更とは独立にできる。
- 下限の決め方は測ってから。**0054で分かっている数値**: プレビューが422pxに
  なるとグラフが374pxまで縮む、パレットの縦帯は180pxでタブ名
  （`Ωギリシャ大文字` 124.7px）が収まる。
- ドラッグの実装は、`.panes` の `grid-template-columns` を状態で持つ形になる。
  **状態が増える**（いまUIの一時状態はパレットのタブ・検索クエリ・コピー結果だけ）。
  [architecture.md](../architecture.md) の「状態は `source` 1つに集約」に
  例外を足すことになるので、仕様で位置づけを書くこと。
- [0054](0054-palette-placement.md) のスコープ外に「帯の幅を利用者が変えられる
  ようにする（ドラッグ）」として送ったもの。本issueがその受け皿。
