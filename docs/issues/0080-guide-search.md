# 0080: 算式記載ガイドの中を探せない

- 状態: open
- 起票日: 2026-09-22

## 背景

[0079](0079-notation-guide.md) で入れた算式記載ガイドは、第2部に**954件の
コマンドと33件の環境**を13分類で並べている。分類の見出しはあるが、
**ガイドの中を絞り込む手段がない**。

- パレットの検索（[0011](0011-palette-search.md)）が対象にしているのは
  パレットの記号151件と公式75件で、ガイドの954件は入っていない。
- `Ctrl+F` は文書内の検索バー（[0043](0043-find-replace.md)）を開く。
  これは**編集中の文書**に対するもので、ガイドの中は探せない。
  ガイドを開いている間に押しても、背後の文書の検索バーが開く。
- ブラウザ自身の検索も、ガイドは同じページの中の要素なので混ざる。

「見出しを頼りにスクロールして探す」だけが残っている。分類「関係子」は
221件あり、目で追うには多い。

## やりたいこと

ガイドを開いたまま、**コマンド名で絞り込める**ようにする。

## やらないこと

- パレットの検索（0011）にガイドの954件を混ぜること。パレットの検索結果は
  押すと挿入されるもので、ガイドは読むためのもの。役割が違う。
- ガイドからエディタへの挿入（0079のスコープ外のまま）。

## メモ

- 名前の欄はパレットに名前があるものだけ埋まっている。日本語で引ける語が
  少ないので、**コマンド名（`\\frac`）での絞り込みが主**になる。
- `lib/search.ts` の `normalize`（`\` や `{}` を落とす）はそのまま使えるはず。
- ガイドを開いている間に `Ctrl+F` をどちらに効かせるかも、このissueで決める。
