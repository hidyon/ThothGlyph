# 0022: 狭い画面でソースとプレビューを切り替えられない

- 状態: open
- 起票日: 2026-09-19

## 背景

`src/index.css` の `@media (max-width: 720px)` で、2ペインは左右分割から
**上下分割**（`grid-template-rows: 1fr 1fr`）に変わる。横に並べるよりは読めるが、
縦を半分ずつ分け合うため、スマートフォンではソースもプレビューも数行しか見えない。

[0002](0002-dark-mode.md) の検証で幅600pxの表示を確認しているが、
見ているのは「ツールバーのボタンが画面内に収まるか」だけで、
**書けるかどうか**は確かめていない。

## やりたいこと

- 狭い画面で、ソースとプレビューを切り替えて**片方を大きく使える**。
- いまどちらを見ているかが画面から分かる。
- 切り替えても編集中の内容とカーソル位置が失われない。
- 広い画面の左右分割はこれまで通り（切り替えUIが出てこない）。

## やらないこと

- 分割位置をドラッグで変えること。広い画面の話であり、別の需要。
- モバイル専用のレイアウトを新しく作ること。いまのCSSの延長で収める。

## メモ

- 切り替えの見せ方の候補: ツールバーにタブを置く、ペインのヘッダー
  （`ソース` / `プレビュー`）自体を押せるようにする。後者は要素が増えない。
- 選んだペインを保存するかどうかを仕様で決めること。保存するなら
  [0002](0002-dark-mode.md) のテーマと同じ形（`localStorage` に1キー）に揃う。
- 受け入れ基準は実機検証。`page.setViewportSize` で狭くして、
  切り替え後にそれぞれのペインの高さを**測って**確かめる（目視で判断しない）。
- 720pxという境界値が妥当かは確かめていない。**未確認。**
