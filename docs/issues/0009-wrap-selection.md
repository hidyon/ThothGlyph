# 0009: 選択範囲をパレットの記号で囲む

- 状態: open
- 起票日: 2026-09-19

## 背景

`x + 1` を選んで `\frac` を押すと、いまは選択範囲が消えて `\frac{}{}` に
置き換わる（`insertSnippet.ts` は選択範囲を置換する）。書いた式に後から
ルートや分数をかぶせる操作ができず、打ち直しになる。

## やりたいこと

- 選択範囲があるときにパレットを押すと、選択した文字列が記号の中に入る。
  例: `x + 1` を選んで `\sqrt` → `\sqrt{x + 1}`。
- 囲んだあとのカーソル位置が、続きを書きやすい場所にある。
- 選択範囲がないときの挙動はこれまで通り。

## やらないこと

- 複数の選択範囲（マルチカーソル）。textareaでは扱えない。

## メモ

- `palette.ts` の `snippet` に「選択範囲をここに入れる」トークンが要る。
  既に `%CURSOR%` があるので、`%SELECTION%` のような形で足すのが素直。
  記号ごとに入れる場所が違う（`\frac` は分子、`^{}` は中身）点に注意。
- `insertSnippet` は純粋関数なので、ここはテストが書きやすい。
  [0014](0014-unit-tests.md) の最初の対象に向く。
