# 0053: パレットのタブが文字だけで、狙ったタブを探すのに読む必要がある

- 状態: closed
- 起票日: 2026-09-20

## 背景

記号パレットのタブは8つ（`基本` `ギリシャ小文字` `ギリシャ大文字` `演算子`
`関係子` `括弧・構造` `Markdown` `公式`）で、**どれも文字だけ**でできている。
タブを選ぶたびに文字を読んで見分けることになり、位置で覚えるのにも
手がかりが少ない。

実測（2026-09-20、幅1440×900・日本語／英語）:

| | 日本語 | 英語 |
|---|---|---|
| タブ8つの横幅の合計 | 650.1px | 874.9px |
| タブの高さ | 30px（Markdownのみ27px） | 27px |
| パレット全体の高さ | 94px | 92px |

狭い画面ではタブ行が**横スクロール**になっている（幅360px、日本語。
見えているのは142px、中身は674px。英語は899px）。**アイコンを足すと
1タブあたりの幅が増え、この横スクロールがさらに長くなる**ので、
足したあとの合計幅を測る必要がある。

## やりたいこと

- 8つのタブそれぞれにアイコンが付き、**文字を読まずに見分けられる**。
- アイコンを足してもパレットの高さが増えない（幅1440pxで94px、
  幅360pxで139px。[0032](0032-palette-height-narrow.md) の蓋を壊さない）。
- 狭い画面（幅360px）でタブ行の横スクロールが極端に長くならない。
  現状の674px（日本語）からどれだけ増えるかを仕様の時点で測って書く。
- 日本語と英語のどちらでも同じアイコンが出る（アイコンは翻訳を持たない）。

## やらないこと

- タブ名の文字を消してアイコンだけにすること。まずアイコンを**足す**。
  文字を消すかどうかは、足して測ってから別に決める。
- パレットのボタン（記号そのもの）へのアイコン。ボタンの `label` は
  KaTeXで描いたLaTeXで、記号そのものが絵になっている。
  ただしMarkdownタブの7件だけは例外で、下のメモに書く。
- タブの並べ替え。

## メモ

- **アイコンの持ち方を仕様で決めること。** 外部のアイコンフォントや
  ライブラリは入れない（CLAUDE.mdの「入れない依存」）。インラインSVGを
  `lib/` か `components/` に持つ形になる。初期チャンクに乗るので、
  8件ぶんのバイト数を `scripts/measure-load.mjs` で測って書く。
- 色と線の太さは、グラフ（[0037](0037-graph.md)）の `renderGraph.ts` と
  同じ制約に当たる。**色はSVGの属性ではなくCSSで当てる**（ダークモードのため）。
- **Markdownタブのボタン7件は、記号ではなく日本語の文字が描かれている**
  （`見出し` `太字` `斜体` `箇条書き` `グラフ` が `\text{見出し}` のような
  固定のLaTeXで、**英語表示でも日本語のまま出る**。実測で確認）。
  ここをアイコンにすると英語表示の問題も同時に消えるが、
  本issueの範囲はタブに絞る（ユーザーと合意）。別issueにする価値がある。
- [0054](0054-palette-placement.md)（広い画面でのパレットの置き方）と
  同じ場所を触る。**先に0054をやるとタブの並び方そのものが変わる**ので、
  着手順に注意する。
