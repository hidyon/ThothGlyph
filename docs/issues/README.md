  `unsaved.current` と `saveState` の両方を戻した。
  表示の戻し先は `lastSavedAt` のref（`SaveState` は `savedAt` を `saved` の
  ときだけ持つので、`pending` になると前回の時刻が失われる）。
- **`verify-ui.mjs` の `resetState` にあった「beforeunload で書き戻され、
  消したはずの文書が復活する（0009の検証で踏んだ）」はこの不具合だった。**
  検証側では回避されていたので、実際の利用でだけ踏んでいた。
  **検証で回避したことは、直すべきものを隠す。**
- **「時刻が更新される」は判定に使えない**（表示は分単位まで）。
  保存されたかどうかは**内容で見る**こと。
- 全区分の所要時間は264.1秒→277.1秒で**短くならなかった**。
  `saveSettled()` の5秒待ちが効いていたのは `undo` 区分だけで、
  足した6件（`autosave` が5.3→14.8秒）のほうが大きい。
- `undo` 区分はいまもlocalStorageで保存の完了を待っている（表示ベースに
  戻せるようになったが、**検証の書き換えは別の作業**として残してある）。

**スクロール同期は0010で完了した**（上の「着手順の目安」を見ること）。
