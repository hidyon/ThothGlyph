# 0088: 自分用スニペットをバックアップ・移行できない

- 状態: implemented
- 起票日: 2026-09-22

## 背景

自分用スニペットはブラウザのlocalStorageにだけ保存される。端末やブラウザを替える、ブラウザのデータを消す、別のプロファイルで作業する、といった場面では、時間をかけて登録した定義・証明の雛形・定型文を持ち出せない。

サーバやアカウントを持たない方針は保ちたい。利用者自身が1つのファイルとして控えを取り、必要な環境で復元できればよい。

## やりたいこと

- 登録済みの自分用スニペットをJSONファイルとして書き出せる。
- 書き出したファイルを別のブラウザや端末で読み込み、名前・本文・挿入の規則を保ったまま復元できる。
- 読み込み前に、現在のスニペットを置き換えることを確認できる。
- 壊れたファイルや別用途のJSONを選んでも、現在のスニペットは変わらず、理由が分かる。

## やらないこと

- サーバ、アカウント、端末間同期、他者との共有。
- 一覧への部分的な追加・重複の自動解決・フォルダ分け。
- 文書本文やテーマなど、スニペット以外の設定のバックアップ。

## メモ

- [0087](0087-personal-snippets.md) で追加した個人スニペットの保存形式を使う。
- 既存のMarkdownファイルの読み込み・書き出し（[0012](0012-file-io.md)、[0034](0034-file-save.md)）と、失敗時の表示を揃える。
- 入出力の入口は、狭い幅でもツールバーを増やさない自分用タブの中に置く。
