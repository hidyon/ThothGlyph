# 0043: 文書の中を検索・置換できない

- 状態: open
- 起票日: 2026-09-20

## 背景

パレットの検索（[0011](0011-palette-search.md)）は**記号と公式**を探すもので、
編集中の文書は対象外。文書の中の語を探す手段はブラウザの `Ctrl+F` しかなく、
それはプレビュー側のテキストには当たるが、**textareaの中は当たらない**
（見つかっても編集位置は動かない）。

置換にいたっては手段がない。ノートを書き進めてから記号を変えたくなること
（`\alpha` を `\beta` に全部直す、変数名を `x` から `t` にする）は珍しくない。

## やりたいこと

- 編集中の文書の中を検索し、見つかった位置へカーソルが動く。
- 次／前へ送れる。何件あるかが分かる。
- 置換（1件ずつ／すべて）ができる。
- 置換を取り消せる（[0021](0021-undo.md) のUndo履歴に乗る）。

## やらないこと

- 正規表現での検索。まず素の文字列で。
- 複数文書をまたぐ検索。それは [0004](0004-multi-document.md) の後。

## メモ

- `Ctrl+F` を奪うかどうかは仕様で決める。奪うならブラウザの検索が使えなくなるので、
  プレビュー側を探したい人が困る。[0008](0008-keyboard-shortcuts.md) と合わせて
  考えるのがよい。
- 置換は**挿入と同じ経路**（`App.tsx` の `insertIntoTextarea`）を通せば
  Undoが自動で効く（0021）。別の経路を作らないこと。
- 検索欄の置き場所は [0042](0042-outline.md) と競合する。両方を別々の場所に
  足すと画面が痩せるので、置き場所を一緒に決めるほうがよい。
