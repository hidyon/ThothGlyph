# 0046: 自分用の数式マクロを定義できない

- 状態: open
- 起票日: 2026-09-20

## 背景

ノートを書いていると同じ記法を何十回も書く（`\mathbb{R}`、`\frac{d}{dx}`、
`\begin{pmatrix}...\end{pmatrix}`）。LaTeXなら `\newcommand` で短い名前を
付けられるが、このエディタにその仕組みはない。

**ただし副作用として動いてしまう経路がある。** `$\def\R{\mathbb{R}} \R$` と
書くと定義が効く。これは意図した機能ではなく、KaTeXのマクロ状態が
共有されていることによるもので、[0047](0047-macro-leak.md) の不具合として別に起票した。
機能として使える形にはなっていない。

## やりたいこと

- 文書の中で自分の記法を定義し、その文書のどこからでも使える。
- 定義を消したら、使っていた場所が「未定義」として分かる（黙って古い定義が残らない）。
- 定義がどこにあるか見つけやすい（文書の先頭にまとめて書けるなど）。
- 持ち出した先で、定義そのものが文字として残る。

## やらないこと

- 引数つきマクロ（`\newcommand{\abs}[1]{|#1|}`）。まず引数なしで様子を見る。
- 複数文書で共有するマクロ集。[0004](0004-multi-document.md) の後。

## メモ

- KaTeXの `macros` オプションに渡す形が素直（描画のたびに同じ辞書を渡せば、
  グローバル状態に頼らずに済む）。0047を直すときの設計と直結するので、
  **0047を先に片付けてから、その上に機能として載せる**のがよい。
- 定義の書き場所は、文書先頭の専用ブロック（` ```macros `）か、
  ふつうの数式の中の `\newcommand` を拾うか。仕様で決める。
- 数式のキャッシュ（`renderMarkdown.ts`）はLaTeX文字列をキーにしている。
  マクロが変われば同じ文字列でも結果が変わるので、キーにマクロ定義を
  含める必要がある。
