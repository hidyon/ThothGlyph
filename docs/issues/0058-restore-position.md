# 0058: リロードすると、見ていた位置とカーソルが先頭に戻る

- 状態: open
- 起票日: 2026-09-21

## 背景

[0001](0001-autosave.md) で編集内容は復元されるようになったが、復元されるのは
本文だけで、スクロール位置とカーソル位置は先頭に戻る。長い文書では
リロードのたびに「どこまで書いたか」を探し直すことになる。

現状の保存内容は `matheditor:document:v1` の
`{ version, source, savedAt }` の3つだけで、位置に関するものは何も持っていない
（`src/lib/documentStorage.ts` を確認）。

もとは [0010](0010-scroll-sync.md)（スクロール同期）に同梱されていたが、
0010を同期だけに絞ったときに切り出した（2026-09-21）。

## やりたいこと

- リロードしても、直前にエディタで見ていた位置から再開できる。
- リロードしても、直前のカーソル位置から打ち始められる。
- プレビューもその位置に合っている（0010の同期に任せる）。

## やらないこと

- スクロールの同期そのもの（[0010](0010-scroll-sync.md)）。本issueは0010が
  入ったあとに乗る。位置を「行番号」で持つには、行とy座標の対応づけ
  （0010で入る `data-line` とミラー）が要る。
- 複数文書それぞれの位置の保存（[0004](0004-multi-document.md)）。

## メモ

- 保存先は `matheditor:document:v1` を**版を上げずに任意フィールドで拡張する**
  のが自然（版を上げると、版違いを「保存なし」として捨てる現在の読み込みに
  引っかかり、既存の利用者の本文が消える）。仕様で確定すること。
- スクロールしただけで「保存中…」が点滅しないこと。保存の表示の意味が薄れる。
  既存の `autosave` 区分15件に影響しないかを見ること。
- 位置は**ピクセルではなく行**で持つと、次に開いたときの画面幅が違っても
  同じ段落に戻る（0057で幅が可変になったので、なおさら効く）。
