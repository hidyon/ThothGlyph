# 0085: 式の番号と参照の古い書き方を落とす

- 状態: open
- 起票日: 2026-09-22

## 背景

[0083](0083-crossref-dialect.md) で、式のラベルと参照をQuartoの綴り
（`$$ … $$ {#eq-名前}` と `@eq-名前`）へ移した。そのとき
**古い書き方（[0044](0044-equation-numbers.md) の `\tag{名前}` と
`[(1)](#eq-名前)`）も読めるまま**にしてある。

書き方が2通りあると、

- 手本（サンプル文書・算式記載ガイド）は新記法だけなのに、実装とテストは
  2通りを抱える（`renderMarkdown.ts` に `TAG_PATTERN` と `REF_PATTERN`、
  単体テストに旧記法ぶん、実機検証 `eq-number` 区分にも旧記法のチェック）。
- 「古い書き方も読める」という説明を、README・機能仕様・ガイドの3か所に置くことになる。

**落とすと決めた**（2026-09-22、ユーザー）。READMEの一文は
[0084](0084-readme-nonstandard.md) で先に消した。

## やりたいこと

`\tag{名前}` と `[(1)](#eq-名前)` を、**採番と参照の記法として扱うのをやめる**。
残すのは方言（`{#eq-名前}` と `@eq-名前`）だけにする。

## やらないこと

- 方言の記法そのものの変更。[0083](0083-crossref-dialect.md) で決めたまま。
- 書き出し時の番号の焼き込み（[0082](0082-bake-equation-numbers.md)）。

## 決めておくこと（仕様で扱う）

1. **`\tag{名前}` をどう扱うか。** いまはLaTeXから外して番号に置き換えている。
   扱いをやめると、**KaTeX自身が `\tag` を描く**（式の右に `(名前)`）。
   0044はこれを避けるために外していた —— KaTeXの `\tag` は
   `mtable width="100%"` を作り、**幅360pxで式と番号が重なって読めなくなる**
   （0044で実測）。次のどれかを選ぶ。
   - **KaTeXに任せる**（標準のLaTeXの振る舞い。狭い画面で重なる問題が戻る）
   - 外し続けるが番号は振らない（**書いたラベルが黙って消える**。よくない）
2. **`[(1)](#eq-名前)` をどう扱うか。** 扱いをやめると、ただのリンクとして
   描かれる。飛び先 `#eq-名前` は存在しない（idは `eq-番号`）ので**飛べない**。
   文字はそのまま残るので、壊れた表示にはならない。
3. **いま旧記法で書かれた文書をどうするか。** 保存はブラウザの中にあり、
   こちらからは直せない。**移行を促す表示を出すか、黙って変わるか。**

## メモ

- 触る範囲の実測（2026-09-22）: `renderMarkdown.ts` の該当箇所19行、
  単体テスト29件が `tag` に触れ、`verify-ui.mjs` に旧記法のチェック8か所。
  文書は要求・機能・アーキテクチャ・テストの4つと、ガイド（`guideDocument.ts`）。
- **0044の仕様（`docs/specs/0044-equation-numbers.md`）は消さない。** 過去の
  変更の記録なので、そのまま残す。「現在の姿」を書いた4文書のほうを直す。
- `\tag` はパレットから入れる案（[0077](0077-palette-tag.md)）がopenのまま。
  **このissueが先に入るなら0077は方言のラベルを入れる話に変わる**ので、
  0077の背景も直すこと。
