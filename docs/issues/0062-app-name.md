# 0062: アプリに名前がない

- 状態: open
- 起票日: 2026-09-21

## 背景

このアプリは `matheditor`（数式エディタ）と名乗っている。これは名前ではなく
種別の説明で、同じ説明が当てはまる道具は他にいくつもある。

現状、この文字列は次の8か所に出ている（2026-09-21 時点で実際に確認した）。

| 場所 | 現在の値 |
|---|---|
| `index.html:15` | `<title>matheditor</title>` |
| `src/components/Toolbar.tsx:89` | `<h1 className="toolbar__title">matheditor</h1>`（画面に出る） |
| `package.json:2` | `"name": "matheditor"` |
| `public/manifest.webmanifest:2,3` | `name` / `short_name` |

| `README.md:3` | `# matheditor` |

`scripts/verify-ui.mjs`、`scripts/make-screenshots.mjs`、`index.html` の
初期化スクリプトにも直接書かれている。

## やりたいこと

**名前は `cuneus`（クネウス）に決まった。** 由来は下の「名前の由来」。
次の状態になれば解決したと言える。

- 画面・タブ・インストール時の表示が `cuneus` になっている。
- `README.md` と `docs/requirements.md` に名前と由来が書かれている。
- 名前の表記規則（小文字のみ・日本語表記）が文書にあり、それに反する表記がない。

**localStorage のキーを変えるかどうかは、この issue の仕様で決める。**
変えると既存利用者の文書・テーマ・言語・ペイン幅が読めなくなる。移行するか、
`matheditor:` のまま据え置くか、どちらかを選んで理由を仕様に書く。

## やらないこと

- ロゴやアイコンの図柄の変更。アイコンは [0019](0019-app-icon.md) で
  受け入れ基準（白インク量・実効線幅）まで決めてあり、名前とは別の論点。
- ドメインの取得や公開。

## 名前の由来

**cuneus** はラテン語で「楔（くさび）」。

- **楔形文字 `cuneiform` の語源**（cuneus + forma ＝ 楔の形）。楔形文字は、
  葦の茎の先を粘土板に押し当てて刻む。cuneus は**刻まれる形そのもの**であり、
  同時に刻むための道具の名でもある。
- **人類が最初に数式を書きつけた場所が粘土板だった。** イェール大学蔵の
  **YBC 7289**（前1800年頃）には正方形の対角線と √2 の近似値
  1;24,51,10（60進法、誤差100万分の1以下）が刻まれ、コロンビア大学蔵の
  **Plimpton 322** にはピタゴラス数の表が並ぶ。このアプリの遠い祖先にあたる。
- **記号を選んで打ち込む操作**が、楔を粘土に打ち込む動作に重なる。
  パレットから記号を選ぶという、このアプリの中心的な操作の比喩になっている。
- **書いたものは持ち出して使う**（[要求仕様 1](../requirements.md#1-誰のための道具か)）。
  粘土板もその場で書いて運ぶものだった。

表記は**小文字のみの `cuneus`**。文頭でも大文字にしない。日本語表記は
**クネウス**。

## メモ

- 名前を決めるにあたり28語の空き状況を調べた。`Graphion`・`Grafio`・`Caret`・
  `Pilcrow`・`Tilde`・`Galley`・`Organon`・`Lemma` などは、いずれも実在の
  ソフトウェア製品や企業が使っている（`Caret`・`Pilcrow`・`Tilde`・`Galley` は
  **実在のMarkdownエディタ／テキストエディタ**）。`cuneus` はソフトウェア領域に
  衝突がなく、ヒットするのは海運のクルー派遣会社と英国の登記会社のみ。
- ツールバーの `<h1>` は画面に出るので、**仕様では新旧の文字列が占める幅を
  測って書くこと**（幅360pxのツールバーは [0033](0033-toolbar-overflow-phone.md)
  で溢れた経緯がある）。`cuneus` は `matheditor` より短いので余白は増える側だが、
  数値は測って残す。
