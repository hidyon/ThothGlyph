# 0062: アプリに名前がない

- 状態: closed
- 起票日: 2026-09-21

## 背景

このアプリは `matheditor`（数式エディタ）と名乗っている。これは名前ではなく
種別の説明で、同じ説明が当てはまる道具は他にいくつもある。

現状、この文字列は次の8か所に出ている（2026-09-21 時点で実際に確認した）。

| 場所 | 現在の値 |
|---|---|
| `index.html:15` | `<title>matheditor</title>` |
| `src/components/Toolbar.tsx:89` | `<h1 className="toolbar__title">matheditor</h1>`（画面に出る） |
| `package.json:2` | `"name": "matheditor"` |
| `public/manifest.webmanifest:2,3` | `name` / `short_name` |
| `public/favicon.svg:1,2` | `aria-label` / `<title>` |
| localStorage のキー接頭辞 | `matheditor:document:v1` / `:theme:v1` / `:lang:v1` / `:panes:v1` |
| `README.md:3` | `# matheditor` |
| `CLAUDE.md:3` | `# matheditor` |

localStorage のキーは、実装（`src/lib/` の4ファイル）のほかに単体テスト4件、
`scripts/verify-ui.mjs`、`scripts/make-screenshots.mjs`、`index.html` の
初期化スクリプトにも直接書かれている。

## やりたいこと

**名前は `ThothGlyph`（トトグリフ）に決まった。** 由来は下の「名前の由来」。
次の状態になれば解決したと言える。

- 画面・タブ・インストール時の表示が `ThothGlyph` になっている。
- `README.md` と `docs/requirements.md` に名前と由来が書かれている。
- 名前の表記規則（小文字のみ・日本語表記）が文書にあり、それに反する表記がない。

**localStorage のキーを変えるかどうかは、この issue の仕様で決める。**
変えると既存利用者の文書・テーマ・言語・ペイン幅が読めなくなる。移行するか、
`matheditor:` のまま据え置くか、どちらかを選んで理由を仕様に書く。

## やらないこと

- ロゴやアイコンの図柄の変更。アイコンは [0019](0019-app-icon.md) で
  受け入れ基準（白インク量・実効線幅）まで決めてあり、名前とは別の論点。
- ドメインの取得や公開。

## 名前の由来

**ThothGlyph** は **Thoth**（トト）と **glyph**（グリフ）を合わせた名前。

- **トト**はエジプト神話の神で、**文字を発明したとされる書記の守護神**であり、
  同時に**計算・測量・暦の神**でもある。月の満ち欠けを数えて時を刻み、
  神々の裁きを書き留める。プラトン『パイドロス』にも、文字を発明して王に
  献じた「テウト」として登場する。**書くことと数えることが一柱に同居している**
  ところが、この道具の2つの側面と重なる。
- **glyph** は字形・記号そのもの。語源はギリシャ語 γλύφω（gluphō ＝ 刻む）で、
  **刻まれた記号**を指す。トトが与えたとされる聖刻文字は、エジプト語で
  medu netjer ＝「神の言葉」という。
- 数式も記号の体系であり、**書くことと数えることが交わるところ**にある。
  このエディタで利用者がしているのは、パレットからグリフを選んで並べること
  （記号102個・公式60件）。名前はその操作をそのまま指している。

表記は **`ThothGlyph`**（`T` と `G` が大文字）。日本語表記は**トトグリフ**。
npmのパッケージ名とlocalStorageのキーだけは、大文字が使えないので
小文字の `thothglyph`。

## メモ

- 名前を決めるにあたり、**35語ほどの空き状況を調べた**。意味が良くて短い語は
  ほぼすべて先客がいる。とくに**書くことに関わる語はエディタ作者が真っ先に使う**
  ため激戦で、`Caret`・`Pilcrow`・`Tilde`・`Galley`・`Grafio`・`ThothPad` は
  いずれも実在のエディタ名だった（`thoth-note` は crates.io にある Rust 製の
  ターミナルMarkdownノート）。`Organon` は製薬大手、`Graphion` は
  クラウドセキュリティ製品の商標。
- **`ThothGlyph` はソフトウェア領域に衝突がない**（2026-09-21 時点）。
  `Thoth` 単体・`ThothPad`・`Djehuty`（トトのエジプト語名）はいずれも
  使われていたが、`Glyph` と組んだ形は空いていた。
- ツールバーの `<h1>` は画面に出るので、**仕様では新旧の文字列が占める幅を
  測って書くこと**（幅360pxのツールバーは [0033](0033-toolbar-overflow-phone.md)
  で溢れた経緯がある）。実測では `matheditor` 102.4px → `ThothGlyph` 105.8px で
  **3.4px広くなる**が、名前が表示される最小の幅721pxでも横スクロールは出ていない
  （[仕様](../specs/0062-app-name.md#2-画面とメタデータ)）。
