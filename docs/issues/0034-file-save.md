# 0034: .mdファイルの書き出し

- 状態: open
- 起票日: 2026-09-20

## 背景

[0012](0012-file-io.md) は「.mdの書き出しと読み込み」として起票したが、
ツールバーに足せる余地が幅360pxに無く（[0033](0033-toolbar-overflow-phone.md) の
実測で4ボタンの右端が350px、右のpaddingを使い切っている）、2つ同時に足すと
置き場所の検討が二重になる。読み込みを0012に残し、書き出しをこのissueへ分けた。

いま文書を持ち出す手段はクリップボードへのコピーだけで、貼り付け先を
開いていない場面では使えない。

## やりたいこと

- 編集中の文書を `.md` ファイルとしてダウンロードできる。

## やらないこと

- File System Access API による「上書き保存」。対応ブラウザが限られる。
  まずダウンロードで足りるか見る。
- `.md` 以外の形式（HTML、PDF）。0003・[0013](0013-print-style.md) が扱う。
- 複数文書をまとめて書き出すこと（[0004](0004-multi-document.md)）。

## メモ

- ファイル名をどう決めるか（先頭の見出しから作る？ 固定？）を仕様で決めること。
- 置き場所は0012（読み込み）で決めたところに揃えるのが素直。
  0012を先にやると、このissueは同じ場所へ1つ足すだけになる。
