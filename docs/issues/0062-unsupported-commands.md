# 0062: KaTeXが対応していないコマンドが、エラーとして扱われないまま本文に混ざる

- 状態: open
- 起票日: 2026-09-21

## 背景

教科書や証明集から式を持ち込むと、KaTeXが実装していないLaTeXコマンドが必ず混ざる。
そのとき**アプリは壊れたことを検知できず、書き手にも壊れたと分からない**。

実在の数式ノート（多変量正規分布と重回帰、ブロック数式112個）で試したところ、
`\label` が112個・`\eqref` が44個の**合計156箇所**が該当した。

### 壊れ方が3種類ある

`renderMarkdown` に入れて、`katex-error` クラスの有無とエラー色
（`#dc2626`）の有無で分けた実測:

| 入力 | `katex-error` | 赤字 | 画面に出る文字 |
|---|---|---|---|
| `$\frac{$`（括弧が閉じない） | **つく** | あり | `\frac{` |
| `$\begin{nosuch} a \end{nosuch}$` | **つく** | あり | `\begin{nosuch}a\end{nosuch}` |
| `$\label{eq:a} a = b$` | **つかない** | あり | `\labeleq:aa=b` |
| `$x = \eqref{eq:a}$` | **つかない** | あり | `x=\eqrefeq:a` |
| `$x = \ref{fig:1}$` | **つかない** | あり | `x=\reffig:1` |
| `$x \cite{knuth}$` | **つかない** | あり | `x\citeknuth` |
| `$\mbox{text}$` | **つかない** | あり | `\mboxtext` |
| `$\bm{x}$` | **つかない** | **なし** | `x`（黙って消える） |
| `$$E = mc^2 \tag{1}$$` | — | なし | 正常（番号が出る） |
| `$$\begin{align} a &= b \end{align}$$` | — | なし | 正常 |

つまり、

1. **壊れた式**（1〜2行目）は `katex-error` が付く。アプリから検知できる。
2. **未対応のコマンド**（3〜7行目）は `katex-error` が付かない。
   コマンド名が赤い文字として描かれ、引数の中身は数式として組まれる
   （`\label{eq:a}` → 赤い「\label」＋ `eq : a`）。**検知できないまま壊れる。**
3. **`\bm`** は赤字にすらならず、**何も起きずに消える**。

### なぜ困るか

- **[0015](0015-error-list.md)（数式エラーの一覧）を作っても拾えない。**
  文書全体を描画して `katex-error` を数えると、156箇所あっても **0件**と出る。
- **色が書き手のタイプミスと同じ。** 赤（`#dc2626`）は「入力途中の壊れたLaTeX」を
  示すための色なので、書き手は「自分が打ち間違えた」のか
  「このアプリが対応していない記法」なのか区別できない。
- 数式の**外**にある `\eqref{...}`（地の文に書かれたもの）は `$...$` の外なので
  KaTeXにも渡らず、LaTeXのソースがそのまま本文に表示される。

## やりたいこと

- 対応していない記法を使ったとき、**書き手がそれと分かる**。
  「壊れている」ではなく「この記法はこのアプリでは使えない」と伝わる。
- アプリがその箇所を**数えられる・場所を示せる**（[0015](0015-error-list.md) が
  その上に乗れる）。
- `\bm` のように**黙って消える**ものが、黙ったままにならない。

## やらないこと

- **対応コマンドを増やすこと自体。** `\label` / `\eqref` を実際に効かせるのは
  [0044](0044-equation-numbers.md)（式番号と参照）、マクロは
  [0046](0046-math-macros.md)。本issueは「使えないと分かる」ところまで。
- KaTeXを別の実装に置き換えること。

## メモ

- 検知の手がかりは2つ。
  - **(a) 出力を見る**: KaTeXの出力に `#dc2626` が現れているのに
    `katex-error` クラスが無い箇所を拾う。実装は小さいが、
    `\bm` のように黙って消えるものは拾えない。
  - **(b) 入力を走査する**: 使えないコマンドの一覧を持ち、`renderToString` の
    前にLaTeXを走査する。**名指しで言える**（「`\eqref` は使えません」）ぶん
    伝わり方がよく、`\bm` も拾える。一覧を保つ手間はかかる。
- KaTeXの「対応していないコマンド」の一覧は公式にある。全部を持つ必要はなく、
  **実際に持ち込まれるもの**（`\label` `\eqref` `\ref` `\cite` `\mbox` `\bm`
  `\newcommand`）から始めれば足りる。
- **`\tag{1}` は動く**（実測）。番号を出す手段はすでにあるので、
  [0044](0044-equation-numbers.md) は `\label`/`\eqref` を `\tag` へ
  読み替える形で組める見込み。[0051](0051-undocumented-syntax.md) が
  「書かれていないのに動く」と指摘している記法の1つでもある。
- **`$\newcommand{\R}{\mathbb{R}} \R$` は `katex-error` が付いた**（実測）。
  [0046](0046-math-macros.md)（自分用のマクロ）に着手するときは、
  `\newcommand` が現状どう扱われるかをここから確かめること。
  [0047](0047-macro-leak.md)（マクロが別の式に漏れる）とあわせて見る。
- 知らせ方は画面に何かを出すことになるので、**仕様の時点で幅360pxで測る**。
