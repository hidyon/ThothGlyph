# 0044: 式に番号を振って参照できない

- 状態: open
- 起票日: 2026-09-20

## 背景

ノートでは「式(1)を(2)へ代入すると」のように式を番号で指す。
KaTeXの `\tag{1}` は**このエディタでも効く**ので、手で番号を振ることはできる。

```
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \tag{1}
$$
```

ただし手で振った番号は、**式を1つ挿入しただけで全部ずれる**。
参照のほうも `(1)` と書いた文字列でしかないので、飛べないし、ずれても気づかない。

## やりたいこと

- ブロック数式に番号が自動で振られる（書いた順に1から）。
- 本文からその番号を参照でき、式を足し引きしても番号と参照が揃ったままになる。
- 参照をたどって式の位置へ移動できる。
- 番号を振りたくない式は振らずに済む。

## やらないこと

- 章ごとの番号（`(2.1)`）。まず通し番号で。
- 定理・図表の番号。[0041](0041-theorem-blocks.md) を入れてから合わせて考える。

## メモ

- 記法は **[R7](../requirements.md#r7-markdownとして正しく扱える) の方針**に従う。
  `$$ ... $$ {#eq:quad}` のような**独自のラベル記法は原則として採らない**。
  すでに標準の道具が2つある:
  - 番号は LaTeX の `\tag{1}`（KaTeXが解釈する。このエディタでも効くことを実測済み）
  - 参照はMarkdownのリンク（`[(1)](#eq-1)`）
  自動採番をこの2つの上にどう載せるかが、このissueの設計の中心になる。
- 番号を振るのは `renderMarkdown` の中（文書全体を見ないと採番できない）。
  数式のキャッシュはLaTeX文字列をキーにしているので、**同じ式が別の番号になる**
  ケースでキャッシュが効かなくなる。キーに番号を含めるなどの手当てが要る。
- 参照のリンク先はプレビュー内のアンカー。[0020](0020-preview-click-to-edit.md) と
  同じく「プレビューから位置を指す」仕組みなので、先に0020をやると土台ができる。
