# 0064: パレットの中身が高校数学の範囲しかなく、要求仕様R2を満たしていない

- 状態: closed
- 起票日: 2026-09-21

## 背景

[要求仕様](../requirements.md#1-誰のための道具か)は対象を
**「講義ノート、技術メモ、解説記事」**としていて、高校数学とは書いていない。
[R2](../requirements.md#r2-数式のコマンドを覚えていなくても書ける) は
「`\int` や `\alpha` を覚えていない人でも、記号を選んで挿入できる」と定めている。

しかし**パレットの中身は高校数学の範囲で止まっている**。

### いまの中身（実測）

| 記号パレット | 件数 | 公式 | 件数 |
|---|---|---|---|
| 基本 | 8 | 方程式 / 三角比 / 三角関数 | 各5 |
| ギリシャ小文字 | 31 | 指数・対数 / 数列 / 微分・積分 | 各5 |
| ギリシャ大文字 | 24 | ベクトル / 図形と方程式 | 各5 |
| 演算子 | 12 | **確率・統計** | 5 |
| 関係子 | 14 | 複素数 / 微分・積分（応用） / 極限・不等式 | 各5 |
| 括弧・構造 | 6 | | |
| Markdown | 7 | | |
| **計 102件・7グループ** | | **計 60件・12分類** | |

`確率・統計` の5件は 順列・組合せ・余事象・条件付き確率・期待値。
条件付き確率は **`P_A(B)`**（高校の記法）で、`P(B \mid A)` ではない。
**分布（正規・二項・カイ二乗）は1件もなく、線形代数・行列の分類自体がない。**

### 実際に書けなかったもの

CC BY-SA の統計の証明集から10ページ相当の覚書（多変量正規分布と重回帰、
ブロック数式112個）を組み、このアプリで書き通したときに、
**常用する記号を検索して1件も出なかったもの**:

| 要るもの | 使う場面 | パレットの検索結果 |
|---|---|---|
| `\sim` | $\varepsilon \sim \mathcal{N}(0, \sigma^2)$ の「〜に従う」 | 0件 |
| `\mathcal` | $\mathcal{N}$（正規分布） | 0件 |
| `\mathrm` / `\text` | $\mathrm{E}(X)$、$X^{\mathrm{T}}$ の立体 | 0件 |
| `\top` | $X^\top$（転置） | 0件 |
| `\mid` | $p(x_1 \mid x_2)$（条件付き） | 0件 |
| `\tilde` | $\tilde\beta$（`\hat` `\bar` `\vec` はある） | 0件 |
| `\overset` | 等号の上に根拠を書く | 0件 |
| `bmatrix` | 角括弧の行列（`pmatrix` はある） | 0件 |

語で引いても出ない。**「正規分布」0件、「転置」0件。**

## やりたいこと

- 大学初年度の講義ノート（統計・線形代数）を書くときに、常用する記号を
  **覚えていなくても選んで入れられる**。R2 が対象読者の範囲で満たされる。
- 語で引ける。「転置」「正規分布」と打てば当たる。
- 足しても**狭い画面が悪くならない**（[0032](0032-palette-height-narrow.md) の蓋を割らない）。

## やらないこと

- **高校数学の記号を減らすこと。** 足すだけで、既存の102件・60件は動かさない。
- **分野を無制限に広げること。** 物理の単位、化学式、音楽記号などは入れない。
  どこまでを範囲にするかは仕様で決める。
- **記法そのものの追加**（式番号は [0044](0044-equation-numbers.md)、
  未対応コマンドの知らせ方は [0063](0063-unsupported-commands.md)）。
- **サンプル文書を変えること。** いまの二次方程式は初回訪問の案内を兼ねていて、
  実機検証の複数の区分が先頭行 `# 二次方程式の解の公式` に依存している。
  変えるなら別issue。
- **要求仕様の書き換え。** 対象読者はもともと「講義ノート、技術メモ、解説記事」
  なので、直すところがない。

## メモ

- 範囲の候補（仕様で絞る）:
  - **装飾**: `\mathcal` `\mathbb` `\mathrm` `\text` `\tilde` `\overset` `\underset`
  - **統計**: `\sim` `\mid` 分布・期待値・分散・共分散
  - **線形代数**: `\top` 転置・逆行列・行列式・ノルム・内積・`bmatrix`
  - **集合・論理**: `\in` `\subset` `\forall` `\exists`（関係子14件に何があるか要確認）
- **READMEの件数は単体テストで固定されている**（記号7グループ102件・
  公式12分類60件）。足すと `npm test` が落ちるので、READMEの数字も同じコミットで直す
  （[0035](0035-readme-for-users.md)）。
- **i18nは1行に両方書くだけでよい**（`t('平方根', 'Square root')`。[0031](0031-english-ui.md)）。
- **`palette.test.ts` がパレット全件のLaTeXをKaTeXで描画して確かめている。**
  足した分も自動で対象になるので、描けない記号は入れた時点で落ちる。
- 高さの制約は2つ既にある。**幅720px以下は上限つき**（0032）、
  **幅1200px以上は左の縦帯180px**（[0054](0054-palette-placement.md)）。
  縦帯は公式タブですでに縦スクロールしているので、**件数を増やすと
  スクロールが伸びる**。仕様の時点で幅1440pxと幅360pxで測ること。
- **検索（[0011](0011-palette-search.md)）があるので件数が増えても引ける。**
  ただし引けるのはコマンド名・日英の名前・labelなので、
  **「正規分布」で当てたいなら名前にその語を入れること。**
- `\mathrm{T}` と `\top` のように**同じ用途で書き方が複数ある**ものは、
  どちらを入れるか決めて片方にする（両方入れると選ぶ側が迷う）。
