# 0070: 2文字以上に掛かる上飾りがなく、装飾が2グループに散っている

- 状態: open
- 起票日: 2026-09-21

## 背景

[0068](0068-palette-decorations.md) で装飾・書体を11件足したが、**上飾りは
1文字に掛かるものだけ**で、2文字以上に掛かるものが1件もない。

### いまある装飾（実測）

| グループ | 装飾 |
|---|---|
| 基本（8件中3件） | `\bar{x}` `\vec{v}` `\hat{x}` |
| 括弧・構造（17件中6件） | `\tilde{x}` `\dot{x}` `\ddot{x}` `\overset{a}{=}` `\underset{a}{=}` `\underbrace{x}_{a}` |

**装飾が2つのグループに散っている。** 0068で括弧・構造に置いたのは、
基本が8件でちょうど1行の端にいて、1件でも足すと読み込み中だけ41px飛ぶため
（[0068の仕様](../specs/0068-palette-decorations.md#基本タブに足せない理由測って分かったこと)）。
**置きたい場所ではなく、置ける場所に置いた**形になっている。

### 引けないもの（`searchPalette` で実測）

| 語 | 検索結果 |
|---|---|
| `widehat` / `広いチルダ` / `widetilde` | いずれも**0件** |
| `線分` | **0件**（`\overline{AB}` を引く手段がない） |
| `下線` / `underline` | いずれも**0件** |
| `上の波括弧` / `overbrace` | いずれも**0件**（`\underbrace` は0068で入ったが対になる上側がない） |
| `幾何のベクトル` / `overrightarrow` | いずれも**0件** |
| `アクセント` / `check` | いずれも**0件** |
| `角` | 6件当たるが**すべて公式**（2倍角・半角など）。**記号は0件** |

$\widehat{ABC}$（角）と $\overrightarrow{AB}$（幾何のベクトル）は
高校数学の図形の範囲でも常用するのに、`\hat` `\vec` では**1文字分しか掛からない**。

## やりたいこと

- **2文字以上に掛かる上飾り**を、覚えていなくても選んで入れられる。
  「角」「線分」「下線」と打てば当たる。
- **装飾が1か所にまとまっている。** `\bar` `\vec` `\hat` の隣に
  `\widehat` `\overrightarrow` が並び、装飾を探すときに1つのタブで足りる。

## やらないこと

- **記号の新しいタブを作ること。** 0064の実測どおり、タブ1つで検索欄が
  2行目に落ち始める幅が上がる（日本語944→1007px）。落ちると横帯で+34px。
- **グループ名を変えること。** 0068で測ったとおり、`括弧・構造` を
  `括弧・装飾・構造` へ改名すると英語で横帯の全幅で検索欄が2行目に落ちる。
- **書体を動かすこと。** `\mathcal` `\mathbb` `\mathrm` `\mathbf` `\text` は
  「中身を決める入れ物」で、装飾とは別の系統。括弧・構造に残す。
- **囲み・打ち消し（`\boxed` `\cancel`）と大きさ・間隔（`\displaystyle` `\quad`）。**
  必要になったら別issueで足す。
- **線形代数**（[0067](0067-palette-linear-algebra.md)）。

## メモ

- 候補: `\widehat{ABC}`（角）・`\widetilde{x}`・`\overrightarrow{AB}`（幾何のベクトル）・
  `\underline{x}`（下線）・`\overbrace{x}^{a}`（上の波括弧）・
  `\check{x}` `\breve{x}` `\acute{x}` `\grave{x}`（アクセント）。
- **`\overline` は演算子グループにある**（0064で「上線（標本平均・補集合）」として
  入れた）。線分 $\overline{AB}$ は同じコマンドなので、**2か所に置かない**
  （0068で同じ理由で `\overline` の重複を却下した）。tooltipに「線分」を足して
  引けるようにする手がある。
- **置き場所は「基本に集める」方針で決まっている**（0068の実測で、基本は
  **8件のままか19件まで増やすかの二択**。9〜13件では読み込み中だけ41px飛ぶ）。
  括弧・構造から装飾6件を移し、上飾りを足して**19件以上**にすれば飛びは消える。
  代価は初期表示のタブが**幅900pxで+53px・幅600pxで+41px**。この交換は合意済み。
- **移す前に、飛びが消える件数を測り直すこと。** 0068で測った「19件で消える」は
  装飾6件＋書体5件の組み合わせでの値で、**ラベルの文字数が違えば境目も動く**
  （`\overrightarrow{AB}` は20文字で、いま最も長いラベルより長い）。
- **0068の `palette-decor` 区分は括弧・構造の寸法と「先頭がチルダ」を見ている。**
  装飾を移すと落ちるので、同じコミットで直すこと。
- READMEの件数（記号141個）は単体テストで固定されている。
- 追加するLaTeXは仕様の時点で `katex.renderToString` に `throwOnError: true` で
  通すこと（0064・0068でそうした。**挿入直後の「中身が空」の形も確かめる**）。
