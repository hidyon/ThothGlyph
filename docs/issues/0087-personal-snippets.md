# 0087: 自分用の定型を登録して再利用できない

- 状態: implemented
- 起票日: 2026-09-22

## 背景

パレットには共通の記号・公式があるが、書き手が繰り返し使うものは人によって違う。たとえば講義ノートの定義の枠、よく使う行列、証明の書き出し、研究固有の記号を含む説明は、毎回ソースを探してコピーするか打ち直す必要がある。

クリップボードは次に使うまで内容を保てず、リロード後や別のノートで使い直せない。数式マクロ（[0046](0046-math-macros.md)）は数式のコマンドを短く書く機能であり、文章・見出し・複数行の数式を含むMarkdown全体を再利用する用途とは異なる。

## やりたいこと

- 利用者が選んだMarkdownを名前つきの自分用スニペットとして登録できる。
- 登録したスニペットを、今後の訪問でも一覧から選んでカーソル位置へ入れられる。
- スニペットの名前と内容を変更・削除できる。
- 数式だけでなく、文章・見出し・箇条書き・複数行のブロック数式を含むMarkdownを扱える。
- 空のときは、画面を占有する領域や空の一覧を出さない。

## やらないこと

- 数式の展開規則を定義するマクロ機能（[0046](0046-math-macros.md)）。
- 複数のノートや利用者の間でスニペットを同期・共有すること。
- あらかじめ用意する公式や記号の追加（[0067](0067-palette-linear-algebra.md)など）。
- スニペットを文書ごとに分けて持つこと。複数文書の保存形式は[0004](0004-multi-document.md)で決める。

## メモ

- 自分用スニペットは、数式だけでなくMarkdown全体を入れられるため、既存の`insertSnippet`を再利用できる可能性がある。選択範囲がある場合の挿入規則と、カーソル位置を指定する記号を許すかは仕様で決める。
- 保存先はブラウザ内を前提とし、保存失敗の表示や容量の扱いは自動保存（[0001](0001-autosave.md)）と整合させる。
- パレットへ入口を足す場合、幅・高さは[0086](0086-width-checks-section.md)で作った`width`区分を指定して検証する。
