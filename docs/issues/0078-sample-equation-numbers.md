# 0078: サンプル文書に式の番号と参照が出てこない

- 状態: in-progress
- 起票日: 2026-09-22

## 背景

[0044](0044-equation-numbers.md) で、`\tag{名前}` を書いたブロック数式に番号が
自動で振られ、`[(1)](#eq-名前)` で参照できるようになった。しかし
**サンプル文書（初回訪問で入っている文書）には `\tag` が1つもない**。

サンプル文書は「何ができるかが一目で分かること」を狙って置いてある
（`src/sampleDocument.ts`）。0040でグラフを入れたのも同じ理由で、
パレットに機能があってもサンプルに出てこないと気づかれない。
式の番号と参照は**記法を手で書く前提**（パレットからは入れられない。
[0077](0077-palette-tag.md)）なので、サンプルが唯一の手本になる。

現在のサンプルにはブロック数式が2つあり、どちらも番号を持たない。

## やりたいこと

- サンプル文書のブロック数式に番号が振られていて、本文からその番号で
  参照している箇所がある。
- 日本語版と英語版の両方で同じことができている。
- 文書としての読みやすさを落とさない（番号のための不自然な一文を足さない）。

## やらないこと

- サンプル文書の題材を変えること（0072で正規分布に決めたばかり）。
- 先頭行（`# 正規分布と標本平均`）を変えること。検証9件が依存している。

## メモ

- `src/sampleDocument.ts` の注記のとおり、**中身を変えると検証に波及する**。
  今回効くのは `math-click` の1件（サンプルの2つ目のブロック数式の中身を
  期待している。`\tag` を足すと選ばれる文字列が変わる）。
- **READMEのスクリーンショット3枚を撮り直す**
  （`node scripts/make-screenshots.mjs`）。初期表示が変わるため。
- `verify-file-build.mjs` の「数式16個」は `\tag` を足しても変わらない
  （参照はリンクであって数式ではない）。
