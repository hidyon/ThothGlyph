# 0092: ソースで行番号とシンタックスハイライトを使えない

- 状態: closed
- 起票日: 2026-09-23

## 背景

現在のソースペインは素の `textarea` で、行番号とシンタックスハイライトを表示しない。長いMarkdown文書では、編集箇所の位置を数えにくく、見出し・数式・コードブロック・記法を読み分けるにも時間がかかる。

行番号とハイライトは全員に必要とは限らず、無地の入力欄を好む利用者もいる。そのため、表示するかどうかを利用者が切り替えられる必要がある。

## やりたいこと

ソースペインで行番号とMarkdown・LaTeXのシンタックスハイライトを表示できる。設定からそれぞれをオン／オフでき、選択は次回訪問時にも保たれる。

表示の有無にかかわらず、入力、選択、IME、Undo／Redo、検索・置換、パレットからの挿入、スクロール同期は従来どおり使える。

## やらないこと

WYSIWYG編集、別のコードエディタライブラリの導入、Markdown以外の言語のハイライト、複数文書の管理は扱わない。

## メモ

- 現在の機能仕様では、ソースペインに「行番号、シンタックスハイライト、折り返しの制御は今はない」と記録している。
- 実装前に、表示の方式、設定メニュー内の置き場所、狭い画面での見え方、textareaとの同期方法を仕様として決める。
- UI変更後は、既存の実機検証をメニュー操作と新しいソースペインのDOMに合わせて更新する。
