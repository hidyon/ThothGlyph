# 0090: 設定メニューからREADMEを読めない

- 状態: closed
- 起票日: 2026-09-23

## 背景

READMEには機能、記法、画面例がまとまっているが、アプリを使っている最中はリポジトリを開かないと読めない。設定メニューには表示言語とテーマを置いているため、アプリについて知る入口もここにまとめると見つけやすい。

## やりたいこと

設定メニューの「README」を選ぶと、現在の表示言語のままREADMEをアプリ内で読める。

## やらないこと

READMEの編集、外部サイトへの遷移、README本文からの文書への挿入は扱わない。

## メモ

- 既存の算式記載ガイドと同じく、編集中の文書を変えないモーダルとして表示する。
