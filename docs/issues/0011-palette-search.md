# 0011: 記号パレットの検索

- 状態: open
- 起票日: 2026-09-19

## 背景

パレットはグループのタブで分かれており、目的の記号がどのタブにあるかを
覚えていないと往復することになる。記号を増やすほど（パレットはデータ駆動なので
増やすこと自体は簡単）この問題は悪化する。

## やりたいこと

- 入力欄に打つと、全グループを横断して記号が絞り込まれる。
- `\alpha` のようなコマンド名でも、「積分」のような日本語の名前でも引ける。
- キーボードだけで、絞り込んで選んで挿入まで完結する。

## やらないこと

- 曖昧検索やスコアリング。まず前方一致・部分一致で足りるか見る。

## メモ

- `palette.ts` の `title`（日本語）と `label`（LaTeX）が既に検索対象として使える。
  読み仮名まで要るかは、実際に引いてみて判断する。
- 検索中はタブの選択状態をどう見せるかを決めること（全グループ横断なので、
  いまのタブUIと素直には両立しない）。
