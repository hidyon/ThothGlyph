# 0038: グラフにデータ系列を描く

- 状態: open
- 起票日: 2026-09-20

## 背景

[0037](0037-graph.md) で ` ```graph ` ブロックに関数を描けるようにするが、
描けるのは `y = f(x)` だけで、**数値の並び**は描けない。

実測値に近似曲線を重ねる、数列の項を点で打つ、といった説明は
関数だけでは書けない。0037で土台（式の評価・SVG描画・パイプラインへの接続）が
できたあと、その上に足すのが安い。

## やりたいこと

- 数値の組を並べて、点または折れ線として描ける。
- 同じブロックの中で、関数と数値の並びを重ねられる。
- 複数の系列を見分けられる（色・点の形・凡例）。

## やらないこと

- 棒グラフ・円グラフ。数式を書く道具の主用途ではない。
- CSVなど外部ファイルからの読み込み。まずブロックに直接書く形で使ってみる。

## メモ

- 記法の案（0037の記法に足す形）:

  ````
  ```graph
  y = x^2
  points: (0,0) (1,1) (2,4) (3,9)
  ```
  ````

- 関数は連続、データは離散なので、**x軸の目盛りをどちらに合わせるか**が
  0037にはない判断になる。データの範囲が `x:` の指定とずれたときの扱いも決める。
- 凡例をどこに置くか。幅360pxで凡例がグラフを潰さないか測ること。
- 0037を実際に使ってから仕様を書く。使わないまま足すと、要らない自由度が残る。
