# 0030: 公式をさらに30件追加する

- 状態: closed
- 起票日: 2026-09-19

## 背景

[0018](0018-formula-library.md) で公式パレットを入れ、高校数学までの
6分類30件を収録した（方程式・三角比・三角関数・指数対数・数列・微分積分）。

実際に使ってみると、**高校数学の範囲でも入っていない領域がある**。
ベクトル、図形と方程式、確率・統計、複素数は1件も入っていない。
微分・積分も5件では基本形しかなく、置換積分や部分積分がない。

0018の仕様は「この一覧が仕様であり、増減は別issueにする」としたので、
その別issueにあたる。

## やりたいこと

- 高校数学で使う公式が、いまより広くカバーされる（合計60件程度）。
- 分類が増えても、目的の公式にたどり着ける。
- 追加した公式も、既存の30件と同じ基準を満たす
  （KaTeXでエラーにならない、`%CURSOR%` をちょうど1つ持つ、名前が重複しない）。

## やらないこと

- 大学以降の数学。0018の「やらないこと」を引き継ぐ。
- 公式の説明文（どんなときに使うか）を出すこと。
- 利用者による公式の登録。

## メモ

- 追加の候補（各5件で6分類なら30件）:
  - **ベクトル**: 内積、なす角、成分表示の大きさ、平行条件、分点公式
  - **図形と方程式**: 2点間の距離、点と直線の距離、円の方程式、
    直線の方程式（傾きと1点）、内分点
  - **確率・統計**: 順列、組合せ、余事象、条件付き確率、期待値
  - **複素数**: 絶対値、共役、極形式、ド・モアブルの定理、和と積の共役
  - **微分・積分（追加）**: 商の微分、合成関数の微分、部分積分、置換積分、体積
  - **極限・その他**: sinx/x の極限、eの定義、二項定理、相加相乗平均、
    絶対値の不等式
- **分類が12個になると2段目のタブが1行に収まらない可能性がある。**
  0018の実測では、幅600pxで6個は1行に収まっていた。12個で折り返るかは未確認。
  折り返ること自体は既存の `flex-wrap` の挙動どおりだが、見え方を確かめること。
- テストは0018で作った全件走査（`formulas.test.ts`）がそのまま効く。
  件数の期待値（30件・6分類・各5件）を直すこと。
- どの公式を入れるかは好みが入る。**一覧を仕様に書いて合意してから実装する**のは
  0018と同じ進め方でよい。
