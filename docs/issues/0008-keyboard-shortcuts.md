# 0008: キーボードショートカット

- 状態: open
- 起票日: 2026-09-19

## 背景

エディタは素の `<textarea>` なので、Tabキーを押すとフォーカスが次の要素へ移る。
数式や箇条書きのインデントが打てない。数式を囲む `$` も毎回手で2つ打っている。
パレットはマウスへ手を移す必要があり、打鍵の流れが切れる。

## やりたいこと

- Tabでインデントが入り、Shift+Tabで戻せる（フォーカス移動に取られない）。
- 選択範囲を `$...$` / `$$...$$` で囲むショートカットがある。
- Markdownコピーがキーボードから実行できる。
- どのキーで何ができるかが画面から分かる（一覧を出す手段がある）。

## やらないこと

- キーバインドのカスタマイズ。まず固定のセットで使ってみる。
- Vim/Emacsキーバインド。

## メモ

- Tabをエディタで捕まえるとキーボード操作の人がtextareaから出られなくなる。
  Escでフォーカスを逃がすなどの退路を仕様で決めること（アクセシビリティ）。
- 選択範囲を囲む挙動は [0009](0009-wrap-selection.md) と実装が重なる。
  同時にやるか、0009を先にやってその上に乗せるか、仕様で決める。
- ブラウザやOSが既に使っているキーを避けること（Ctrl+T、Ctrl+W など）。
