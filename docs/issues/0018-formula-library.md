# 0018: 有名な公式を選んで挿入する

- 状態: closed
- 起票日: 2026-09-19

## 背景

パレットは**記号**を1つずつ挿入する道具で、62件すべてが記号かMarkdownの
囲みである。一方、実際に書きたいのは「解の公式」「余弦定理」「加法定理」
といった**式のかたまり**であることが多い。

いまはそれを1記号ずつ組み立てるしかない。サンプル文書の解の公式
`x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}` は、パレットだけで作ると
10回以上の打鍵になる。覚えていない人ほど組み立てられない、という
[R2](../requirements.md)（コマンドを覚えていなくても書ける）の穴になっている。

## やりたいこと

- 高校数学までの範囲の有名な公式を、名前で選んで挿入できる。
- 挿入されるのは完成したLaTeXで、そのまま正しく描画される。
- どんな式が入るのかを、挿入する前に見て確かめられる。
- 公式の追加が、パレットの記号追加と同じくらい簡単である
  （データに1行足せば済む）。

## やらないこと

- 大学以降の数学。まず高校範囲で、選ぶ単位がうまくいくか見る。
- 公式の検索。[0011](0011-palette-search.md) が記号の検索を扱うので、
  そちらと揃える形になるはず。先に0011をやるか、仕様で決める。
- 利用者が自分の公式を登録すること。まず固定のセットで使ってみる。
- 数値を入れると計算してくれること。これは数式エディタの仕事ではない。

## メモ

- 収録範囲の候補: 二次方程式の解の公式、因数分解・展開の公式、三角比の相互関係、
  加法定理、倍角・半角、正弦定理・余弦定理、指数・対数の法則、数列の和、
  微分・積分の基本公式、順列・組合せ、確率。
- 件数が増えるとパレットのタブに収まらない。パレットに同居させるのか、
  別のUI（ダイアログなど）にするのかを仕様で決めること。
- 挿入後にどこを直したくなるかを考えて `%CURSOR%` を置く。
  [0009](0009-wrap-selection.md) で `%CURSOR%` の有無が挙動を決めると固めたので、
  公式データもその約束に乗る。
- 公式のLaTeXが正しいことをどう保証するか。KaTeXでエラーにならないことを
  単体テストで全件確かめるのが手堅い（`renderMarkdown` を通す）。
