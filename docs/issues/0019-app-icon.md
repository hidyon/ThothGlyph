# 0019: アプリのアイコン

- 状態: open
- 起票日: 2026-09-19

## 背景

`public/favicon.svg` は足場を作ったときのまま、**Claudeのロゴ**（紫の
アスタリスク）が入っている。このアプリのものではない他所のロゴなので、
タブを見てもmatheditorだと分からないし、そもそも掲げるべきものではない。

このアプリは「開きっぱなしにして書く」道具なので、タブの見分けがつかないのは
地味に効く。あわせて `index.html` にはmanifestもapple-touch-iconも無い。

## やりたいこと

- ブラウザのタブとブックマークに、matheditor固有のアイコンが出る。
- ライトでもダークでも潰れて見えない（[0002](0002-dark-mode.md) で
  ダークに対応したので、アイコンも両方で確かめる）。
- ホーム画面に追加したときにも妥当なアイコンが出る。

## やらないこと

- PWA化（オフライン動作、Service Worker）。アイコンとmanifestは重なるが、
  オフラインで動かすことはこのissueでは扱わない。必要なら別issueにする。
- ロゴやブランディングの設計。アプリ名の見せ方やツールバーの意匠は変えない。

## メモ

- SVGで作れば1ファイルで済み、ダークでの見え方も `prefers-color-scheme` で
  切り替えられる。ただしSVG faviconを読まないブラウザがあるので、
  PNGのフォールバックを置くかを仕様で決めること。
- 題材の候補: 数式記号（∑、√、π）、あるいは「左がソース・右がプレビュー」の
  2ペイン構造。文字ベースだと16pxで潰れやすい。
- 画像を足すと「見た目の違和感は目視で判断しない」という検証の約束と相性が悪い。
  何をもって「潰れていない」と判定するかを、受け入れ基準を書くときに決めること。
- 既存の `public/favicon.svg` は48x46のグラデーション付きSVG。差し替えで消す。
- `index.html` の `<html lang="en">` も足場のままだが、これは別の話なので
  ここでは触らない（気になるなら別issue）。
