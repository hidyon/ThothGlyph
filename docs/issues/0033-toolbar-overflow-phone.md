# 0033: 幅414px以下でツールバーのボタンが画面から溢れる

- 状態: open
- 起票日: 2026-09-20

## 背景

[0032](0032-palette-height-narrow.md) の検証中に、幅375px・高さ667pxの
スクリーンショットで「Markdownをコピー」ボタンが右端で切れているのを見つけた。
測った結果（ヘッドレスChromium、日本語表示）:

| 画面幅 | 横スクロールが出るか | コピーボタンの右端 |
|---|---|---|
| 600px | 出ない | 590px（収まっている） |
| 414px | **出る** | 435px |
| 375px | **出る** | 435px |
| 360px | **出る** | 435px |

幅414px以下でツールバーの中身が入りきらず、**ページ全体が横スクロールする**。
ボタンは4つ（言語・テーマ・サンプルに戻す・Markdownをコピー）で、
狭い画面では文字を隠して記号だけ残す作りになっているが、それでも足りない。

[要求仕様](../requirements.md) のN5・N9は**720px以下・600pxで確認**と書いてあり、
600pxまでは満たしている。スマートフォンの実幅（360〜414px）は見ていなかった。

0032はパレットだけを触ったので、この溢れは0032の前からある。

## やりたいこと

- 幅360pxでも、ツールバーのボタンがすべて画面内に収まる。
- ページ全体が横スクロールしない。
- どのボタンも押せる（隠して終わりにしない）。

## やらないこと

- ツールバーのボタンを減らすこと。どれも別々のissueで足したもの。
- パレットの高さ（[0032](0032-palette-height-narrow.md) で扱った）。

## メモ

- 「サンプルに戻す」と「Markdownをコピー」は狭い画面でも文字が出ている
  （`.button__label` を隠すのは言語・テーマだけ）。ここを詰めるのが素直か。
- 要求仕様のN5・N9の基準幅を600pxから見直すかどうかも、このissueで決める。
- 実測は `node scripts/verify-ui.mjs` の `layout` 区分（いまは幅600pxだけ）に足せる。
