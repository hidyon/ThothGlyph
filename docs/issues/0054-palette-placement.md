# 0054: 広い画面でパレットが横を使い切らず、高さだけ取っている

- 状態: closed
- 起票日: 2026-09-20

## 背景

パレットはツールバーの下に横いっぱいの帯として置かれている。狭い画面では
[0032](0032-palette-height-narrow.md) で高さに蓋をしたが、**広い画面では
横が大きく余ったまま、高さを全幅で取り続けている**。

実測（2026-09-20、幅1440×900）:

| | 日本語 | 英語 |
|---|---|---|
| パレットの幅 | 1440px（全幅） | 1440px（全幅） |
| パレットの高さ | 94px | 92px |
| タブ行が実際に使う右端 | 662.1px | 886.9px |
| ボタン行が実際に使う右端 | 400.2px | 400.2px |
| 検索欄 | 1236〜1428px（右寄せ） | 同じ |
| textareaの高さ | 721px | 725px |

`基本` タブのボタン8件は左から400.2pxまでしか使っておらず、
**そこから検索欄の左端（1236px）まで約836pxが空いている**。
いちばん背の高い `公式` タブでも高さは171.9px（幅1440px）で、
その間も横は同じように空く。

つまり広い画面では、**余っているのは横で、削られているのは縦**という形に
なっている。縦は本文（textarea）が使いたい方向である。

## やりたいこと

- 幅の広い画面で、パレットが横の余白を使い、**本文の縦を今より空ける**。
- 幅1440pxで、パレットが本文から奪う高さが現状（94px、公式タブ171.9px）より
  小さくなる。どれだけ小さくなるかを仕様の時点で測って数値で書く。
- 狭い画面（幅720px以下）の見え方は今のまま変えない。
  [0032](0032-palette-height-narrow.md) の蓋（幅360pxで139px）を壊さない。
- 記号を選ぶまでの操作の回数が今より増えない。

## やらないこと

- 狭い画面の作り直し。0032・0033で測って決めた形をそのまま残す。
- パレットの中身（タブの分け方、記号の件数）の変更。
- 置き場所を利用者が選べるようにすること（設定として持たない）。

## メモ

- 案は少なくとも3つある。**仕様の時点で幅1440pxと幅1024pxで測って比べること。**
  - **左の縦帯にする**（広い画面だけ）。縦にタブを並べ、ボタンを縦に流す。
    高さの奪いはゼロになるが、`panes` の横が減るので**プレビューの幅**が
    どれだけ減るかを測る必要がある。
  - **タブ行とボタン行を1行にまとめる**（タブが左、ボタンが右）。
    今の形のまま高さが約半分になる。タブ8つ650.1px＋ボタン400.2pxで
    1050.3pxなので、幅1440pxなら入る見込み（英語は874.9px＋400.2pxで
    1275.1px。検索欄192pxと重なるので要検討）。
  - **ソースペインの中に入れる**。エディタとの距離が縮むが、
    [0043](0043-find-replace.md) の検索バーと
    [0042](0042-outline.md)（目次）と置き場所を奪い合う。
- どの案でも **幅1440pxのREADMEのスクリーンショット2枚を撮り直す**
  （`node scripts/make-screenshots.mjs`）。
- [0053](0053-palette-tab-icons.md)（タブのアイコン）と同じ場所を触る。
  0054を先にやるとタブの並ぶ向きが変わりうるので、**0054 → 0053の順が安い**。
- [0022](0022-narrow-pane-switch.md)（狭い画面でのペイン切り替え）とは
  逆向きの話（あちらは狭い画面）。混同しないこと。
