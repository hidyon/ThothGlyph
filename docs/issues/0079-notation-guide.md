# 0079: 書ける記法とコマンドを、編集中に調べられない

- 状態: closed
- 起票日: 2026-09-22

## 背景

このエディタは「LaTeXのコマンドを知らない人がパレットで入力する」ことを想定して
いる。だがパレットで入るのは**用意した151件（7グループ）と公式75件**だけで、
それ以外を書きたくなったとき、**アプリの中に調べる手段がない**。

- パレットのtooltipは日本語名を出すが、「この記号を出したい」から引ける導線は
  検索欄（[0011](0011-palette-search.md)）だけで、パレットにない記号は出てこない。
- [機能仕様](../functional-spec.md)の「対応する記法」は5行の表で、
  インライン数式・ブロック数式・`graph`・Markdown・改行しか載っていない。
  そもそも文書は `docs/` にあり、**アプリを開いている人の手元にはない**。
- 手本になるのはサンプル文書（`src/sampleDocument.ts`、95行）だけで、
  ここに出てくる記法しか実例がない。しかもサンプルは「サンプルに戻す」で
  呼び戻すもので、**書きかけの文書と入れ替わる**（`App.tsx` の `handleReset`）。

結果として、パレットの外に出た瞬間に手が止まる。

## やりたいこと

**「算式記載ガイド」というMarkdown文書を用意し、アプリからいつでも参照できる
ようにする。** 書きかけの文書を失わずに開けること。

内容は **KaTeXが対応しているコマンド全般**を対象にする。パレットに載せている
ものだけでなく、パレットにない記号・環境・装飾も引けることを狙う。各項目は
**書くコマンドと、それが描かれた姿の両方**が見える形で並べる（コマンド名だけ
並んでいても、知らない人には選べない）。

Markdownの記法（見出し、表、コードブロック、`graph`、`$$`、`\tag` と参照）も
同じガイドに含める。数式だけ分かっても文書は書けない。

## やらないこと

- パレットに項目を足すこと。ガイドは**調べるためのもの**で、挿入の導線を
  増やす話ではない（パレットの拡充は [0067](0067-palette-linear-algebra.md)、
  [0077](0077-palette-tag.md)）。
- 機能仕様とREADMEの記述を実装に合わせること。それは
  [0051](0051-undocumented-syntax.md)。ただし**ガイドに何を載せるかを決めると
  0051の判断（`<details>` などを正式に載せるか）が先に要る**ので、
  仕様を書くときに順序を相談する。
- 未対応コマンドをエラーとして扱うこと。それは [0063](0063-unsupported-commands.md)。

## メモ

- **「KaTeX対応コマンド全般」は件数が多い。** 載せた以上は描かれることを
  保証することになるので、「ガイドに書いたコマンドが実際に描画される」ことを
  機械的に確かめる手段（`renderMarkdown` を通す単体テストなど）を仕様で決める。
  確かめずに載せたコマンドは、[0063](0063-unsupported-commands.md) の
  「エラーにならないまま本文に混ざる」をガイドが増やすことになる。
- 表示のしかた（別ペインか、ダイアログか、文書の切り替えか）は仕様で決める。
  **画面に要素を足すなら、占める幅・高さを仕様の時点で測って書くこと**
  （ツールバーは幅600pxで既に窮屈。[0033](0033-toolbar-overflow-phone.md)）。
- ガイド自身がこのエディタで書かれたMarkdownなら、**書式そのものが実例になる**。
- 英語UIがあるので（[0031](0031-english-ui.md)）、ガイドも2言語ぶん要るかを
  仕様で決める。サンプル文書は `sampleDocument(lang)` で2言語持っている。
