# 0077: パレットから式のラベルと参照を入れられない

- 状態: open
- 起票日: 2026-09-22

## 背景

式に番号を振ると、本文から参照できる。ただし**記法は手で書く前提**で、
パレットにはラベルも参照も入れるボタンが1つもない。

[R2](../requirements.md#r2-数式のコマンドを覚えていなくても書ける) は
「`\int` や `\alpha` を覚えていない人でも、記号を選んで挿入できる」と言っている。
ラベルも同じで、覚えていないと使えない機能になっている。

**記法は2度変わっている。** [0044](0044-equation-numbers.md) の
`\tag{名前}` と `[(1)](#eq-名前)` は、[0083](0083-crossref-dialect.md) で
Quartoの綴り（`$$ … $$ {#eq-名前}` と `@eq-名前`）へ移り、
[0085](0085-drop-old-equation-notation.md) で旧記法は落ちた。
**このissueで入れるのは新記法のほう**で、`\tag` ではない。

現在のパレットは Markdown グループに「見出し」「箇条書き」などがあり、
記法を入れる場所としてはここが近い。

## やりたいこと

- パレットから、ラベル付きのブロック数式（`$$ … $$ {#eq-}`）を挿入できる。
- 参照（`@eq-`）も挿入できる。
- 挿入したあと、名前を書く位置にカーソルがある。
- **ラベルは英小文字・数字・`-` `_` だけ**（0083の決まり）。パレットの雛形も
  それに合わせる。

## やらないこと

- 名前を自動で付けること（`eq1`, `eq2` のような連番）。何を指す式かは
  書いた人にしか分からない。

## メモ

- **画面に要素を足すissue**なので、ボタンを足したときのパレットの高さを
  仕様の時点で測ること（[0032](0032-palette-height-narrow.md) の蓋、
  幅600/375/360pxでの `palette-height` 区分）。
- Markdown グループの `snippet` はLaTeXではないので、
  `palette.test.ts` のKaTeX描画テストの対象外になっている。`\tag` を
  どちらのグループに置くかで、テストの扱いが変わる。
