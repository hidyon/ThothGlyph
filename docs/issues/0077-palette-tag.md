# 0077: パレットから式の番号（`\tag`）を入れられない

- 状態: open
- 起票日: 2026-09-22

## 背景

[0044](0044-equation-numbers.md) で、`\tag{名前}` を書いたブロック数式に
番号が自動で振られるようになった。ただし**記法は手で書く前提**で、
パレットには `\tag` を入れるボタンが1つもない。

[R2](../requirements.md#r2-数式のコマンドを覚えていなくても書ける) は
「`\int` や `\alpha` を覚えていない人でも、記号を選んで挿入できる」と言っている。
`\tag` も同じで、覚えていないと使えない機能になっている。参照の書き方
（`[(1)](#eq-名前)`）も同様。

現在のパレットは Markdown グループに「見出し」「箇条書き」などがあり、
記法を入れる場所としてはここが近い。

## やりたいこと

- パレットから、番号付きのブロック数式（`$$ … \tag{} $$`）を挿入できる。
- 参照のリンク（`[(1)](#eq-)`）も挿入できる。
- 挿入したあと、名前を書く位置にカーソルがある。

## やらないこと

- 名前を自動で付けること（`eq1`, `eq2` のような連番）。何を指す式かは
  書いた人にしか分からない。

## メモ

- **画面に要素を足すissue**なので、ボタンを足したときのパレットの高さを
  仕様の時点で測ること（[0032](0032-palette-height-narrow.md) の蓋、
  幅600/375/360pxでの `palette-height` 区分）。
- Markdown グループの `snippet` はLaTeXではないので、
  `palette.test.ts` のKaTeX描画テストの対象外になっている。`\tag` を
  どちらのグループに置くかで、テストの扱いが変わる。
