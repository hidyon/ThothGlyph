# 0072: サンプル文書が二次方程式のままで、いまできることを見せていない

- 状態: closed
- 起票日: 2026-09-21

## 背景

初回訪問で入っているサンプル文書は**二次方程式の解の公式**で、
[0018](0018-formula-library.md) の頃（公式30件・記号62件）に書かれたもの。
[0040](0040-sample-graph.md) でグラフを1つ足しただけで、中身は変わっていない。

### いまのサンプル（実測）

| | 日本語 | 英語 |
|---|---|---|
| 行数 | 32行 | 32行 |
| バイト数 | 789バイト | 701バイト |
| 見出し | 2（`# 二次方程式の解の公式`・`## 導出`） | 2 |
| ブロック数式 | 2 | 2 |
| インライン数式 | 8 | 9 |
| グラフ | 1（`y = x^2 - 2x`） | 1 |
| 箇条書き | 3 | 3 |

末尾は `パレットのボタンを押すと、カーソル位置に数式コマンドが入ります。` で、
**初回訪問の案内を兼ねている**（[0054](0054-palette-placement.md)でパレットが
左の縦帯になったとき、「上のパレット」という位置の言葉を消した経緯がある）。

### この間にパレットは2.4倍になった

| | 0018の頃 | いま |
|---|---|---|
| 記号 | 62件・6グループ | **150件・7グループ** |
| 公式 | 30件・6分類 | **75件・15分類** |

[0064](0064-palette-beyond-highschool.md)（統計・確率と集合・論理）・
[0068](0068-palette-decorations.md)（装飾・書体）・
[0070](0070-wide-accents.md)（上飾り）で足した記号は、
**サンプル文書に1つも出てこない**。開いた人が最初に見る画面は、
いまも高校数学の二次方程式だけになっている。

## やりたいこと

- 初回訪問の画面が、**このアプリでいま何が書けるか**を見せている。
- サンプル文書そのものが**読んで意味のある短い文章**である
  （記号の展示だけの羅列にはしない）。
- 初回訪問の案内（パレットの使い方に触れる一文）は残す。
- 日本語と英語の両方がある。訳ではなく、同じ狙いを満たす文書でよい
  （いまもそうなっている）。

## やらないこと

- **白紙から始める手段を作ること**（[0061](0061-new-note.md)）。別issue。
- **サンプルを長くすること。** いま32行・789バイトで、初回訪問の描画コストと
  スクリーンショットの収まりがこの規模で確かめられている。**2倍にはしない。**
- **記法を足すこと。** 定理の囲み（[0041](0041-theorem-blocks.md)）や
  式番号（[0044](0044-equation-numbers.md)）は未実装なので使えない。
- **パレットの中身を変えること。**

## メモ

- **依存している検証が多い。起票の時点で数えた:**

| 依存しているもの | 箇所 |
|---|---|

  （サンプルとは独立した単体テストだが、読む人は同じものだと思う）。
- `docs/functional-spec.md` の2箇所（ファイル名の例・サンプルの名前）も直す。
- **READMEのスクリーンショット3枚はサンプル文書が写っている。**
  `node scripts/make-screenshots.mjs` で撮り直すこと（幅1440pxのライト・ダークと幅360px）。
- 中身の候補（仕様で決める）:
  - **統計の短い覚書**（0064で足した `\mathcal{N}` `\sim` `\mathrm{E}`、0070の
    `\overrightarrow` や `\widehat` が自然に出る）。0060の起票に使った
    「多変量正規分布と重回帰」の覚書が実在の例。
  - **微分積分の1節**（既存の公式分類と重なる）。
  - **アプリの案内**（何ができるかを列挙する。読み物にはならない）。
- **初回訪問の描画コストは測ること。** いまのサンプルで読み込み101ms・
  追いつくまで1.1秒（0060の起票時の実測）。数式を増やすと初回の体感が変わる。
