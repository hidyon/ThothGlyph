# 0049: ノートを一覧して選べない（0004の次）

- 状態: open
- 起票日: 2026-09-20

## 背景

[0004](0004-multi-document.md) は「複数文書を持てるようにする」issueで、
まだ着手していない。それが入った後、ノートが10件20件と増えたときに要るのが
**一覧・並べ替え・分類**で、0004の受け入れ基準には入っていない
（0004は文書を切り替えられるところまで）。

いまは文書が1件しか持てないので、この話は0004の後にしか始められない。

## やりたいこと

- 持っているノートが一覧で見え、選んで開ける。
- 更新日時や名前で並べ替えられる。
- 探せる（名前と中身の両方から。[0043](0043-find-replace.md) の文書内検索とは別物）。
- 分類できる（タグ、または科目のようなまとまり）。

## やらないこと

- 共有・同期。サーバを持たない方針は変えない。
- フォルダの入れ子。まず平らなタグで様子を見る。

## メモ

- **[0004](0004-multi-document.md) が先。** 保存形式（いまは
  `matheditor:document:v1` に1件）を変えるのは0004なので、そこで一覧に必要な
  情報（名前、更新日時）が入る形にしておけば、このissueは表示の話だけになる。
  0004の仕様を書くときに、このissueの存在を伝えること。
- 一覧の置き場所は画面を大きく占める。[0032](0032-palette-height-narrow.md)・
  [0033](0033-toolbar-overflow-phone.md) で測ったとおり余白はもうない。
  別画面にするのか、重ねて出すのかを仕様で決める。
