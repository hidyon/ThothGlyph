# 0028: 初期表示の区分にチェックが1件もない

- 状態: open
- 起票日: 2026-09-19

## 背景

[0017](0017-verify-script-structure.md) で検証スクリプトを区分に分けたとき、
`initial`（初期表示）の区分に `check()` の呼び出しが**1件もない**ことが分かった。
やっているのは次の3つだけで、どれも結果を判定していない。

```
console.log('見出し:', …)
console.log('ブロック数式:', …)
console.log('数式の総数:', …)
await page.screenshot(…)
```

`node scripts/verify-ui.mjs initial` を流すと「0/0 件 OK」で終わり、
**終了コードは0**になる。初期表示が壊れても、この区分は落ちない。

[テスト仕様](../test-spec.md)は初期表示を区分として数えており、
チェックがあるように読める。実態と合っていない。

**[0040](0040-sample-graph.md) で2件だけ増えた**（サンプル文書のグラフが描かれること、
グラフのエラーが出ていないこと）。見出し・ブロック数式の数・数式の総数は、
いまも `console.log` で出すだけで判定していない。

## やりたいこと

- 初期表示が壊れたときに、`initial` の区分が落ちる。
- いま `console.log` で出している3つの値（見出し、ブロック数式の数、数式の総数）が、
  期待値との比較として判定される。
- 「0/0 件 OK」で通る区分がなくなる。

## やらないこと

- 他の区分へのチェックの追加。この区分に閉じる。
- ログの削除。値が目に見えること自体は、落ちたときに役に立つ。

## メモ

- サンプル文書は `src/sampleDocument.ts` にあるので、期待値はそこから決まる。
  ただし**サンプル文書を変えるたびに期待値も変わる**ため、数を直書きすると
  壊れやすい。見出しの文字列一致だけにするか、数はゼロより大きいことを見るか、
  仕様で決めること。
- 0017の仕様は「チェックの中身は1件も変えない」としていたので、
  そちらでは直さずに起票した。
- [0027](0027-verify-flaky.md) で区分ごとの結果をJSONに残すようにすると、
  0件の区分はいっそう目につきやすくなる。
