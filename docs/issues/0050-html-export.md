# 0050: 数式が描かれた形で文書を渡せない

- 状態: open
- 起票日: 2026-09-20

## 背景

いまの持ち出し方は3つで、いずれも**渡した先で数式が描かれるとは限らない**。

- `Markdownをコピー` — 貼り付け先がKaTeXを解さなければ `$x^2$` のまま
- `ファイルに保存`（`.md`） — 同じ
- グラフ（[0037](0037-graph.md)） — ` ```graph ` のコードブロックとして残るだけ

[0003](0003-image-export.md)（数式の画像書き出し）は**数式1つ**を画像にする話で、
ノート全体を誰かに渡す場面は埋まらない。

## やりたいこと

- 文書全体を、**数式とグラフが描かれた状態**の1ファイルとして書き出せる。
- 受け取った側は、ブラウザで開くだけで読める（このアプリも通信も要らない）。
- ダーク／ライトのどちらでも読める。

## やらないこと

- PDF。それは [0013](0013-print-style.md)（印刷とPDF出力）。
- 編集できる形で渡すこと。それは `.md` の書き出しで足りている。

## メモ

- 単一のHTMLファイルにするなら、KaTeXのCSSとフォントを埋め込む必要がある。
  **フォントを埋めるとファイルが数百kBになる**ので、大きさを仕様で測って決める。
  埋めずにCDNを参照する手もあるが、オフラインで読めなくなる。
- グラフのSVGはそのまま埋められる（自前で生成しているため）。
- [0013](0013-print-style.md) と土台が重なる（画面のUIを外して本文だけにする）。
  どちらかを先にやるなら、その整理を先にすること。
