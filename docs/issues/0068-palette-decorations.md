# 0068: パレットに装飾・書体の記号がない

- 状態: open
- 起票日: 2026-09-21

## 背景

[0064](0064-palette-beyond-highschool.md) で統計・確率と集合・論理をパレットに
足したが、**装飾・書体は範囲外にした**（[0064の仕様](../specs/0064-palette-beyond-highschool.md#スコープ外)）。
0064の背景にある実測のうち、次の2件が残っている。

| 要るもの | 使う場面 | いまの検索結果 |
|---|---|---|
| `\tilde` | $\tilde\beta$（`\hat` `\bar` `\vec` `\overline` はある） | 0件 |
| `\overset` | 等号の上に根拠を書く | 0件 |

`\mathcal` `\mathrm` `\mathbb` は0064で入ったが、**書体を選ぶ道具としてではなく
「正規分布」`\mathcal{N}` 「期待値」`\mathrm{E}` 「実数全体」`\mathbb{R}` という
完成した記号として**入れた。`\mathcal{F}` や `\mathrm{d}` のように**自分で中身を
決めたいときには使えない**。

## やりたいこと

- 文字に飾りを付けたいとき（チルダ、記号の上下に何かを載せる、書体を変える）に、
  **コマンドを覚えていなくても選べる**。
- `\hat` `\bar` `\vec` `\overline` と同じ場所（`基本` グループ）に並んでいて、
  装飾を探しているときに1か所で見つかる。

## やらないこと

- **記号の新しいタブを作ること。** 0064と同じ理由（タブ1つで横帯が+34px）。
- **線形代数の記号**（[0067](0067-palette-linear-algebra.md)）。
- **0064で入れた `\mathcal{N}` `\mathrm{E}` `\mathbb{R}` を消すこと。**
  用途が違う（完成した記号 vs 中身を決める入れ物）ので、両方あってよい。
  ただし**検索で紛れる**ので、tooltipの書き方は仕様で決めること。

## メモ

- 範囲の候補（仕様で絞る）: `\tilde` `\overset` `\underset` `\text`
  `\mathcal{}` `\mathbb{}` `\mathrm{}` `\mathbf` `\dot` `\ddot` `\underbrace`。
- **`基本` グループに足すときは、ラベルの文字数に注意する。** 0064で
  `\overline{X}`（12文字）を基本の9件目に置いたら、**読み込み中だけパレットが
  41px高くなり**（ラベルはKaTeXが届くまでLaTeXのソースで出る）、
  0024の「読み込み前後で飛ばない」チェックが落ちた。演算子へ移して解決した。
  装飾は `\overset{a}{=}` のようにlabelが長くなりやすいので、
  **仕様の時点で幅600pxの `loading` 区分を流して測ること。**
- READMEの件数（記号130個・公式75件）は単体テストで固定されている。
- 追加するLaTeXは仕様の時点で `katex.renderToString` に `throwOnError: true` で通すこと。
