# 0091: プロダクト仕様書が現行UIに追随していない

- 状態: closed
- 起票日: 2026-09-23

## 背景

ツールバー、パレット、ソースの操作をメニューへ集約し、トトのマスコットと設定メニューのREADMEを追加した。一方で、要求仕様・アーキテクチャ・機能仕様・テスト仕様には、直接ボタン、パレットのタブ、保存通知、以前の読み込み性能値を前提にした記述が残っていた。

実装と仕様書が食い違うと、利用者向けの説明と次の変更時の判断基準が古くなる。

## やりたいこと

4つのプロダクト仕様書が、2026-09-23時点の画面構成・操作経路・読み込み実測・検証状況を表す。

## やらないこと

画面や機能の変更、既存の実機検証スクリプトをメニュー操作へ移行する実装、未提供のMarkdownコピー導線の追加は扱わない。

## 結果

- `docs/requirements.md` に設定メニュー、現行の性能実測、未提供のMarkdownコピー導線を記録した。
- `docs/architecture.md` にマスコット、READMEモーダル、README本文を含む初期チャンクを記録した。
- `docs/functional-spec.md` にツールバー、パレット、ソースのメニュー操作と通知なしの保存・ファイル操作を記録した。
- `docs/test-spec.md` にREADME区分の実測と、旧UIを前提にする既存実機検証をメニュー操作へ移行する必要を記録した。
