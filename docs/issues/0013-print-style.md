# 0013: 印刷とPDF出力のスタイル

- 状態: open
- 起票日: 2026-09-19

## 背景

いま印刷すると、ツールバー・パレット・ソース側のペインまで一緒に紙に出る。
プレビューは2分割の細いカラムのまま印刷されるので、数式が読める状態にならない。

ブラウザの「PDFに保存」で配布物が作れれば、[0003](0003-image-export.md)（数式の
画像書き出し）ほど作り込まなくても足りる場面がある。

## やりたいこと

- 印刷するとプレビューだけが、紙幅いっぱいの1カラムで出る。
- 数式が途中で切れず、リンクや表も読める。
- 追加の操作なしに、ブラウザの印刷から使える。

## やらないこと

- ページ番号、ヘッダ・フッタ、目次の自動生成。
- サーバ側でのPDF生成。

## メモ

- `@media print` のCSSだけで済む見込み。JSは要らないはず。
- 検証はヘッドレスChromiumの `page.pdf()` か `emulateMedia({ media: 'print' })` で
  できる。受け入れ基準はそれで書く。
- 長い数式ブロックの改ページ（`break-inside: avoid`）の挙動を確認すること。
