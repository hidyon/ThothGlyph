# 0055: ギリシャ大文字が11件しかなく、24件そろっていない

- 状態: open
- 起票日: 2026-09-20

## 背景

`ギリシャ大文字` タブは**11件**（Γ Δ Θ Λ Ξ Π Σ Υ Φ Ψ Ω）。
[0029](0029-greek-complete.md) が**意図して13件を除いた**もので、
[その仕様](../specs/0029-greek-complete.md)にはこう書いてある。

> **大文字は24個すべてではなく11個にする。** `\Alpha` はラテン文字の `A` と
> 見た目がまったく同じで（実際にKaTeXで描画して確かめた）、ボタンに並べても
> 区別がつかない。**見分けのつかないボタンを13個増やす意味がない。**

本issueは**この判断を取り消す**。理由は、除かれた13件が画面にも検索にも
存在しないため、`\Alpha` と書きたい利用者には
「このエディタでは出せない」と映ること。字形がラテン文字と同じでも、
LaTeXのコマンドとしては別物で、実際に書かれる（`\Alpha` と `A` は
数式の意味づけが違う場面がある）。小文字は `\omicron` まで24件そろっていて、
**大文字だけ欠けているのは一覧としても分かりにくい**。

抜けているのは13件で、いずれもKaTeXで描画できることを確認した（2026-09-20）:
`\Alpha` `\Beta` `\Epsilon` `\Zeta` `\Eta` `\Iota` `\Kappa` `\Mu` `\Nu`
`\Omicron` `\Rho` `\Tau` `\Chi`。

## やりたいこと

- `ギリシャ大文字` タブから24件すべてを入力できる（11件 + 13件）。
- パレットの高さが今の蓋を壊さない。幅360pxで139px、幅1440pxで94px
  （[0032](0032-palette-height-narrow.md) の上限）。
  **大文字タブは今11件で1行に収まっている**ので、24件にしたときの行数と
  高さを仕様の時点で測って書く。
- 0029が挙げた「見分けがつかない」問題への答えが仕様に書かれている
  （tooltipのコマンド名だけで足りるのか、ボタンにも何か要るのか）。
- 検索（[0011](0011-palette-search.md)）で `Alpha` `\Alpha` を打つと出る。

## やらないこと

- 小文字と異体字の変更（31件のまま）。
- 大文字のタブを分割すること（24件が1タブに収まるかは測ってから決める）。
- ラテン文字と同じ字形であること自体を見た目で解決すること
  （フォントを変える、色を変えるなど）。

## メモ

- **README・単体テストの件数が落ちる。** `src/lib/palette.test.ts` に
  「大文字はラテン文字と字形が異なる11件」「記号は7グループ89件」があり、
  READMEにも「記号7グループ89個」と書いてある。13件足すと102件。
  **テストの文言（「字形が異なる11件」）も0029の判断に沿って書かれている**ので、
  数字だけでなく説明も直すこと。
- 0029の仕様（`docs/specs/0029-greek-complete.md`）は「現在の姿」ではなく
  「変更の単位」の文書なので書き換えない。**判断を変えたことは本issueの仕様に書く。**
- データを足すだけなので実装は軽い（`src/lib/palette.ts` に13行）。
  重いのは「見分けがつかないボタンをどう扱うか」の判断のほうである。
- 0029は「omicron は `o` と似ているが、24文字から1文字だけ欠けているほうが
  分かりにくい」として小文字には入れている。**本issueは同じ理屈を大文字にも
  当てるもの**と位置づけられる。
