# 0012: .mdファイルの書き出しと読み込み

- 状態: open
- 起票日: 2026-09-19

## 背景

いま文書を持ち出す手段はクリップボードへのコピーだけ。貼り付け先を開いていない
場面では使えず、逆に手元の `.md` を開いて続きを書くこともできない。
[0001](0001-autosave.md) でブラウザには残るようになったが、ブラウザの外には
出せないままである。

## やりたいこと

- 編集中の文書を `.md` ファイルとしてダウンロードできる。
- 手元の `.md` ファイルを開いて編集できる（ドラッグ＆ドロップを含む）。
- 読み込みで編集中の内容が消える場合は、その前に確認がある。

## やらないこと

- File System Access API による「上書き保存」。対応ブラウザが限られる。
  まずダウンロードと読み込みで足りるか見る。
- `.md` 以外の形式（HTML、PDF）。0003・[0013](0013-print-style.md) が扱う。
