# 0012: .mdファイルの読み込み

- 状態: closed
- クローズ日: 2026-09-20
- 起票日: 2026-09-19
- 更新日: 2026-09-20（書き出しを [0034](0034-file-save.md) へ分けた。ここは読み込みだけ）

## 背景

いま文書を持ち出す手段はクリップボードへのコピーだけ。貼り付け先を開いていない
場面では使えず、逆に手元の `.md` を開いて続きを書くこともできない。
[0001](0001-autosave.md) でブラウザには残るようになったが、ブラウザの外には
出せないままである。

## やりたいこと

- 手元の `.md` ファイルを開いて編集できる。入口は2つ。
  - ファイル選択のボタン（押すとOSのダイアログが出る）
  - エディタへのドラッグ＆ドロップ
- 読み込むと編集中の内容が置き換わるので、**その前に確認がある**
  （「サンプルに戻す」と同じ形。[0001](0001-autosave.md) で保存された内容も
  上書きされるため）。

## やらないこと

- `.md` ファイルの書き出し（ダウンロード）。[0034](0034-file-save.md) で扱う。
  読み込みだけを先にやるのは、**ツールバーに足す要素が1つで済み、
  幅360px（[0033](0033-toolbar-overflow-phone.md) で下げた基準）の測り直しが
  1回で終わる**ため。
- File System Access API による「上書き保存」。対応ブラウザが限られる。
- `.md` 以外の形式（HTML、PDF）。0003・[0013](0013-print-style.md) が扱う。

## メモ

- **置き場所を仕様で決めること。** 0033の実測では、幅360pxでツールバーの
  4ボタンの右端は350pxで、右のpadding 10pxを使い切っている。
  **ツールバーに5つ目のボタンを足す余地は360pxにはない。**
  ソースペインの見出し行など、別の場所も含めて測ってから決める。
- 読み込むファイルの大きさに上限を置くか（0007で400節・400数式は扱えている）。
- [0004](0004-multi-document.md)（複数文書）と組み合わさると「まとめて開く」需要が
  出るが、このissueでは編集中の1件に絞る。

## 結果（2026-09-20 クローズ）

ソースペインの見出し行の右端に「ファイルを開く」ボタンを置き、ペインへの
ドラッグ＆ドロップでも読み込めるようにした。`.md` / `.markdown` / `.txt` を
1MBまで、一度に1件。置き換える前に確認が出る。BOMと改行（CRLF）は
読み込み時に正規化する。

見出し行の縦paddingを0にして `min-height: 30px` にしたので、ボタンを足しても
見出し行は30pxのまま、幅375pxのtextareaは207pxを保っている（0032・0033のぶんが減らない）。

検証は区分 `file-load`（32件）。単体テストは `lib/loadMarkdownFile.test.ts`（14件）。
仕様: [0012](../specs/0012-file-load.md)
