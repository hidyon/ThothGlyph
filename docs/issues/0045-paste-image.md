# 0045: 手元の画像を貼り付けられない

- 状態: open
- 起票日: 2026-09-20

## 背景

外部URLの画像（`![図](https://example.com/a.png)`）は表示できることを確かめた。
一方、**手元の画像ファイルは入れられない**。ドラッグしても `.md` の読み込み
（[0012](0012-file-io.md)）として扱われ、拡張子が違うと断られる。
クリップボードから貼っても何も起きない。

数式ノートでは、教科書の図の写真、手書きの図、実験データのグラフ画像などを
挟みたい場面がある。いまはその手段がない。

## やりたいこと

- 画像をドラッグ、またはクリップボードから貼ると、文書に挿入されて表示される。
- 貼った画像が、次に開いたときにも残っている。
- 画像を含む文書を持ち出せる（`.md` として書き出したときに画像が失われない）。

## やらないこと

- 画像の編集（切り抜き、注釈）。
- サーバへのアップロード。サーバを持たない方針は変えない。

## メモ

- **容量が最大の論点。** 保存先はlocalStorage（上限5MB前後）で、いまは文書1件を
  そこに入れている。写真1枚で数MBになるので、そのまま入れると保存が失敗する
  （[N3](../requirements.md)「保存の失敗で編集が止まらない」に触れる）。
  IndexedDBへ移す、縮小してから入れる、枚数と大きさに上限を設ける、といった
  判断が要る。**起票の時点では測っていないので、仕様で実測すること。**
- `.md` に埋めるなら `data:` URI になり、ソースが読めなくなる
  （[0037](0037-graph.md) でグラフの記法を決めたときと同じ問題）。
  書き出しのときだけ埋める、という手もある。
- [0004](0004-multi-document.md)（複数文書）より先に入れると、保存形式を
  2回変えることになる。順序を相談してから着手するのがよい。
