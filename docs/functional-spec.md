# 機能仕様

> **更新のタイミング**: 画面に見えるもの、操作、振る舞いが変わったとき。
> issueをクローズしたら、この文書の記述が変わっていないか確かめる。

**いま何ができるか**だけを書く。未実装のものは「今はない」とissue番号を添える。

## 1. 画面の構成

上から4つ。すべて1画面に収まり、ページ遷移はない。

```
┌────────────────────────────────────────────────────────────┐
│ [√] ThothGlyph  保存しました 12:34 [言語: 日本語][テーマ: 自動][サンプルに戻す][Markdownをコピー] │ ツールバー（幅480px以下では[戻す][コピー]）
├────────────────────────────────────────────────────────────┤
│ √基本 αギリシャ小文字 Ωギリシャ大文字 Σ演算子 ≠関係子 {}括弧・構造 #Markdown ƒ公式 [検索…] │ タブと検索欄
│ [a/b] [√x] [ⁿ√x] [xⁿ] [xᵢ] [x̄] [v⃗] [x̂]                      │ パレットのボタン
├───────────────────────┬────────────────────────┤
│ ソース [検索][ファイルに保存][ファイルを開く] │ プレビュー  更新中…     │
│                       │                        │
│ （textarea）           │ （描画結果）              │
└───────────────────────┴────────────────────────┘
```

**幅1200px以上では、パレットは左の縦帯（180px）になる**（[0054](specs/0054-palette-placement.md)）。
**3つの領域の境目はドラッグで動かせる**（[0057](specs/0057-resizable-panes.md)）。
仕切りは6pxが2本。下限はパレット150px・ソース360px・プレビュー360px。
左右キーで16pxずつ動き、ダブルクリックで既定（180px・半々）に戻る。
分け方は `thothglyph:panes:v1` に保存する（パレットはpx、ソースとプレビューは割合）。

```
┌────────────────────────────────────────────────────────────┐
│ [√] ThothGlyph       …ツールバーは全幅のまま…                    │
├──────┬─────────────────────┬───────────────────┤
│ パレット │ ソース [検索][保存][開く] │ プレビュー            │ ← 3つとも見出し行（30px）
│ √基本  │                     │                   │
│ αギ小  │                     │                   │
│ Ωギ大  │ （textarea）          │ （描画結果）           │
│ …     │                     │                   │
│ [検索…] │                     │                   │
│ [a/b]… │                     │                   │
└──────┴─────────────────────┴───────────────────┘
```

幅720px以下では、左右2分割が上下2分割に変わり、保存状態の文言は1行に省略される。
`ThothGlyph` の文字も隠れ、左上はアイコンだけになる（読み上げには残る）。

## 2. エディタ（左ペイン）

素の `<textarea>`。Markdownソースをそのまま編集する。

- スペルチェックは切ってある（LaTeXコマンドが波線だらけになるため）。
- 空のときは `Markdownを入力… 数式は $x^2$ または $$...$$` と出る。
- Tabキーはフォーカス移動のまま（インデントは入らない。[0008](issues/0008-keyboard-shortcuts.md)）。
- Undo・Redoはブラウザのもの（Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y）。パレットからの
  挿入も同じ履歴に乗る（[0021](specs/0021-undo.md)）。ファイルの読み込みと
  「サンプルに戻す」は履歴に乗らず、Ctrl+Zでは戻らない。
- 行番号、シンタックスハイライト、折り返しの制御は今はない。

### 文書内の検索・置換（[0043](specs/0043-find-replace.md)）

ソースの見出し行の `検索` / `Find`、またはエディタで `Ctrl+F` を押すと、
見出し行の下にバーが開く。閉じている間は何も出ない。

```
[検索欄        ] 3/12件 [前へ][次へ][置換][閉じる]
[置換後の文字列 ] [置換][すべて置換]        ← バーの「置換」を押している間だけ
```

- **`Ctrl+F` を奪うのはエディタにフォーカスがあるときだけ。** プレビューや
  パレットにいるときはブラウザの検索が開く（プレビューの文字を探す手段を残す）。
- 語を打つと件数（`3/12件` / `3/12`、なければ `0件` / `No matches`）が出て、
  **一致がすべて塗られる。いま選ばれている1件だけ色が濃い。**
  画面の外なら見えるところまでスクロールする。塗りはバーを閉じると消える。
- `次へ` `前へ`（`Enter` / `Shift+Enter`）で送る。**端では反対側へ回る。**
- **素の文字列として照合し、大文字と小文字を区別する**（`\alpha` と `\Alpha` は別物）。
  重なる一致は数えない（`aaaa` から `aa` は2件）。正規表現は使えない。
- `置換` はいま選ばれている1件、`すべて置換` は全件を置き換える。
  置換後の文字列は再検索しないので、`x` を `xx` にしても増殖しない。
- **どちらもCtrl+Zで戻せる。すべて置換は何件でも1回で戻る。**
- `閉じる` / `Esc` でバーが閉じ、エディタにフォーカスが戻る。
- 開くときにソースで文字列を選んでいれば、それが検索欄の初期値になる。
- 幅480px以下ではボタンの文言が `‹` `›` `全て` `×` に短くなる。
- プレビュー側は検索の対象外。検索語の保存もしない。

### ファイルの読み込み（[0012](specs/0012-file-load.md)）

手元の `.md` を開いて続きが書ける。入口は2つ。

- ソースの見出し行の右端にある `ファイルを開く` / `Open file` ボタン
- ソースペインへのドラッグ＆ドロップ（重ねている間はペインの枠が破線になる。
  枠の色だけが変わり、**ペインの大きさは変わらない**）

読み込みは編集中の内容を置き換えるので、先に確認が出る
（`編集中の内容を破棄して <ファイル名> を読み込みます。よろしいですか？`）。
キャンセルすると何も変わらない。OKなら置き換わり、通常どおり自動保存される。

受け取るのは `.md` / `.markdown` / `.txt` で、**1MBまで、一度に1件**。
読めたテキストは、先頭のBOMを落とし、改行を `\n` に揃えてから入れる。

断ったときと読めたときの結果は、コピーの結果と同じ枠（ツールバー）に数秒出る。

| 結果 | 表示 |
|---|---|
| 読み込めた | `<ファイル名> を読み込みました` |
| 2件以上 | `一度に開けるのは1つだけです` |
| 対象外の拡張子 | `.md ファイルを選んでください` |
| 1MB超 | `ファイルが大きすぎます（上限1MB）` |
| 読み取りに失敗 | `ファイルを読み込めませんでした` |

### ファイルの書き出し（[0034](specs/0034-file-save.md)）

見出し行の `ファイルに保存` / `Save to file` を押すと、編集中の内容が
`.md` ファイルとしてダウンロードされる。確認は出ない（何も失わないため）。

ファイル名は**先頭の見出し**から作る（`# 二次方程式の解の公式` →
`二次方程式の解の公式.md`）。見出しがなければ `document.md`。
ファイル名に使えない文字（`/ \ : * ? " < > |` と制御文字）は `-` になり、
50文字で切る。見出しの記法は剥がさないので、`# **強調**` は `--強調--.md` になる。

書き出す中身はエディタの内容そのままで、末尾に改行がなければ1つ足す。
本文が空白だけのときは書き出さず、`書き出す内容がありません` と出る。
書き出せたときは `<ファイル名> を保存しました` が数秒出る。

## 3. プレビュー（右ペイン）

エディタの内容を変換して表示する。読み取り専用で、ここから編集はできない。

- 入力から遅れて追いつく。遅れている間はヘッダに `更新中…` が出る。
- **開いた直後、数式の描画エンジンが届くまでは本文が空で、ヘッダに `準備中…` が出る**
  （[0024](specs/0024-bundle-size.md)）。その間もエディタは書けて、自動保存も動く。
  エンジンが届かないままなら `準備中…` のまま留まる。
- 壊れた数式は**赤字で表示される**。プレビュー全体が消えることはない。
  どこが壊れているかの一覧は今はない（[0015](issues/0015-error-list.md)）。
- **エディタと連動してスクロールする**（[0010](specs/0010-scroll-sync.md)）。下記。

### スクロールの同期（[0010](specs/0010-scroll-sync.md)）

ソースとプレビューが連動して動く。**どちらを動かしても、もう一方が追う。**

- エディタをスクロールすると、エディタの上端に見えている段落が
  プレビューでも上端に来る。
- プレビューをスクロールすると、エディタも同じ段落へ動く。
  **動くのはスクロール位置だけで、カーソルと選択範囲は動かない**
  （読み返している最中に編集位置を失わないため）。
- 片方を最上端・最下端にすると、もう一方も最上端・最下端になる。
- 合わせ方はブロック（見出し・段落・箇条書き・表・引用・コードブロック・
  グラフ）の単位。ブロックとブロックの間は比例で埋める。
- 幅1199px以下の上下に分かれた配置でも同じように動く。
- 止める設定はない。

### 対応する記法

| 記法 | 例 | 結果 |
|---|---|---|
| インライン数式 | `$x^2$` | 文中に数式 |
| ブロック数式 | `$$\n x^2 \n$$` | 中央寄せの独立した数式 |
| 関数のグラフ | ` ```graph ` のコードブロック | 曲線が描かれたSVG（下の「関数のグラフ」） |
| Markdown | 見出し、箇条書き、表、引用、コード、リンク、水平線 | GFM相当 |
| 改行 | 行末の改行 | そのまま改行になる（`breaks: true`） |

数式として**扱われない**もの:

- コードフェンス（` ``` ` / `~~~`）とインラインコード（`` ` ``）の中の `$`
- `$100 から $200` のような、`$` の直後・直前が空白の並び
- `\$` とエスケープしたもの

### 関数のグラフ（[0037](specs/0037-graph.md)）

コードブロックの言語名を `graph` にすると、中身が関数の指定として読まれ、
プレビューにグラフが描かれる。

````
```graph
y = x^2 - 2x
x: -3..5
```
````

書ける行は3種類だけで、1行に1つ書く。

| 行 | 意味 | 省略したとき |
|---|---|---|
| `y = <式>` | 描く関数。**最大3本**。上から順に色が変わる | 1本もなければエラー |
| `x: <数>..<数>` | 横の範囲 | `-5..5` |
| `y: <数>..<数>` | 縦の範囲 | 描いた値から自動で決まる |

空行と `#` で始まる行は無視される（コメント）。同じ指定が2回あれば後のほうを使う。
どれにも当てはまらない行はエラーになる（打ち間違いを黙って無視しない）。

式に書けるのは、数・`x`・`pi`・`e`・`+ - * / ^`・括弧と、
`sin` `cos` `tan` `sqrt` `abs` `exp` `log`（自然対数）。角度はラジアン。
`2x` `3(x+1)` `2sin(x)` のように掛け算の記号は省ける。大文字は受け付けない。
範囲にも式を書ける（`x: -pi..pi`）。

描かれ方:

- 縦横比3:2。広い画面では480×320px、狭い画面ではプレビューの幅に合わせて縮む
  （幅360pxで312×208px）。上下2分割のときはプレビューのペインより高くならない。
- 目盛りはx・yとも5本。グリッド線が引かれ、値は有効数字3桁までで出る。
  `x=0` / `y=0` が範囲に入るときは、その軸だけ濃く引かれる。
- 関数が2本以上のときは、図の下に凡例（色と式）が出る。
- **有限でない値と範囲の外の点は描かず、そこで線が切れる。** `1/x` や `tan(x)` が
  画面を縦断する縦線でつながることはない。
- yの範囲を自動で決めるときは、上下5%の値を捨ててから余白を取る
  （`1/x` のような桁違いの値で曲線が1本の直線に潰れないようにするため）。
- ダークモードでは線の色が明るいほうへ替わる。

描けないときは、その場に赤字で1行出る（`式を読めません: x^^2` など）。
**プレビュー全体が消えることはない**（壊れた数式と同じ扱い）。
メッセージは表示言語で変わる。

グラフは**このアプリの中だけの記法**で、外へ持ち出すと図にはならず、
` ```graph ` のコードブロックとして残る（式は文字として読める）。
画像としての書き出しは今はない（[0003](issues/0003-image-export.md)）。

## 4. 記号パレット

7グループ・141個の記号ボタンと、15分類75件の公式。押すとエディタのカーソル位置に挿入される。

**タブの名前の前には記号が1つ付く**（`√` 基本 / `α` ギリシャ小文字 / `Ω` ギリシャ大文字 /
`Σ` 演算子 / `≠` 関係子 / `{}` 括弧・構造 / `#` Markdown / `ƒ` 公式）。
読まずにタブを見分けるためのもので、言語では変わらない
（[0053](specs/0053-palette-tab-icons.md)）。

**幅1200px以上では左の縦帯**（幅180px）、**1199px以下では上の横帯**。
縦帯のときは先頭に `パレット` / `Palette` の見出し行（30px。ソース・プレビューと
同じ形）が付く。**横帯では見出しを出さない**——縦帯では帯の余白に載るので
高さが増えないが、横帯では30px増えてtextareaがそのぶん減るため
（[0056](specs/0056-palette-header.md)）。
縦帯にすると高さの奪いがゼロになり、幅1440pxでtextareaが721px → 815pxになる
（代わりにプレビューが720px → 624px。うち6pxは0057の仕切り）。1199px以下で横帯のままなのは、
幅1024pxで縦帯にするとグラフが464px → 374pxまで縮むため
（[0054](specs/0054-palette-placement.md)）。縦帯では公式タブだけ中身が
帯より高く（959px）、帯の中で縦スクロールする。

**幅720px以下では、タブが折り返さず横スクロールになり、記号・公式の一覧は
高さ98px（画面が低いときは15vh）で頭打ちになって縦スクロールする**
（[0032](specs/0032-palette-height-narrow.md)）。記号や公式が増えても
パレットの高さは変わらない。幅375px・高さ667pxで141〜177px（画面の21〜27%）。

開いた直後、数式の描画エンジンが届くまでのラベルはLaTeXのソースで出る（`\fra…` のように幅で切れる）。押せば挿入は効き、何が入るかはtooltipで読める（[0024](specs/0024-bundle-size.md)）。

| グループ | 件数 | 内容 |
|---|---|---|
| 基本 | 8 | 分数、根号、上付き・下付き、バー、ベクトル、ハット |
| ギリシャ小文字 | 31 | 小文字24文字すべてと異体字7件（`\varepsilon` など）（[0029](specs/0029-greek-complete.md)） |
| ギリシャ大文字 | 24 | Α Β Γ Δ Ε Ζ Η Θ Ι Κ Λ Μ Ν Ξ Ο Π Ρ Σ Τ Υ Φ Χ Ψ Ω（字母順）。ラテン文字と字形が同じ13件（`\Alpha` `\Rho` など）も入っている。見分けはtooltipで与える（`Alpha（大文字。ラテン文字のAと同じ字形）`）（[0055](specs/0055-greek-uppercase-complete.md)） |
| 演算子 | 26 | 総和、総乗、積分、極限、偏微分、ナブラ、四則の記号。統計の演算子と分布（確率 `P`、期待値 `\mathrm{E}`、分散、共分散、正規分布 `\mathcal{N}`、二項分布、カイ二乗、二項係数、上線）と集合の演算（和集合、共通部分、差集合、添字つきの和集合・共通部分）（[0064](specs/0064-palette-beyond-highschool.md)） |
| 関係子 | 28 | ≤ ≥ ≠ ≈ ≡ ∝ ∈ ⊂ → ⇒ ⇔ ∞ ∀ ∃ と、統計・集合・論理の ∼（分布に従う） ∣（条件付き） ⊥（独立） `\xrightarrow{d}`（収束） ∉ ⊆ ⊃ ∅ ℝ ∧ ∨ ¬ ∴ ∵（[0064](specs/0064-palette-beyond-highschool.md)） |
| 括弧・構造 | 17 | 自動サイズの丸括弧・波括弧、絶対値、2x2行列、場合分け、複数行の式（aligned）。装飾（チルダ、点1つ・2つ、上に載せる、下に載せる、下の波括弧）と書体の入れ物（筆記体 `\mathcal{}`、白抜き `\mathbb{}`、立体 `\mathrm{}`、太字 `\mathbf{}`、数式の中の文章 `\text{}`）（[0068](specs/0068-palette-decorations.md)）。**装飾がこのグループにあるのは、`基本` が8件でちょうど1行の端にいて、1件でも足すと読み込み中だけ41px高くなるため**（探すときは検索で引く） |
| Markdown | 7 | 数式の囲み（インライン／ブロック）、見出し、太字、斜体、箇条書き、グラフの雛形（[0037](specs/0037-graph.md)） |
| 公式 | 75 | 名前のついた式のかたまり。下の「公式」を見よ（[0018](specs/0018-formula-library.md)） |

挿入の振る舞い:

- ボタンのラベルはKaTeXで描画された実物の記号（テキストのコマンド名ではない）。
- **選択範囲があるとき**、どの記号を押しても選択したテキストは消えない
  （[0009](specs/0009-wrap-selection.md)）。記号に「カーソルを置く場所」が
  定義されていれば、選択した文字列がその中に入る（`x + 1` を選んで `√` →
  `\sqrt{x + 1}`）。定義されていない単体記号（`\alpha` など94件）では、
  選択範囲の直後に挿入される（`x + 1` を選んで `α` → `x + 1\alpha `）。
  どちらになるかはボタンのtooltipに出る（`平方根（選択範囲を囲む）` /
  `pi（選択範囲の後ろに挿入）`）。
- 挿入後は選択が解除され、カーソルが挿入した文字列の末尾に来る。
- **選択範囲がないとき**、挿入後のカーソルは続きを書くべき位置に入る
  （`\frac{}{}` なら分子の中）。
- エディタを一度も触っていない場合は文書の末尾に挿入される。
- **挿入は手で打った文字と同じ履歴に乗る**（[0021](specs/0021-undo.md)）。
  押し間違えたら Ctrl+Z で挿入前に戻り、Ctrl+Shift+Z（Ctrl+Y）でやり直せる。
  挿入は何文字入っても**1回のCtrl+Zでまとめて**消える（打った文字は1文字ずつ）。
  選択範囲を囲んだ場合は、戻したときに選択範囲も元に戻る。
- 記号の検索は下の「検索」を見よ（[0011](specs/0011-palette-search.md)）。

### 検索

タブ行の右端に検索欄がある。打つとタブを横断して、記号141件と公式75件から絞り込む。

- `\int` でも `int` でも `積分` でも `integral` でも引ける。`\` `{}` `^` `_` と
  空白を落として小文字にしてから、部分一致で照合する。**表示言語に関わらず
  日英どちらの名前でも引ける。** 読み仮名では引けない（`せきぶん` は当たらない）。
- 並び順は前方一致が先、次に部分一致。同順はパレットの定義順。
- 検索中は**どのタブも選択状態にならない**（横断しているため）。
  クエリを消すか `Esc` を押すと、検索を始める前に見ていたタブに戻る。
  タブを押しても検索を終える。
- 結果は最大40件。超えた分は `他N件` と件数だけ出る。
- 結果が多いときは**結果の欄だけがスクロールする**（画面高の21%が上限）。
  蓋がないと幅600pxでパレットが画面の65%を占め、ソースが2行になる。
- 当たらないときは `一致する記号がありません`。
- tooltipには元のグループ名が付く（`積分（選択範囲を囲む）［演算子］`）。
- キーボードだけで挿入まで終わる。

| 場所 | キー | 動き |
|---|---|---|
| 検索欄 | `Enter` | 先頭の結果を挿入する（フォーカスはエディタへ戻る） |
| 検索欄 | `↓` | 先頭の結果へフォーカスを移す |
| 検索欄 | `Esc` | クエリを空にする。空ならエディタへ戻る |
| 結果 | `↓` `→` / `↑` `←` | 次 / 前の結果へ（並び順の前後。折り返しは見ない） |
| 結果 | `Enter` `Space` | 挿入する |
| 結果 | `Esc` | 検索欄へ戻る |

挿入してもクエリは残る（同じ記号を続けて入れられる）。検索欄に一発で移る
ショートカットは今はない（[0008](issues/0008-keyboard-shortcuts.md)）。

### 公式

`公式` タブを選ぶと2段目のタブ（15分類）が出て、分類ごとに5件ずつ並ぶ
（[0018](specs/0018-formula-library.md)・[0030](specs/0030-formula-library-more.md)・
[0064](specs/0064-palette-beyond-highschool.md)）。高校数学から統計・確率・集合と論理までで
合計75件。

| 分類 | 収録 |
|---|---|
| 方程式 | 解の公式、判別式、解と係数の関係、因数分解（2乗の差）、展開（和の2乗） |
| 三角比 | 相互関係、正弦定理、余弦定理、加法定理（sin／cos） |
| 三角関数 | 2倍角（sin／cos）、半角（sin²）、和積（sinの和）、三角関数の合成 |
| 指数・対数 | 指数法則（積／べき）、対数の積、対数の商、底の変換 |
| 数列 | 等差数列の一般項と和、等比数列の一般項と和、Σk の公式 |
| 微分・積分 | 微分の定義、べき乗の微分、積の微分、べき乗の積分、定積分と面積 |
| ベクトル | 内積、なす角、大きさ（成分）、平行条件、内分点 |
| 図形と方程式 | 2点間の距離、点と直線の距離、円の方程式、直線の方程式、円の接線 |
| 確率・統計 | 順列、組合せ、余事象、条件付き確率、期待値 |
| 複素数 | 絶対値、共役との積、極形式、ド・モアブルの定理、和の共役 |
| 微分・積分（応用） | 商の微分、合成関数の微分、部分積分、置換積分、回転体の体積 |
| 極限・不等式 | sin x / x の極限、e の定義、二項定理、相加相乗平均、三角不等式 |
| 確率 | ベイズの定理、全確率の公式、独立なときの積、二項分布、正規分布の確率密度 |
| 期待値・分散 | 期待値の線形性、分散の定義、共分散、相関係数、標準化 |
| 集合と論理 | ド・モルガンの法則、包除原理、分配法則、対偶、全称の否定 |

- 公式のボタンは**名前と描画された式の両方**を出す。式だけでは目で探しにくく、
  名前だけでは何が入るか分からない。
- 挿入されるのは**ブロック数式**（`$$` で囲む）。挿入した瞬間にプレビューで
  描画された形が見える。
- カーソルは式の先頭（最初に書き換えたくなる記号の直前）に入る。
  選択範囲があればそこに包まれる（記号と同じ約束）。
- 公式の検索・追加・編集は今はない。収録内容を増やすのは別issue。

## 5. 自動保存

操作は要らない。入力が600ms止まると保存し、ページを離れるときにも書き切る。

ツールバーの表示:

| 状態 | 表示 |
|---|---|
| 保存待ち（入力直後） | `保存中…` |
| 保存済み | `保存しました 12:34`（現地時刻、秒は出さない） |
| 保存に失敗 | `保存できません（ブラウザの設定か容量の上限）`（赤字、消えない） |
| 初回訪問・未編集 | 何も出ない |

保存されるのは編集中の1文書だけ（[0004](issues/0004-multi-document.md)）。

次に開いたときは、保存した内容と「いつ保存したか」が復元される。
スクロール位置とカーソル位置は復元されない（[0010](issues/0010-scroll-sync.md)）。
保存がない・壊れている場合はサンプル文書（二次方程式の解の公式）が出る。
サンプル文書には $y = x^2 - 2x$ のグラフが1つ入っている（[0040](specs/0040-sample-graph.md)）。

## 6. ツールバーの操作

狭い画面（幅480px以下）では、ボタンの文言が短くなる。
`サンプルに戻す` → `戻す`、`Markdownをコピー` → `コピー`（英語は `Reset` / `Copy`）。
押したときの動きは変わらず、読み上げに渡る名前も長いほうのままにしてある
（[0033](specs/0033-toolbar-overflow-phone.md)）。

### Markdownをコピー

編集中のソース全文をクリップボードへ入れる。成功すると `コピーしました`、
失敗すると `コピーできませんでした（手動で選択してください）` が数秒出る
（`http://` 経由やブラウザ設定でクリップボードAPIが使えないことがある）。

### サンプルに戻す

確認ダイアログ（`編集中の内容を破棄してサンプル文書に戻します。よろしいですか？`）を
出し、OKならサンプル文書に置き換える。置き換えた内容も通常どおり保存されるため、
**元の内容は失われる**。キャンセルすると何も変わらない。

### テーマの切り替え

ボタンを押すたびに `自動 → ライト → ダーク → 自動` と巡り、いまの状態を
`テーマ: 自動` のように表示する（狭い画面では `自動` だけ）。

- `自動` はOSの設定に従う。既定値。
- 選んだテーマは保存され、次回訪問時にも保たれる。OSの設定より優先される。
- 初期表示で配色はちらつかない（本体の読み込み前にテーマを当てている）。
- ダークでは、本文のコントラスト比14.6:1、壊れた数式の赤で8.8:1（実測）。

### 言語の切り替え

ボタンを押すたびに `日本語 ⇄ English` と切り替わり、いまの状態を
`言語: 日本語` のように表示する（狭い画面では `日本語` だけ）。

- 画面の文字（ツールバー、ペインの見出し、記号と公式の名前、確認ダイアログ）が
  切り替わる。
- **編集中の文書は変わらない。** 利用者が書いたものは翻訳しない。
- 選んだ言語は保存され、次回訪問時にも保たれる。
- 保存がない初回訪問では、ブラウザの言語設定に従う
  （`navigator.language` が `ja` で始まれば日本語、それ以外は英語）。
  そのとき出るサンプル文書も、選ばれた言語のものになる。
- `<html lang>` が表示中の言語と一致する（`ja` / `en`）。

翻訳は約182件（記号88・公式60・分類と群19・画面の文言15）。数学用語の英訳は
一般的な呼び方を使っているが、専門家の校閲は受けていない。

### アイコン

タブ・ブックマーク・ホーム画面に出るアイコンは、**青地に白の三日月**
（トトは月の神。[0066](specs/0066-moon-icon.md)）。
同じ記号を**ツールバーの左上**にも20pxで出す（タブのアイコンは他人から見た見分け、
ツールバーのアイコンは開いている本人から見た見分けで、目的が違う）。
`public/favicon.svg` 1枚が主で、PNG4件（32 / 180 / 192 / 512）は
そこから `scripts/make-icons.mjs` で書き出している。

- 三日月は**円を2つ重ねて**描く（白い円の上に地色の円）。円弧のパスだと
  膨らむ向きが large-arc と sweep で決まって読みにくく、`stroke-width` を
  持つぶん縮小で太さが飛ぶ。
- 16pxまで縮めても形が残る（白インク量14.5%、512pxとの差0.3pt。
  [0066](specs/0066-moon-icon.md) で実測。基準は [0019](specs/0019-app-icon.md)）。
- 地を不透明にしてあるので、ライトでもダークでも見え方が変わらない。
- `apple-touch-icon.png` だけ角丸なし（iOSが自分で角を丸める）。
- ツールバーの記号は `favicon.svg` をそのまま参照している（パスを書き写していない）。
