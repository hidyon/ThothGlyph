## 目的

コマンドを覚えていなくても選べるようにする。[0064](0064-palette-beyond-highschool.md)

使えない**。`\tilde` と `\overset` はいまも検索して0件。

記号を11件足して、記号は130→141件になる。

### 基本タブに足せない理由（測って分かったこと）

**基本タブは8件でちょうど1行の端にいる。** 読み込み中のラベルはKaTeXではなく
LaTeXのソースで出る（`\tilde{x}` のように長い）ので、**1件でも足すと読み込み中
だけ2行になり、[0032](0032-palette-height-narrow.md)の蓋（`min(98px, 15vh)`）に
達して141pxになる**。KaTeXが届くと100pxに戻るため、**読み込みの完了時に41px飛ぶ**。

| 9件（[0064](0064-palette-beyond-highschool.md)で踏んだ） | 141px | 100px | 41px | **NG** |

19件にすると幅900pxで124→177px（+53px）、幅600pxで100→141px（+41px）になり、
**初期表示のタブなので開いた瞬間に効く**。0056が30pxの見出しを諦めた基準からすると

## 仕様

### 1. 記号を11件足す（130→141件、`括弧・構造` グループへ）

タブは8つのまま増やさない。グループ名も変えない。置き場所は `括弧・構造`（6→17件）で、
既存の6件（括弧3種・2x2行列・場合分け・aligned）の**前**に並べる
（装飾のほうが1文字に掛けるもので、環境より手前にあるほうが探しやすい）。

| label | snippet | tooltip（日 / 英） |
|---|---|---|
| `\tilde{x}` | `\tilde{%CURSOR%}` | チルダ / Tilde |
| `\dot{x}` | `\dot{%CURSOR%}` | 点1つ（時間微分） / Dot (time derivative) |
| `\ddot{x}` | `\ddot{%CURSOR%}` | 点2つ（2階の時間微分） / Double dot |
| `\overset{a}{=}` | `\overset{%CURSOR%}{=}` | 上に載せる（等号の上に根拠） / Overset |
| `\underset{a}{=}` | `\underset{%CURSOR%}{=}` | 下に載せる / Underset |
| `\underbrace{x}_{a}` | `\underbrace{%CURSOR%}_{}` | 下の波括弧（説明を付ける） / Underbrace |
| `\mathcal{F}` | `\mathcal{%CURSOR%}` | 筆記体（集合・変換） / Calligraphic |
| `\mathbb{N}` | `\mathbb{%CURSOR%}` | 白抜き（数の集合） / Blackboard bold |
| `\mathrm{d}` | `\mathrm{%CURSOR%}` | 立体（単位・演算子） / Roman (upright) |
| `\mathbf{v}` | `\mathbf{%CURSOR%}` | 太字（ベクトル・行列） / Bold |
| `\text{文字}` | `\text{%CURSOR%}` | 数式の中の文章 / Text in math |

**11件すべてが `%CURSOR%` を持つ**ので、選択範囲があるときは選択した文字列が
中に入る（[0009](0009-wrap-selection.md)）。単体記号（選択の後ろに挿入されるもの）は
94件から変わらない。

#### tooltipの付け方の規則

0064で決めた規則をそのまま使う。**検索が照合するのは `label` と `title` の日英だけ**
なので、コマンド名から想像できないものは「使う場面」を括弧で足す。

| 入力（検索語） | 当たる記号 | なぜ当たるか |
|---|---|---|
| `時間微分` | `\dot{x}` | tooltipが「点1つ（時間微分）」。`\dot` を「ドット」とだけ書くと引けない |
| `blackboard` | `\mathbb{N}` | tooltipの英語が `Blackboard bold`。表示言語が日本語でも引ける（0031） |
| `tilde` | `\tilde{x}` | labelが `\tilde{x}`。正規化で `\` `{}` が落ちるため |

0064で入れた `\mathcal{N}(\mu, \sigma^2)`（正規分布）と、今回の `\mathcal{F}`（筆記体）は
**検索で並んで出る**。用途が違う（完成した記号 / 中身を決める入れ物）ので両方残し、
tooltipで区別する（「正規分布」と「筆記体（集合・変換）」）。

## 実装で変えたところ

仕様から変えた点。**記号の内容と置き場所は仕様どおり**で、変わったのは
検証の書き方と、仕様に書いた実測値1つの訂正。

### 1. 幅721pxの実測値が誤っていた（196px → 207px）

仕様の比較表に「721px 154→196px」と書いたが、**正しくは207px**。

原因は測り方で、`.palette__item` が現れるのを待って測っていたため、
**パレットのラベルがまだKaTeXで描かれていない（細い）状態を測っていた**。
ラベルはエンジンが届くまでLaTeXのソースで出るが、CSSの都合でこの段階のボタンは
描画後より狭く、折り返しが1行少なく出る。

**パレットの寸法を測るときは `.palette .katex` が現れるまで待つ。**
`.palette__item` の出現だけでは足りない（このissueで実際に11px小さく見積もった）。
比較のため基準値（6件のとき）も同じ待ち方で測り直し、そちらは122/152/154pxで
変わらないことを確かめた。

### 2. `mathcal` の検索は3件当たる（仕様では2件と書いた）

公式「標準化」の preview に `\mathcal{N}(0, 1)` が入っているため、
記号2件に加えて公式1件が当たる。**検索は公式の preview も照合対象**（0011）なので
正しい動き。チェックは件数を固定せず「筆記体と正規分布の両方が出る」に変えた。

### 3. 2行以上の確認は幅1199pxではできない

`括弧・構造` は17件でも**幅1199pxでは1行に収まる**（122px・1行）。
0053で踏んだラベルのはみ出しの回帰は2行以上並ばないと見えないので、
2行になる幅721pxで確認するように変えた。

## 検討したが採らなかった案

- **基本グループに足す**（issue 0068が想定していた置き場所）。`\bar` `\vec` `\hat` の
  隣に並ぶので探しやすいが、**基本は8件でちょうど1行の端**にいて、1件でも足すと
  読み込み中だけ41px高くなる（[上の実測](#基本タブに足せない理由測って分かったこと)）。
  飛びを消すには19件まで増やす必要があり、そうすると幅900pxで+53px・幅600pxで+41px。
  初期表示のタブなので、開いた瞬間に効く。
- **グループ名を `括弧・装飾・構造` に変える**。名前と中身は合うが、英語では
  横帯の全幅で検索欄が2行目に落ちる（1169px → 1199px）。
- **`装飾` タブを新設する**。0064で測ったとおり、タブ1つで検索欄が2行目に落ち始める
  幅が上がる（日本語944→1007px）。落ちると横帯で+34px。
- **`\mathsf` `\mathtt` `\mathfrak` も入れる**。数学のノートで使う頻度が低く、
  `\mathbf` と合わせて4書体あれば足りる。必要になったら別issueで足す。
- **`\overline` を `括弧・構造` にも置く**。0064で演算子グループに入れてあり、
  同じ記号を2か所に置くと検索結果に重複が出る。
