# 0029: ギリシャ文字をすべてパレットから入力できるようにする

- 対応issue: [0029](../issues/0029-greek-complete.md)
- 状態: implemented
- 作成日: 2026-09-19

## 目的

ギリシャ文字は16件しか入っていない（小文字12・大文字4）。ζ ξ ν のように
数学でも物理でもふつうに使う文字が抜けていて、書くにはLaTeXのコマンドを
覚えて手で打つしかない。[R2](../requirements.md)（コマンドを覚えていなくても
書ける）の穴を塞ぐ。

## 仕様

### 1. 収録するのは42件

| 種類 | 件数 | 中身 |
|---|---|---|
| 小文字 | **24** | α β γ δ ε ζ η θ ι κ λ μ ν ξ ο π ρ σ τ υ φ χ ψ ω |
| 異体字 | **7** | `\varepsilon` `\vartheta` `\varkappa` `\varpi` `\varrho` `\varsigma` `\varphi` |
| 大文字 | **11** | Γ Δ Θ Λ Ξ Π Σ Υ Φ Ψ Ω |

**大文字は24個すべてではなく11個にする。** `\Alpha` はラテン文字の `A` と
見た目がまったく同じで（実際にKaTeXで描画して確かめた。出力の違いはLaTeXの
注釈だけ）、ボタンに並べても区別がつかない。数学の慣習でも、ラテン文字と
字形が同じ大文字は使わない。**見分けのつかないボタンを13個増やす意味がない。**

小文字は `\omicron`（ο）も入れる。`o` と見た目は近いが、24文字の一覧から
1文字だけ欠けているほうが分かりにくい。

### 2. グループを2つに分ける

いまの `ギリシャ文字` グループ（16件）を、次の2つに置き換える。

| グループ名 | 件数 | 中身 |
|---|---|---|
| `ギリシャ小文字` | 31 | 小文字24 + 異体字7 |
| `ギリシャ大文字` | 11 | 大文字11 |

42件を1つのタブに並べるとパレットが高くなる。小文字と大文字は探すときの
気持ちが違う（「ξ が欲しい」と「Σ が欲しい」）ので、分けるほうが探しやすい。

異体字は小文字の側に置き、**もとの字の直後に並べる**（ε の次に ϵ、θ の次に ϑ）。
別タブにすると「ε の別の形」を探せない。

### 3. スニペットの形は変えない

既存と同じく `'\\alpha '`（末尾に空白）。空白があるのは、後ろに文字が続いたとき
`\alphax` のようにコマンド名が伸びてしまうのを防ぐため。

`CURSOR_TOKEN` は持たない（単体記号なので、[0009](0009-wrap-selection.md) の
約束どおり選択範囲の直後に挿入される）。

### 4. `title` は英語のコマンド名

既存に合わせる（`alpha`、`beta`）。大文字は `Gamma（大文字）` の形を引き継ぐ。
異体字は `varepsilon（epsilonの別の形）` のように、**コマンド名で始めて**
もとの字も分かる形にする。

**実装時に直した点**: 当初は `epsilon（別の形）` と書いていたが、これだと
`varpi` の `pi（別の形）` が `pi` と前方一致で衝突し、検証スクリプトが
ボタンを一意に選べなくなった（実際に落ちて気づいた）。他のtitleが
コマンド名で始まっているのに合わせるほうが、利用者にとっても
「何のコマンドか」が分かる。

### 対象ファイル

| ファイル | すること |
|---|---|
| `src/lib/palette.ts` | `ギリシャ文字` を2グループに置き換え、42件を並べる |

| `scripts/verify-ui.mjs` | `selection` 区分は `ギリシャ文字` タブを使っているので直す。`greek` 区分を足す |
| `docs/functional-spec.md` / `docs/test-spec.md` | 件数と内容を更新 |

`SymbolPalette.tsx` は**触らない**。グループが増えるだけで、描画の仕組みは同じ
（パレットはデータ駆動という約束どおりに済むかの確認でもある）。

## 未確認の前提

- **`scripts/verify-ui.mjs` の `selection` 区分が壊れる。** `\alpha` を押すのに
  `getByRole('tab', { name: 'ギリシャ文字' })` を使っており、グループ名を
  変えると当たらなくなる。タブ名を `ギリシャ小文字` に直せば済む見込みだが、
  実際に流すまで分からない。
- 42件に増えたときのパレットの高さは測っていない。0018で記号タブは94pxだった。
  極端に高くなるようなら、グループの分け方に戻る。
- 異体字7件がKaTeXで描画できることは確認済み（`throwOnError: true` で55件すべて
  エラーなし）。ただし**ボタン上で見分けがつくか**は見ていない。

## 測定の記録

| タブ | 件数 | パレットの高さ（幅1440px） |
|---|---|---|
| ギリシャ小文字 | 31 | **136px**（2行） |
| ギリシャ大文字 | 11 | **94px**（1行） |

比較のため、[0018](0018-formula-library.md) で測った値: 記号タブ（基本・8件）94px、
公式タブ 148px。**31件でも136pxで、公式タブより低い。** グループを分けない場合は
42件が1タブに入って3行以上になったはずで、分けた判断は妥当だった。

`SymbolPalette.tsx` には差分がない（`git diff --stat src/components/` が空）。
グループを2つに増やしただけで描画の仕組みに触れずに済んでおり、
**「パレットはデータ駆動」という設計上の約束が実際に守られている**ことの確認にもなった。

## 検討したが採らなかった案

- **大文字24件すべてを入れる。** `\Alpha` `\Beta` などはラテン文字と
  見た目が同じで、ボタンで選べない。入れても「どれを押せばいいか分からない」
  ボタンが13個増えるだけ。
- **異体字を別タブにする。** 「ε の別の形が欲しい」ときに探せない。
  もとの字の隣に置くほうが見つかる。
- **1つのタブに42件すべて並べる。** パレットが高くなり、探すのも遅くなる。
- **ヘブライ文字（`\aleph`）を一緒に入れる。** issueの「やらないこと」。

## スコープ外

- 太字・花文字（`\boldsymbol{\alpha}`、`\mathcal{A}`）。
- 検索による絞り込み（[0011](../issues/0011-palette-search.md)）。
  件数が増えるほど必要になるが、このissueでは扱わない。
