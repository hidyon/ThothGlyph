# 0090: 設定メニューからREADMEを読めない

- 対応issue: [0090](../issues/0090-readme-in-settings.md)
- 状態: implemented
- 作成日: 2026-09-23

## 目的

アプリを使っている人が、機能や記法を確認するためにリポジトリや別のタブへ移動せず、設定メニューからREADMEを読めるようにする。編集途中のMarkdownと表示設定はそのまま保つ。

## 仕様

- 設定メニューに、言語・テーマに続けて「README」（英語表示では `README`）を置く。
- 項目を選ぶと、READMEをMarkdownとして描画した読み取り専用のモーダルを開く。
- モーダルには「README」の見出し、閉じるボタン、本文を置く。本文は縦にスクロールできる。
- 背景のクリック、閉じるボタン、Escapeキーでモーダルを閉じる。
- 開閉しても、編集中の文書、カーソル位置、テーマ、言語、設定メニュー以外の画面状態を変えない。
- README本文はビルド時にアプリへ含める。ネットワーク接続、GitHub、`file://`での相対パス解決には依存しない。
- README内の画像は、モーダルでも表示されるようアプリの配布物に含める。

### 対象ファイル

| ファイル | 変更 |
|---|---|
| `src/components/Toolbar.tsx` | 設定メニューのREADME項目とモーダルを追加する |
| `src/lib/messages.ts` | READMEと閉じるための日英文言を追加する |
| `src/index.css` | READMEモーダルの配置、スクロール、Markdown本文の見た目を追加する |
| `README.md` | アプリ内表示向けの画像パスを確認する |
| `public/` | READMEが参照する画像を配布物へ置く |
| `scripts/verify-ui.mjs` | 設定メニューからの開閉と、編集内容が保たれることをChromiumで確認する |
| `docs/functional-spec.md` / `docs/test-spec.md` | 実装後の機能と検証方法を更新する |

## 未確認の前提

- Viteの`?raw` importでリポジトリ直下のREADMEをビルドへ含められること。
- READMEの相対画像パスを、アプリ内で表示できる配布パスへ安全に変換できること。

実装前に確認し、成り立たなければ仕様へ戻る。

## 受け入れ基準

- [x] 設定メニューを開くと「README」が表示され、選ぶとREADME本文を含むモーダルが開く。Chromiumで確認する。
- [x] モーダル内のREADME画像が表示され、本文を縦スクロールして読める。Chromiumのスクリーンショットで確認する。
- [x] 背景、閉じるボタン、Escapeキーのそれぞれでモーダルが閉じる。Chromiumで確認する。
- [x] 編集途中の文字列を入力してからREADMEを開閉しても、文字列、テーマ、言語が変わらない。Chromiumで確認する。
- [x] `npm test`、`npm run build`、`npm run lint`、`npm run build:file` が通る。

## 検討したが採らなかった案

- GitHubのREADMEを別タブで開く: ネットワーク接続と外部サービスに依存し、`file://`配布では使えない。
- READMEをプレーンテキストで表示する: 見出し、表、コード、画像が読みにくく、READMEそのものの見た目と異なる。

## スコープ外

- README本文の編集機能。
- README内リンクのアプリ内ブラウズ。
- 設定メニュー全体のキーボードナビゲーション改善。
