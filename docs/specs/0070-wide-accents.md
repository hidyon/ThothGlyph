# 0070: 上飾りを9件足し、装飾を「基本」に集める

- 対応issue: [0070](../issues/0070-wide-accents.md)
- 状態: implemented
- 作成日: 2026-09-21

## 目的

2文字以上に掛かる上飾りを9件足して、$\widehat{ABC}$（角）や
$\overrightarrow{AB}$（幾何のベクトル）を覚えていなくても選べるようにする。
いまは `\hat` `\vec` しかなく、**1文字分しか掛からない**。
`widehat` `線分` `下線` `上の波括弧` `overrightarrow` `アクセント` は
いずれも検索して0件（[0070](../issues/0070-wide-accents.md)の背景で実測）。

あわせて、[0068](0068-palette-decorations.md) で `括弧・構造` に置いた装飾6件を
`基本` へ移し、**装飾を1つのタブにまとめる**。0068で括弧・構造に置いたのは
「置きたい場所ではなく置ける場所」だったため。

記号は141→150件になる。

## 仕様

### 1. 上飾りを9件足す（`基本` グループへ）

| label | snippet | tooltip（日 / 英） |
|---|---|---|
| `\check{x}` | `\check{%CURSOR%}` | チェック / Check |
| `\breve{x}` | `\breve{%CURSOR%}` | ブレーブ / Breve |
| `\acute{x}` | `\acute{%CURSOR%}` | アキュート / Acute |
| `\grave{x}` | `\grave{%CURSOR%}` | グレーブ / Grave |
| `\widehat{ABC}` | `\widehat{%CURSOR%}` | 角（2文字以上に掛かる） / Wide hat (angle) |
| `\widetilde{xy}` | `\widetilde{%CURSOR%}` | 広いチルダ / Wide tilde |
| `\overrightarrow{AB}` | `\overrightarrow{%CURSOR%}` | 幾何のベクトル / Vector (geometry) |
| `\underline{x}` | `\underline{%CURSOR%}` | 下線 / Underline |
| `\overbrace{x}^{a}` | `\overbrace{%CURSOR%}^{}` | 上の波括弧 / Overbrace |

### 2. 0068で置いた装飾6件を `括弧・構造` から `基本` へ移す

`\tilde{x}` `\dot{x}` `\ddot{x}` `\overset{a}{=}` `\underset{a}{=}`
`\underbrace{x}_{a}` の6件。**labelとsnippetとtooltipは1文字も変えない**
（移すだけ。検索の当たり方も変わらない）。

移したあとの並びは「1文字に掛かるもの → 2文字以上に掛かるもの →
上下に載せるもの」の順にする。

```
分数・根号・上付き・下付き（既存5件）
\bar \vec \hat \tilde \dot \ddot \check \breve \acute \grave   ← 1文字
\widehat \widetilde \overrightarrow \underline                 ← 2文字以上
\overset \underset \overbrace \underbrace                       ← 上下に載せる
```

`括弧・構造` に残るのは11件（書体5件＋括弧・構造6件）。
**書体（`\mathcal` `\mathbb` `\mathrm` `\mathbf` `\text`）は移さない**
（「中身を決める入れ物」で装飾とは別の系統。[0068](0068-palette-decorations.md)）。

### 3. `\overline` のtooltipに「線分」を足す

線分 $\overline{AB}$ は `\overline` と同じコマンドで、**演算子グループに
すでにある**（0064で「上線（標本平均・補集合）」として入れた）。
2か所に置くと検索結果が重複するので、**tooltipを
`上線（標本平均・補集合・線分）` / `Overline (sample mean, complement, segment)`
に変えて引けるようにする**。

#### tooltipの付け方の規則（0064・0068と同じ）

| 入力（検索語） | 当たる記号 | なぜ当たるか |
|---|---|---|
| `角` | `\widehat{ABC}` | tooltipが「角（2文字以上に掛かる）」。いまは公式6件（2倍角など）だけが当たり記号は0件 |
| `線分` | `\overline{X}` | 演算子グループのtooltipに「線分」を足すため。`\overline` を2件目として置かない |
| `geometry` | `\overrightarrow{AB}` | tooltipの英語が `Vector (geometry)`。表示言語が日本語でも引ける（0031） |

## 実装で変えたところ

### 1. 幅540pxでグラフがプレビューに収まらなくなった（`graph` 区分の基準を書き換えた）

仕様の実測表は幅1199/900/721/600/375/360pxで測っていて、**幅540pxを見ていなかった**。
全区分を流したところ `graph` の「幅540pxで図がプレビューのペインに収まり、
横スクロールも出ない」が落ちた（図274px / ペイン264px）。

**調べたところ、この基準は変更前から8タブ中7タブで満たされていなかった。**

| 選んでいるタブ | パレット | ペイン | 図 | 収まるか |
|---|---|---|---|---|
| Markdown（7件） | 100px | 285px | 274px | 収まる |
| ギリシャ小文字（31件） | 141px | 264px | 274px | **収まらない（0070の前から）** |
| 基本（0070で23件） | 141px | 264px | 274px | **収まらない（0070で変わった）** |
| 公式 | 177px | 246px | 274px | **収まらない（0070の前から）** |

パレットの高さは選んでいるタブで変わるので、**0037の検証が通っていたのは
初期表示のタブ（基本）が偶然いちばん小さかったから**だった。
0070で基本が23件になり、初期表示でも収まらなくなって露出した。

ユーザーと相談し（代替案の「装飾を集めず括弧・構造へ足す」も測って比べた）、
**このまま進める判断をもらった**。`graph` 区分の基準は次の2つに書き換えた。

- 幅540/375/360pxで**図の横幅**がペインに収まり、横スクロールも出ない
- 幅540/375/360pxで、**いちばん高いパレット（公式タブ）でも縦スクロールで
  図の下端まで届く**（実測: 幅540pxでパレット177px・ペイン246px・図274pxで届く）

図そのものを狭い画面で縮める話は [0071](../issues/0071-graph-height-narrow.md) へ切り出した。
**目盛りの文字は幅360pxで11.7pxしかなく（基準11px）、縮める余地がほぼない**ことも
起票時に記録してある。

### 2. `\overline` のtooltipを変えたので `palette-stats` が落ちた

0064の区分が `上線（標本平均・補集合）` でボタンを探していた。
`上線（標本平均・補集合・線分）` に直した（自分の変更が起こした回帰）。

### 3. 事前に洗った9件は想定どおりだった

仕様の「壊れる既存チェック」に挙げた9件は、値も直し方も想定どおりだった。
**実装後に出たのは上の2件**（幅540pxのグラフとtooltipの参照）で、
どちらも**仕様の実測表に無かった幅・無かった変更**から出ている。

## 検討したが採らなかった案

- **`\overline{AB}`（線分）を基本にも置く。** 演算子にある `\overline` と
  同じコマンドで、検索結果が2件になる。tooltipに「線分」を足すだけにした。
- **`\overleftrightarrow{AB}`（直線）と `\mathring{x}` も入れる。** どちらも描けるが、
  ノートに書く頻度が低い。`\overleftrightarrow` は23文字で**いま最長のラベル**になる。
- **装飾を括弧・構造に残したまま上飾りだけ足す。** 装飾が2グループに散ったままになる。
  括弧・構造は幅900pxで194pxまで来ていて、公式タブ（210px）まで16pxしかない
  （0068の実測）。9件足すと1行増えて超える。
- **書体も基本へ移す。** 「中身を決める入れ物」で系統が違い、基本が28件になる。
- **`装飾` タブを新設する。** 0064の実測どおりタブ1つで横帯が+34px。

## スコープ外

- **囲み・打ち消し**（`\boxed` `\cancel` `\not`）と**大きさ・間隔**
  （`\displaystyle` `\big(` `\quad`）。必要になったら別issueで足す。
- **線形代数**（[0067](../issues/0067-palette-linear-algebra.md)）。
- **書体の残り**（`\mathsf` `\mathtt` `\mathfrak` `\boldsymbol`）。
  `\boldsymbol` は統計で常用するので、別issueとして起票する価値がある。
- **既存の141件を減らすこと。** 足すと移すだけで、消さない。
- **公式（75件・15分類）を触ること。**
- **サンプル文書を変えること。**
