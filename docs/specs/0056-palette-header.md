# 0056: パレットにも見出しを付ける

- 対応issue: [0056](../issues/0056-palette-header.md)
- 状態: implemented
- 作成日: 2026-09-20

## 目的

ソースとプレビューには見出し行（`ソース` / `プレビュー`）があるのに、
パレットにだけ無い。[0054](0054-palette-placement.md)で3つの領域が横に並んだので、
左端の帯だけ名前がないのが目立つ。同じ形の見出しを付ける。

## 実測（仕様を決めるために先に測った）

2026-09-20。`.pane__header` と同じ見出しをパレットに差し込んで測った。

| 画面 | パレットの高さ | textarea | 一覧（ボタンの領域） |
|---|---|---|---|
| 1440×900（縦帯） | 845 → **845px**（変わらず） | 815 → **815px**（変わらず） | 141 → 141px（変わらず） |
| 1199×800（横帯） | 94 → **124px** | 621 → **591px** | 57 → 57px |
| 720×800（横帯・上下分割） | 100 → **130px** | 294 → **279px** | 57 → 57px |
| 360×640（電話） | 139 → **169px** | 194 → **179px** | 96 → 96px |

**縦帯では高さがまったく増えない。** 帯（845px）の中に余白があり、
見出しはその余白に載るだけだから。一方**横帯では30pxそのまま増え**、
textareaがその分減る（幅360pxでは上下分割なので15px）。

## 仕様

### 1. 見出しは縦帯（幅1200px以上）でだけ出す

- 幅1200px以上: パレットの先頭に `.pane__header` と同じ見出しを出す。
- 幅1199px以下: **出さない**（横帯。今までどおり、いきなりタブが並ぶ）。

横帯で出さないのは、[0032](0032-palette-height-narrow.md)で
「狭い画面では編集領域を残す」と決めているため。幅360pxで
textareaが194px → 179pxに減るのは、その約束を削る方向になる。
**縦帯ではタダで付き、横帯では高く付く**という実測どおりに分ける。

### 2. 見出しの中身

- 文言は `パレット` / `Palette`（`lib/messages.ts` に2言語で足す）。
- ソース・プレビューと同じ `.pane__header` のクラスを使う。高さ30px。
- **ボタンや状態表示は置かない**（名前だけ）。
- パレットの背景は `--bg-muted` なので、見出しもその上に載る
  （ソース・プレビューの見出しは `--bg`。色は既存のクラスに従う）。

### 3. 読み上げ

- 見出しは `<header class="pane__header">`（ソース・プレビューと同じ形）。
- パレット全体に `aria-label` は付けない。タブは既に `role="tablist"` を
  持っており、見出しはその外側の飾りとして置く。

### 対象ファイル

- `src/components/SymbolPalette.tsx` — 先頭に `<header className="pane__header">`。
- `src/lib/messages.ts` — `paletteHeader: t('パレット', 'Palette')`。
- `src/index.css` — 幅1199px以下で見出しを隠す（`@media (max-width: 1199px)`）。
- `scripts/verify-ui.mjs` — `placement` 区分に足す。
- `docs/functional-spec.md` — 画面の図（縦帯側）に見出しを書く。

## 実装で変えたところ

- **既存チェック8件が `.pane__header` を全部拾っていた。** パレットにも
  同じクラスの見出しが付き、横帯では `display: none`（高さ0）になるため、
  「見出し行が30pxのまま」を見ていた6件に0が混ざって落ちた。
  `i18n` の2件は先頭の見出しが `Palette` / `パレット` になって落ちた。
  いずれも**意図は「ソースとプレビューの見出し行」**なので、対象を
  `.pane--editor .pane__header, .pane--preview .pane__header` に絞った
  （`i18n` / `file-load` / `file-save` の4か所）。
  **自分の変更が起こした回帰**なので、その場で直してここに記録する。
- 仕様のとおり、寸法は1つも動いていない（幅1440pxでパレット845px・
  textarea 815px、幅1199pxで94px・621px、幅360pxで139px・194px）。

## 未確認の前提

- `.pane__header` は `justify-content: space-between` で、中身が1つだと
  左寄せになる。パレットでもそうなること
  → **左寄せになった**（スクリーンショットで確認。3つの見出しが横に揃う）。
- 見出しを足しても、縦帯の公式タブ（中身959px）のスクロール量が
  変わらないこと。
  → **変わらなかった**（`placement` 区分の「公式タブで帯が縦スクロールする」が
  中身959px / 帯845pxのまま通っている）。

## 検討したが採らなかった案

- **どの幅でも見出しを出す。** 幅360pxでtextareaが194px → 179pxに減る。
  0032・0033で確保した編集領域を削る方向なので採らない。
- **見出しに検索欄を移す**（ソース側の `検索` ボタンと同じ並び）。
  検索欄の置き場所は[0011](0011-palette-search.md)で決めたもので、
  本issueの範囲を超える。
- **見出しにタブの選択状態を出す**（`パレット / ギリシャ小文字` のように）。
  タブ自身が選択状態を示しているので二重になる。
