# 0083: 式のラベルと参照を、既存の方言で書けるようにする

- 対応issue: [0083](../issues/0083-crossref-dialect.md)
- 状態: implemented
- 作成日: 2026-09-22

## 目的

いまの参照は `[(1)](#eq-密度)` と書く。リンク文字列の数字は描画のたびに現在の
番号で上書きされるので、**書いた数字には意味がない**。ところが見た目は
「数字を自分で管理している」ようにしか読めず、**分かりづらい**という指摘が出た。

このissueのあと、**ラベルを1回書き、本文からは数字を書かずに参照できる**。

```
$$
f(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$ {#eq-density}

@eq-density で $\mu = 0$ とすると
```

記法は**発明しない**。すでにあるQuartoの綴りに合わせる。持ち出した先がQuartoなら
本当に動き、そうでなくても「この綴りは何か」が調べられる。

## 仕様

### 1. どの方言に合わせるか

**Quarto式**（`{#eq-ラベル}` と `@eq-ラベル`）を採る。

| 方言 | ラベル | 参照 | 参照の描画 |
|---|---|---|---|
| **Quarto**（採る） | `$$ … $$ {#eq-density}` | `@eq-density` | Quartoでは `Equation 1` |
| pandoc-crossref | `$$ … $$ {#eq:density}` | `@eq:density` | pandoc-crossrefでは `eq. 1` |

ハイフンのQuarto式にする理由は2つ。**このエディタが作るアンカーが既に
`id="eq-1"` でハイフンであること**と、`:` を含むラベルはHTMLのidとして
扱いにくいこと。

### 2. ラベルの書き方

**閉じの `$$` と同じ行に、空白をはさんで `{#eq-ラベル}` を書く。**

```
$$
E = mc^2
$$ {#eq-einstein}
```

- ラベルは **`eq-` で始まり、続きは `a-z` `0-9` `-` `_` だけ**（ASCII、小文字）。
  Quartoの決まりに合わせる。
- **日本語のラベルは使えない。** `@eq-密度より` のように、後ろに日本語が続くと
  **ラベルの終わりが判定できない**（英数字なら空白や助詞ではなく文字種で切れる）。
  旧記法（`\tag{密度}`）では日本語が使えるので、そちらは残る（5節）。
- ブロック数式（`$$`）だけが対象。インライン数式にラベルは付けられない。
- 同じラベルが2つ以上あるときは、**どちらも採番し、参照は最初のものを指す**
  （0044と同じ）。

### 3. 参照の書き方

本文に **`@eq-ラベル`** と書く。

- 前が英数字・`@` のときは参照とみなさない（メールアドレスなどを巻き込まない）。
- ラベルの終わりは `a-z0-9-_` 以外の文字。日本語はここで切れるので
  `@eq-density で` も `@eq-densityで` も同じように読める。
- **描画は `(1)`**。Quartoの `Equation 1` や pandoc-crossref の `eq. 1` には
  しない。日本語で「式 @eq-density より」と書いたときに
  「式 Equation 1 より」になるのを避けるため。**言語で変えない**
  （0044の参照の見せ方をそのまま引き継ぐ）。
- リンクになり、押すと0044と同じようにその式へ動く（URLは変えない）。
- **採番されていないラベルは何もしない。** `@eq-typo` は文字のまま残る。

### 4. 入力と出力の例

`{#eq-density}` が1番、`{#eq-mean}` が2番に採番されている文書。

| ソース | プレビューでの表示 | リンク先 |
|---|---|---|
| `@eq-density より` | (1) より | `#eq-1` |
| `式 @eq-mean のとおり` | 式 (2) のとおり | `#eq-2` |
| `(@eq-density) を見よ` | ((1)) を見よ | `#eq-1` |
| `@eq-typo より` | @eq-typo より（文字のまま） | — |
| `` `@eq-density` `` | `@eq-density`（コードの中） | — |

**3行目は素直ではない。** Quartoは `(@eq-x)` を `(Equation 1)` と描くので
丸括弧つきで書く習慣があるが、このエディタは `(1)` と描くので `((1))` になる。
**丸括弧は書かない**のが正しい書き方で、手本（サンプル文書・ガイド）は
そのように書く。

### 5. 旧記法との関係

**`\tag{名前}` と `[(1)](#eq-名前)` は読めるまま**にする。利用者の手元の文書と、
これまでの手本がその形で書かれている。

- 採番は**両方をまぜて文書順**に1から振る。
- `{#eq-…}` と `\tag{…}` が同じ式にあるときは、**`{#eq-…}` のラベルを採る**。
  `\tag` は0044どおりLaTeXから外す（番号は1つだけ出る）。
- **手本は新記法に書き換える。** サンプル文書（`sampleDocument.ts`、日英4か所）と
  算式記載ガイドの第1部12項（`guideDocument.ts`、日英4か所）。
  ラベルはASCIIにする（`密度` → `density`、`標本平均` → `samplemean`）。
- 機能仕様には「**旧記法も読める**」と書く。新しく書くなら新記法、と分かる形で。

### 6. 要求仕様（R7）の改訂

[R7](../requirements.md) はいま「**Markdownの書式に従わない独自記法は、原則として
採用しない**」で、この対応はその例外になる。R7に次の趣旨を足す。

> 独自記法は発明しない。ただし、**同じことをする既存の方言がある**なら、
> その綴りに合わせる形で採用してよい。合わせた先（Quarto・Pandoc）では実際に
> 動き、そうでない場所でも「何の記法か」を調べられるため。
> **持ち出した先での劣化**（`{#eq-density}` や `@eq-density` が文字として出る）は
> 承知のうえで採る。完全な形で渡す道は
> [0050](../issues/0050-html-export.md)（HTML書き出し）に置く。

判断の順序（1. 標準の記法 → 2. 標準の入れ物 → 3. 入れない）の2と3の間に
「**2.5 既存の方言に合わせられないか**」を入れる。

## 未確認の前提

- **`{#eq-…}` を拾う位置。** `$$` はMarkdown変換より前に退避される
  （[アーキテクチャ3節](../architecture.md)）。ブロック数式の正規表現に
  「閉じ `$$` の後ろの `{#eq-…}`」を足して**1度の走査のまま**扱えるはずだが、
  `MASK_PATTERN` はグループ番号で分岐しているので、足すと番号がずれる。
- **`@eq-…` と `[(1)](#eq-…)` の同居。** どちらも参照として同じ経路で退避する
  つもりだが、置換後の長さが変わる点（0010の `OffsetMap`）は0044と同じ扱いで
  足りるはず。
- **Quartoが大文字や日本語のラベルをどう扱うか**は確かめていない。この仕様では
  ASCII小文字だけを受けるので、**受ける側としては安全側**に倒している。
- **`@` で始まる語が本文に出る文書**（メールアドレス、SNSのID）で誤検出しないか。
  `eq-` で始まるものだけを見るので当たらないはずだが、実際の文書で確かめる。

## 検討したが採らなかった案

- **pandoc-crossref の `{#eq:…}` / `@eq:…`** — `:` を含むラベルはHTMLのidに
  しづらく、このエディタの既存アンカー（`eq-1`）とも綴りが揃わない。
- **独自記法を作る**（`{#eq:密度}` を自前で定義する） — 発明した記法は
  持ち出した先で「読めないゴミ」にしかならない。合わせる先があるなら合わせる。
- **参照を `Equation 1` と描く**（Quartoに揃える） — 日本語の文中で
  「式 Equation 1 より」になる。ソースの互換が目的で、描き方まで合わせる必要はない。
- **旧記法を落とす** — 利用者の手元の文書が読めなくなる。読む側は両方受ける。

## スコープ外

- 定理・図表の番号（[0041](../issues/0041-theorem-blocks.md)・[0048](../issues/0048-geometry-figures.md)）。
  ただし同じ仕組みで番号を振れる形に寄せておく。
- 書き出し時の番号の焼き込み（[0082](../issues/0082-bake-equation-numbers.md)）。
  **この仕様の記法を焼ける必要がある**ので、0082は0083の後。
- HTML書き出し（[0050](../issues/0050-html-export.md)）。
- 複数参照（`[@eq-a;@eq-b]`）。pandoc-crossrefにはあるが、まず1つずつで足りる。
- READMEの記載（[0084](../issues/0084-readme-nonstandard.md)）。

## 実装したときに変えたこと

| 仕様 | 実装 | なぜ |
|---|---|---|
| 未確認の前提「`MASK_PATTERN` のグループ番号がずれる」 | **ずれた。1:ブロック数式 2:ラベル 3:インライン数式 4:参照の文字列 5:参照のラベル 6:方言の参照** に付け替えた | 1度の走査のまま `{#eq-…}` と `@eq-…` を足したため。番号での分岐はコメントに書いた |
| 採番されていない `@eq-typo` の扱い（「何もしない」） | **リンクにせず文字のまま残す**（`escapeHtml('@' + label)`） | 飛べないリンクを作ると、打ち間違いが押せてしまう。旧記法（`[(1)](#eq-typo)`）は書いた形を保つためリンクのままで、扱いが分かれる |

**仕様から動いた点はこの2つだけで、記法・描き方・旧記法の扱いは仕様のまま。**
