# 0053: パレットのタブにアイコンを付ける

- 対応issue: [0053](../issues/0053-palette-tab-icons.md)
- 状態: implemented
- 作成日: 2026-09-20

## 目的

パレットのタブ8つは文字だけでできている。タブを選ぶたびに文字を読んで見分ける
ことになり、位置で覚える手がかりも少ない。各タブの先頭に、そのタブの中身を
表す記号を1つ置く。`α` が見えれば「ギリシャ小文字」だと**読まずに**分かる。

タブは画面のいちばん狭い帯（幅360pxで見えるのは142px）にあるので、
**足したぶんだけ横に伸びる**。伸びた結果どこがどう変わるかは、下に実測で書く。

## 実測（仕様を決めるために先に測った）

2026-09-20、devcontainerのChromium。ページのDOMにアイコンを差し込んで測った
（実装前に測るため）。

### 現状

| 幅×高さ | 言語 | パレットの高さ | タブ行の帯 | タブ8つの合計幅 |
|---|---|---|---|---|
| 1440×900 | 日本語 | 94px | 36px | 650.1px |
| 1440×900 | 英語 | 92px | 34px | 874.9px |
| 720×800 | 日本語 | 100px | 42px | 横スクロール 674px / 見え502px |
| 375×667 | 日本語 | 141px | 42px | 横スクロール 674px / 見え157px |
| 360×640 | 日本語 | 139px | 42px | 横スクロール 674px / 見え142px |
| 360×640 | 英語 | 136px | 39px | 横スクロール 899px / 見え142px |

### 案を2つ作って測った（幅1440px・日本語）

| | タブ8つの合計幅 | 現状からの差 | 幅360pxの横スクロール |
|---|---|---|---|
| 現状 | 650.1px | — | 674px |
| **A: Unicodeのグリフ**（14px＋余白4px） | 766.5px | **+116.4px** | 791px |
| B: インラインSVG（14×14＋余白4px） | 794.1px | +144.0px | 818px |

**どちらの案でもパレットの高さは1pxも増えなかった**（幅1440/1024/720/375/360px、
日英とも）。タブの高さ（30px）より小さいものを横に足すため。

### 伸びると何が起きるか（境目の実測）

タブ行は、タブ8つ＋検索欄（180px以上）が1行に収まらなくなると**検索欄が
次の行へ落ち**、パレットの高さが 94px → 121px（日本語）に増える。
その境目の幅:

| | 日本語 | 英語 |
|---|---|---|
| 現状 | 868px で2行になる | 1092px で2行になる |
| A案（余白 padding 12px のまま） | 984px | 1208px |
| **A案（padding 10px・余白3px）** | **944px** | **1168px** |
| A案（padding 8px・余白3px） | 912px | 1136px |

つまりアイコンを足すと、**2行になり始める幅が上がる**。padding を 12px → 10px、
アイコンの右の余白を 4px → 3px にすると、上がり幅を 116px から 76px に抑えられる。
残る76pxぶん（日本語なら幅868〜943px、英語なら1092〜1167px）は、
**今より早くパレットが27px高くなる帯**になる。この帯を仕様として受け入れる。

## 仕様

### 1. アイコンはUnicodeのグリフを1文字（A案）

タブのラベルの**先頭**に、そのタブの中身を表す記号を1つ置く。

| タブ | アイコン | 選んだ理由 |
|---|---|---|
| 基本 | `√` | このタブの中で最も分かりやすい形。分数は横線だけで絵にならない |
| ギリシャ小文字 | `α` | 小文字の代表 |
| ギリシャ大文字 | `Ω` | 大文字の代表。`Σ` は演算子と紛れるので使わない |
| 演算子 | `Σ` | このタブの先頭の項目（総和） |
| 関係子 | `≠` | 関係子だけに出る形。`=` は他でも出る |
| 括弧・構造 | `{}` | 括弧そのもの。2文字だが1つの絵として読める |
| Markdown | `#` | 見出しの記法。Markdownの公式ロゴは使わない（商標） |
| 公式 | `ƒ` | 関数の f。`f` では本文の文字と区別がつかない |

**8つとも互いに違う形**であることが条件。同じ字を2つのタブに使わない。

### 2. アイコンは翻訳を持たない

日本語表示でも英語表示でも同じ記号を出す。`Text`（2言語の組）ではなく
ただの文字列として `paletteGroups` の外に持つ。

### 3. 寸法

- アイコンの文字の大きさは **14px**（タブの文字は13px。少し大きくして
  記号として見せる）。
- アイコンとラベルの間は **3px**。
- タブの左右の padding を **12px → 10px** にする（上の実測どおり、
  2行になる幅の上がりを76pxに抑えるため）。
- `line-height: 1`・`display: inline-block`・`vertical-align: -1px` で、
  タブの高さ（30px／英語27px）を変えない。

### 4. 色

アイコンはラベルと同じ色（`currentColor`）で出す。選択中のタブでは
ラベルと一緒に `--accent` になる。**アイコンだけ別の色にはしない**
（ダークモードで色を2つ管理することになるため。`renderGraph.ts` と同じ理由）。

### 5. 公式タブの2段目（12分類）には付けない

2段目のタブは分類が12個あり、記号で見分けられるものばかりではない
（`数と式` `方程式` `三角比` …）。1段目の8つだけに付ける。

### 対象ファイル

- `src/lib/palette.ts` — `PaletteGroup` に `icon: string` を足し、7グループに
  アイコンを1文字ずつ書く。
- `src/components/SymbolPalette.tsx` — タブの中にアイコンの `<span>` を出す。
  公式タブ（8つ目）のアイコンは `paletteGroups` に無いので、
  `FORMULA_TAB_INDEX` と同じ場所に定数で持つ。
- `src/index.css` — `.palette__tab` の padding を 10px に、`.palette__tab-icon`
  を足す。
- `src/lib/palette.test.ts` — アイコンが7グループぶんあり、互いに重ならないこと。
- `scripts/verify-ui.mjs` — `palette` 区分にチェックを足す（下の受け入れ基準）。
- `docs/functional-spec.md` — パレットのタブの説明にアイコンのことを1行。

## 実装で変えたところ

仕様どおりに作れなかった、または仕様の数値が違っていた箇所。

- **「2行になる幅」と「1行の下限」を取り違えていた。** 仕様の表に書いた944px
  （日本語）は**2行になる最初の幅**で、1行のままなのは945px以上だった。
  受け入れ基準を「幅945pxで1行」に直した。実装後の実測:

  | | 1行の下限 | そこから1px狭めたときのパレット |
  |---|---|---|
  | 日本語 | **945px** | 94px → 124px |
  | 英語 | **1170px** | 92px → 121px |

  早く2行になる帯は、日本語で幅869〜944px、英語で幅1093〜1169px。
  （アイコンなしの1行の下限は日本語869px・英語1093px）
- **検証の区分名は `palette` ではなく `tab-icon`。** `palette` という区分は
  無く、既存の `palette-height`（0032）とも中身が違うので新しく足した。
- **自分の変更が起こした回帰を2件直した。** どちらも検証スクリプト側で、
  タブの名前を `innerText` で読んでいた箇所がアイコンを拾ってしまったもの。
  - `palette-height` 区分: タブ名が `√基本` になり、
    `getByRole('tab', { name })` が一致せず30秒待って落ちた。
  - `search` 区分: 「Escapeで検索を抜けると見ていたタブに戻る」が
    `αギリシャ小文字` と比べて落ちた。
  - アイコンを除いてラベルだけを読む `tabLabels()` を共通ヘルパとして足し、
    3か所（`palette-height` / `i18n` / `search`）をこれに寄せた。
    **アイコンは `aria-hidden` なので、`getByRole` の名前には最初から入らない。**
- **ダークモードのチェックでテーマのボタンを1回押していた。** テーマは
  自動→ライト→ダークの巡回なので、1回では**ライト**にしかならず、
  ダークを見たつもりで見ていなかった（スクリーンショットで気づいた）。
  保存の値を直接 `dark` にして開き直す形に変え、「背景が暗いこと」の
  チェックを先に置いた。

## 未確認の前提

- **8つのグリフがdevcontainerのChromiumで描ける**（豆腐にならない）
  → プロトタイプのスクリーンショットで8つとも描かれていることを確認済み。
  実装後の本番の画面でも、ライト・ダークの両方で8つとも描かれている。
  他のOS・ブラウザのフォントは未確認。**描けなかった場合も、隣にラベルの文字が
  残っているのでタブは選べる**（機能は失われない）。
- アイコンを `<span>` で足しても、タブの `aria-selected` や
  `role="tab"` の読み上げが壊れないこと。実装時に確かめる。
  アイコンには `aria-hidden="true"` を付ける（ラベルが本体なので、
  読み上げで記号を二重に読ませない）。
  → **`aria-hidden` で付けた。`getByRole('tab', { name: '基本' })` が
  変わらず一致することを検証で確認した**（アイコンは名前に入らない）。
- padding を 10px にすることで、タブの当たり判定が横に4px狭くなる
  （50px → 46px、いちばん短い `基本` タブ）。指で押せる大きさを下回らないこと。
  → **アイコンのぶん広がるので、実際は `√基本` で58.3pxになった**（現状50px）。
  狭くならずに済んでいる。タブ8つの合計は650.1px → **726.5px**（+76.4px）で、
  padding を詰めたぶん、プロトタイプの+116.4pxより小さく収まった。
  タブの高さは30pxのまま変わっていない。

## 検討したが採らなかった案

- **インラインSVGで描く（B案）**。寸法が環境のフォントに依らず、色も自由に
  当てられる。採らなかったのは、(1) タブ8つの合計幅が +144.0px と
  グリフ（+116.4px）より広く、2行になる幅がさらに上がること、
  (2) `α` `Ω` `Σ` `ƒ` をパスで描くと結局グリフの形を手で写すことになり、
  初期チャンクにバイト数を足すだけになること。
  **豆腐が出る環境が見つかったらB案へ移る**（そのときは本仕様を書き換える）。
- **アイコンだけにして文字を消す**。いちばん狭くなるが、`Σ` が演算子か公式か、
  `√` が基本かを覚えていないと選べなくなる。issueの「やらないこと」どおり、
  まず足す。消すかどうかは足して使ってから別に決める。
- **タブの文字を小さくして幅を取り戻す**。13px → 12px は読みにくくなる方向で、
  アイコンを足す目的（読まずに分かる）と逆行する。
- **検索欄を狭めて1行を守る**（180px → 150px）。2行になる幅は下がるが、
  検索欄は [0011](0011-palette-search.md) で幅を決めた要素なので、
  本issueで動かさない。
