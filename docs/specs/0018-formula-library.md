# 0018: 有名な公式を選んで挿入する

- 対応issue: [0018](../issues/0018-formula-library.md)
- 状態: implemented
- 作成日: 2026-09-19

## 目的

パレットは**記号**を1つずつ挿入する道具で、62件すべてが記号かMarkdownの囲みである。
実際に書きたいのは「解の公式」「余弦定理」のような**式のかたまり**であることが多い。
いまはそれを1記号ずつ組み立てるしかなく、サンプル文書の解の公式は
パレットだけで作ると10回以上の打鍵になる。

**覚えていない人ほど組み立てられない。** [R2](../requirements.md)（数式のコマンドを
覚えていなくても書ける）の穴になっている。名前で選んで挿入できるようにする。

## 仕様

### 1. 公式のデータを `lib/formulas.ts` に置く

記号（`palette.ts`）とは別のファイルにする。記号は「1つの文字」、公式は
「名前のついた式」で、持つ情報が違うため。

```ts
export type Formula = {
  /** ボタンに出す日本語の名前。 */
  name: string
  /** ボタンに描画して見せるLaTeX（挿入されるものと同じ式）。 */
  preview: string
  /** 挿入される文字列。CURSOR_TOKEN を含む。 */
  snippet: string
}

export type FormulaGroup = { name: string; formulas: Formula[] }
```

`palette.ts` と同じく**データ駆動**にする。公式を増やすときは配列に1件足すだけで、
コンポーネントには触らない。

### 2. 収録する公式（高校数学まで・6分類30件）

| 分類 | 収録する公式 |
|---|---|
| 方程式 | 解の公式、判別式、解と係数の関係、因数分解（2乗の差）、展開（和の2乗）|
| 三角比 | 相互関係（sin²+cos²）、正弦定理、余弦定理、加法定理（sin）、加法定理（cos）|
| 三角関数 | 2倍角（sin）、2倍角（cos）、半角（sin²）、和積、合成 |
| 指数・対数 | 指数法則（積）、指数法則（べき）、対数の積、対数の商、底の変換 |
| 数列 | 等差数列の一般項、等差数列の和、等比数列の一般項、等比数列の和、Σk |
| 微分・積分 | 微分の定義、べき乗の微分、積の微分、べき乗の積分、定積分と面積 |

6分類・各5件で30件。**この一覧が仕様であり、増減は別issueにする。**

### 3. 挿入される形

公式は**ブロック数式**として挿入する。挿入した瞬間にプレビューで
描画された形が見えるほうが、合っているかを確かめやすいため。

```
\n$$\n<式>\n$$\n
```

`CURSOR_TOKEN` は**最初に書き換えたくなる場所**に置く。たとえば解の公式なら
係数を入れる場所ではなく、式全体を使うことが多いので末尾ではなく
`x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}` の `x` の位置に置く
（変数名を変える場面がいちばん多いという判断）。

[0009](0009-wrap-selection.md) の約束どおり、`CURSOR_TOKEN` を持つスニペットは
選択範囲があればそこに包む。公式でも同じ挙動になる。

### 4. パレットに「公式」タブを足す

既存のタブ行に `公式` を1つ足し、選ぶと**2段目のタブ**（6分類）が出る。
分類を選ぶと、その分類の公式がボタンとして並ぶ。

```
基本 ギリシャ文字 演算子 関係子 括弧・構造 Markdown [公式]
  方程式 三角比 三角関数 指数・対数 数列 微分・積分
  ┌──────────────┐ ┌──────────────┐
  │ 解の公式       │ │ 判別式        │   ← 名前
  │ x = (-b±√…)/2a │ │ D = b²-4ac    │   ← KaTeXで描画した式
  └──────────────┘ └──────────────┘
```

記号のボタンは記号だけを出すが、**公式のボタンは名前と式の両方を出す**。
式だけでは目で探しにくく、名前だけでは何が入るか分からないため。

`title` / `aria-label` は `describeInsertion` と揃えて
`解の公式（選択範囲を囲む）` の形にする。

## 未確認の前提（実装時に確かめた結果つき）

- **30件すべてがKaTeXでエラーなく描画できるか** → **確かめた。全件エラーなし。**
  式を直す必要はなかった。`preview` と `snippet` の両方を `renderMarkdown` に
  通して `katex-error` が出ないことをテストで固定した（1件につき4テスト×30件）。
- **パレットの高さがどのくらい増えるか** → **測った。**

  | 状態 | 幅1440px | 幅600px |
  |---|---|---|
  | 記号タブ（基本） | 94px | — |
  | 公式タブ（方程式） | **148px** | **207px** |

  分類による差は小さい（145〜150px）。1440pxで54px、画面の6%ほど増える。
  「極端に高い」とは言えないので、仕様には戻らずこのまま進めた。
- **幅600pxで2段目のタブが折り返るか** → **折り返らなかった**（6個で1行に収まる）。
  横スクロールも出ない（`documentElement.scrollWidth <= innerWidth`）。

## 検討したが採らなかった案

- **別ウィンドウ（ダイアログ）で選ばせる。** 30件なら2段タブで収まる。
  ダイアログはフォーカス管理と閉じ方の設計が要り、得るものに対して重い。
  件数が100を超えたら考える。
- **公式を `palette.ts` に混ぜる。** タブが12個に増えて選びにくくなるうえ、
  記号と公式でボタンの見せ方が違う（公式は名前が要る）ので、同じ型に
  収めると `label` の意味が割れる。
- **公式の検索を同時に入れる。** issueの「やらないこと」どおり。
  [0011](../issues/0011-palette-search.md) が記号の検索を扱うので、
  そこで公式もまとめて扱うほうが一貫する。
- **インライン数式として挿入する。** 公式は式として独立して読むものが多く、
  ブロックのほうが確かめやすい。インラインが要るなら選択して `$...$` で
  囲み直せる。

## スコープ外

- 公式の検索・絞り込み（[0011](../issues/0011-palette-search.md)）。
- 利用者が公式を登録すること。
- 大学以降の数学。収録範囲を増やすのは別issue。
- 公式の説明文（どんなときに使うか）を出すこと。
