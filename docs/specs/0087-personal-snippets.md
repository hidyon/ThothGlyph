# 0087: 自分用の定型を登録して再利用できない

- 対応issue: [0087](../issues/0087-personal-snippets.md)
- 状態: implemented
- 作成日: 2026-09-22

## 目的

利用者が何度も使う定義、証明の書き出し、行列、説明文をMarkdownのまとまりとして登録し、別の箇所や次回の訪問でも挿入できるようにする。共通の公式パレットでは埋まらない、個人の書き方を速くする。

## 仕様

### 1. 自分用タブ

記号・公式と並ぶパレットのタブに「自分用」/「Personal」を加える。開くと、登録済みのスニペットを名前の一覧で表示する。項目を押すと、既存のパレットと同じ挿入経路で現在のカーソル位置へ入る。

スニペットにカーソル用トークンが含まれる場合も既存の `insertSnippet` の規則に従う。選択範囲があるときの挿入は次のとおり。

| 登録した内容 | 選択した `x+1` に挿入した結果 |
|---|---|
| `\sqrt{%CURSOR%}` | `\sqrt{x+1}` |
| `**結論:** ` | `x+1**結論:** ` |
| `> 証明\n> %CURSOR%` | `> 証明\n> x+1` |

### 2. 登録・編集・削除

自分用タブには「選択範囲を登録」/「Save selection」の入口を出す。ソースで1文字以上を選んだ状態で押すと、名前を入力して登録できる。空の選択では登録操作を始められない。

各項目では名前と内容を編集でき、不要になった項目は確認して削除できる。登録、編集、削除はすぐ一覧へ反映する。空のときは、登録を促す短い案内と登録入口だけを出し、空の一覧領域は出さない。

### 3. 保存

スニペットは文書とは別にブラウザ内へ保存する。リロード後も登録内容が残る。保存できない場合は、文書の自動保存と同じく画面で失敗が分かる。

保存する1件の情報は、安定した識別子、表示名、Markdown本文である。文書ごとには分けず、すべてのノートで共通に使える。

### 4. 表示と検証

タブとスニペットの一覧は日英で表示する。幅に関わる表示は `width` 区分で確認する。既存の記号・公式の挿入、検索、Undo、パレットの高さの保証を壊さない。

## 未確認の前提

- パレットのタブを1つ増やしても、既存の幅・高さ保証を満たせるかは未測定。実装前に `width` 区分で現状を測り、仕様へ記録する。
- localStorageの残り容量は利用者の文書量に依存する。登録件数や本文長の上限は、実装前に現在の文書保存と合わせて決める。

## 検討したが採らなかった案

- 数式マクロとして作る。文章や複数行Markdownを扱えず、[0046](../issues/0046-math-macros.md)とも役割が重なるため採らない。
- ツールバーやソース見出し行に登録ボタンを足す。狭い幅ですでに余地がないため採らない。
- 文書ごとにスニペットを持つ。複数文書の保存形式が未決定なので、まず全ノート共通の個人設定にする。

## スコープ外

- 利用者間や端末間での共有・同期。
- スニペットのフォルダ分け、検索、並べ替え。
- 数式マクロ（[0046](../issues/0046-math-macros.md)）。
