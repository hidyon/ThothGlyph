# 0085: 式の番号と参照の古い書き方を落とす

- 対応issue: [0085](../issues/0085-drop-old-equation-notation.md)
- 状態: draft
- 作成日: 2026-09-22

## 目的

[0083](0083-crossref-dialect.md) で記法をQuartoの綴りへ移したとき、
古い書き方（[0044](0044-equation-numbers.md) の `\tag{名前}` と
`[(1)](#eq-名前)`）も読めるまま残した。**2通りを抱え続けると、実装・テスト・
検証・文書のすべてが二重になる。**

このissueのあと、採番と参照の記法は**`{#eq-名前}` と `@eq-名前` の1通りだけ**になる。
`\tag` は「このエディタが解釈する印」ではなくなり、**標準のLaTeXとして
KaTeXが描くだけ**になる。

## 仕様

### 1. `\tag{名前}` の扱いをやめる

`renderMarkdown` は `\tag` を見ない。**LaTeXをそのままKaTeXへ渡す。**

- 番号は付かない。`id` も付かない。
- KaTeX自身が `\tag` を描くので、**式の右に `(名前)` が出る**
  （LaTeXの `\tag` 本来の振る舞い）。
- **狭い画面で式と番号が重なる問題が戻る。** 0044はこれを避けるために
  `\tag` を外していた（KaTeXの `\tag` は `mtable width="100%"` を作る。
  幅360pxで実測）。**承知のうえで戻す**（2026-09-22、ユーザー）。
  理由は「独自の振る舞いをやめて標準に戻す」ことが目的だから。
  重なりが起きるのは**落とした記法を使い続けた文書でだけ**。

### 2. `[(1)](#eq-名前)` の扱いをやめる

`renderMarkdown` はこの形を参照として退避しない。**ただのMarkdownのリンク**として
描かれる。

- リンク文字列（`(1)`）は書いたまま出る。**現在の番号に差し替わらない。**
- 飛び先 `#eq-名前` は存在しない（`id` は `eq-<番号>`）ので、押しても動かない
  （`Preview` の `followRef` は飛び先が無ければ何もしない。0044のまま）。
- **表示は壊れない。** 文字とリンクとして読める形で残る。

`#eq-<番号>` を直接書いたリンク（`[(1)](#eq-1)`）は、**これまでどおり飛べる**。
番号のアンカーは方言の採番が作るので、そこは変わらない。

### 3. 移行の表示は出さない

旧記法で書かれた文書は、開いた時点から番号が消える（`\tag` の `(名前)` に変わる）。
**移行を促す表示は出さない。**

- 表示を作ると、旧記法を知る仕組みが実装に残り続ける。落とす目的と矛盾する。
- 文書そのものは壊れない（1節・2節のとおり、読める形で残る）。
- 変わることは機能仕様とREADMEに書く（4節）。

### 4. 文書

- **機能仕様**: 「古い書き方も読める」を消し、代わりに
  **`\tag` を書いても番号は付かない**（KaTeXがそのまま描く）ことを書く。
  「書いていないのに通る記法」を放置しない（[0051](../issues/0051-undocumented-syntax.md) の趣旨）。
- **アーキテクチャ**: 3節の「式の番号と参照」から旧記法の列を消す。
- **要求仕様**: R7の例から `\tag` / `[(1)](#eq-名前)` を借りた経緯は**残す**
  （判断の記録なので消さない）。「その後0085で方言だけにした」と1文足す。
- **算式記載ガイド**（`guideDocument.ts` 第1部12項、日英）: 「古い書き方も読める」の
  一文を消す。
- **0044の仕様**（`docs/specs/0044-equation-numbers.md`）は**消さない**。
  過去の変更の記録。
- **[0077](../issues/0077-palette-tag.md)**（パレットから `\tag` を入れる）の背景を直す。
  入れるべきものが `\tag` から方言のラベルに変わる。

## 未確認の前提

- **KaTeXが `\tag` をどう描くか（幅360px）。** 0044の実測では
  「`\right)` と `(1)` が重なり、横スクロールも出ない」だった。
  **`\tag` を外さずに渡すのは0044より前の状態**なので同じになるはずだが、
  その後にラッパ（`.math-anchor--block`）が付いているので見え方が変わりうる。
  **実装したら幅360pxで撮って、仕様に結果を書く。**
- **`\tag` が2つある式・空の `\tag{}`。** いまは採番しない判断でLaTeXを
  加工していない。扱いをやめれば**KaTeXのエラー（`Multiple \tag`）がそのまま
  赤字で出る**はずで、今と変わらない。
- **旧記法のテスト29件のうち、何件が消えて何件が置き換わるか**は実装で決まる。

## 検討したが採らなかった案

- **`\tag` を外し続けるが番号を振らない** — 書いたラベルが黙って消える。
  利用者から見て「書いたものが無くなる」のがいちばん悪い。
- **移行の表示を出す**（「この書き方はもう使えません」） — 旧記法を知る仕組みが
  残り続け、落とす目的と矛盾する。
- **旧記法を読めるまま残す**（現状維持） — 実装・テスト・検証・文書が二重のまま。
  手本が新記法だけなので、**読めるが誰も書かない記法**を抱えることになる。
