# 0092: ソースの行番号とシンタックスハイライト

- 対応issue: [0092](../issues/0092-source-line-numbers-and-syntax-highlighting.md)
- 状態: implemented
- 作成日: 2026-09-23

## 目的

Markdownソースを長く書いたときに、現在位置を行番号で共有・確認でき、見出し、リンク、コード、数式などの役割を色で読み分けられるようにする。編集自体はこれまでどおり素の`textarea`で行い、入力、IME、Undo／Redo、検索・置換、パレットからの挿入を変えない。

色や番号で視線が散る利用者は、どちらも個別に隠せる。設定は次回開いたときにも復元する。

## 仕様

### 表示

ソースペインの左端に、文書の行数と同じ行番号を表示する。番号は1から始まり、折り返した行には追加しない。スクロール中はtextareaと同じ位置を保ち、編集して行数が増減したらただちに更新する。

シンタックスハイライトはtextareaの下に同じ文字列を重ねる方式にする。textareaは入力と選択だけを担い、色付けした層は操作を受け取らない。既存の検索一致を塗る層と統合し、検索中でも構文色と一致の背景色の両方が見えるようにする。色付け用の出力は必ずHTMLエスケープし、許可した`span`と`mark`だけを生成する。

次の要素を色で区別する。

| 要素 | 対象の例 |
|---|---|
| 見出し | `# 見出し` |
| 引用・リスト | `> 引用`、`- 項目`、`1. 項目` |
| 強調・リンク | `**強調**`、`[名前](URL)` |
| インラインコード・コードフェンス | `` `code` ``、` ```ts ` から閉じるフェンスまで |
| 数式の区切りとLaTexコマンド | `$x^2$`、`$$...$$`、`\frac` |
| コメント | `<!-- コメント -->` |

数式の中身を完全なLaTexパーサーとして解釈しない。区切りとバックスラッシュで始まるコマンドを読み分ける範囲に留める。コードフェンスの中はMarkdown・数式としては色付けしない。

### 設定

ツールバー右端の設定メニューに、表示言語・テーマ・READMEと並べて次の2項目を置く。

- `行番号: オン` / `行番号: オフ`（英語では`Line numbers: On` / `Off`）
- `シンタックスハイライト: オン` / `シンタックスハイライト: オフ`（英語でも同じ語を使う）

押すたびにそれぞれオン／オフが切り替わる。初期値は両方オンとする。設定は`thothglyph:editor-display:v1`に`{ version: 1, lineNumbers: boolean, syntaxHighlight: boolean }`として保存する。値がない、壊れている、版が違う、または保存できない場合は両方オンにする。保存の失敗は編集を妨げず、通知は出さない。

行番号をオフにすると左の番号列を取り除き、本文の開始位置は従来のtextareaと同じになる。ハイライトをオフにするとtextareaを通常の文字色と背景色で表示する。いずれか一方だけをオフにしても、もう一方の表示と検索一致の強調は残る。

### レイアウトとアクセシビリティ

行番号列は読み上げ対象から隠す。編集欄のラベル、キーボード操作、フォーカス先は変えない。行番号列と構文色の層はpointer eventsを受け取らず、テキストの選択とドラッグはtextareaで従来どおり行う。

幅360pxでもソースペイン内に横スクロールを増やさない。行番号が増えても列幅は表示桁数に合わせ、本文の最小幅を保つ。狭い画面での見た目は幅の調整issueでまとめて測る。

### 性能と同期

構文色のHTMLは`useDeferredValue`で遅らせ、入力直後にtextareaの更新を待たせない。400節・400数式の文書での入力反映は要求仕様N1の50ms以内を維持する。

行番号列、構文色の層、検索一致の層はtextareaの`scrollTop`と`scrollLeft`に追従する。スクロール同期で使う隠しミラーの書式は変えず、プレビューとの同期、検索結果への移動、プレビューから数式を選んだときのスクロール位置を維持する。

## 未確認の前提

なし。既存の`editor-highlights`層がtextareaの下で検索一致を描画しており、同じ方式で構文色と統合できることを確認した。

## 受け入れ基準

- [ ] 初期表示で3行のMarkdownを入力すると、左端に`1`から`3`までの行番号が出て、折り返した行に追加番号は出ない。
- [ ] 見出し、引用、リスト、強調、リンク、インラインコード、コードフェンス、数式、LaTexコマンド、HTMLコメントを含む文書を入力すると、表の対象ごとに構文色が出る。コードフェンス内の`$`は数式色にならない。
- [ ] 設定メニューの行番号をオフにすると番号列が消え、オンに戻すと現在の行数で再表示される。リロード後も選択が残る。
- [ ] 設定メニューのシンタックスハイライトをオフにすると構文色が消え、オンに戻すと現在の文書に色が再表示される。リロード後も選択が残る。
- [ ] 行番号またはハイライトをオフにした状態でも、入力、IME、Ctrl+Z、パレットからの挿入、検索・置換、ファイルの読み書きが使える。
- [ ] 検索で一致を選ぶと、構文色を残したまま全一致と現在の一致が背景色で区別される。
- [ ] 400節・400数式の文書に20文字を連続入力しても、1文字あたりの入力反映が50ms以内で、プレビューとのスクロール同期が維持される。
- [ ] `npm test`、`npm run build`、`npm run lint`、対象の実機検証が通る。

## 検討したが採らなかった案

外部のコードエディタライブラリへ置き換える案は採らない。textareaの選択、IME、Undo、検索の重ね合わせ、プレビューとのスクロール同期は既にこのアプリのDOMを前提に作られており、置換すると本issueの範囲を超える回帰確認が必要になるため。

行番号と構文色を常時表示する案も採らない。文章だけを書くときには視覚的な情報量が増えるため、設定で個別に選べるようにする。

## スコープ外

折り返し方法の選択、Markdown以外の言語のハイライト、完全なLaTex構文解析、WYSIWYG編集、外部エディタライブラリの導入は扱わない。
