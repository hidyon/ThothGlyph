# matheditor

数式入りのMarkdownを書くためのWebエディタ。左に書いたものが、右にそのまま組版されて出る。
記号や公式はパレットから選んで入れられるので、LaTeXのコマンドを覚えていなくても書ける。
書いたものはブラウザに自動で残り、`.md` ファイルとして持ち出せる。

![ソースとプレビューが左右に並び、上に記号パレットが出ている画面](docs/screenshots/wide-light.png)

## できること

| | |
|---|---|
| **リアルタイムプレビュー** | 左のソースを打つそばから右が組み上がる。長い文書でも入力は引っかからない |
| **数式** | `$x^2$` で文中に、`$$...$$` で行を変えて。描画はKaTeX |
| **記号パレット** | 7グループ88件。押すとカーソル位置に入る。文字を選んでから押すと、その部分を包む |
| **公式の挿入** | 12分類60件（高校数学までの範囲）。名前と式を見ながら選べる |
| **横断検索** | パレットの検索欄で、タブをまたいで記号と公式を絞り込む |
| **自動保存** | 手が止まると保存され、次に開いたとき続きから書ける |
| **ファイルを開く** | 手元の `.md` をボタンかドラッグ＆ドロップで読み込む |
| **ファイルに保存** | `.md` として書き出す。名前は先頭の見出しから作る |
| **コピー** | ソース全文をクリップボードへ |
| **ダークモード** | OSの設定に従う。手動でも選べ、次回も保たれる |
| **日本語 / English** | 画面の文言を切り替える。書いた文書は翻訳しない |
| **狭い画面** | 幅360pxまで、どのボタンも画面の中に収まる |

## 書き方

数式は `$x^2$`（文中）と `$$...$$`（独立した行）。それ以外は普通のMarkdownで、
見出し・箇条書き・表・コードブロックがそのまま使える。
コードブロックの中の `$` は数式にならないので、LaTeXの書き方の説明も書ける。

記号は上のパレットから入れる。`基本` `ギリシャ小文字` `ギリシャ大文字` `演算子`
`関係子` `括弧・構造` `Markdown` `公式` のタブに分かれていて、
右端の検索欄に打てばタブをまたいで探せる（`積分`、`\int` のどちらでも当たる）。

文字を選んでからパレットを押すと、`\sqrt{}` のように**包める記号は選択部分を包む**。
`公式` タブでは、解の公式や三角関数の加法定理などを、式を見ながら選んで入れられる。

## 保存と持ち出し

入力が止まると自動で保存され、ツールバーに `保存しました 12:34` と出る。
次に開いたときは続きから書ける（保存先はブラウザの中だけで、サーバには送らない）。

持ち出しは3つ。**`ファイルに保存`** で `.md` としてダウンロード、
**`Markdownをコピー`** でソース全文をクリップボードへ、
そして手元の `.md` は **`ファイルを開く`** かソース欄へのドラッグ＆ドロップで読み込める。

## 表示

テーマはOSの設定に従い、`テーマ:` のボタンで `自動 → ライト → ダーク` と切り替わる。
`言語:` のボタンで日本語と English を切り替えられる（書いた文書はそのまま）。
スマートフォンの幅でも、パレットもツールバーも画面に収まる。

## 開発

devcontainerで開き（VSCodeで「Reopen in Container」）、`npm run dev` で
http://localhost:5173。スクリーンショットは `node scripts/make-screenshots.mjs` で撮り直す。
進め方は [CLAUDE.md](CLAUDE.md)、仕様とissueは [docs/](docs/) にある。
